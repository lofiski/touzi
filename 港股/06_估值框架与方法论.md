# 第06章：估值框架与方法论

---

## 1. 估值的基本逻辑

所有估值方法都在回答同一个问题：**这家公司值多少钱？**

估值方法分两类：
- **相对估值（Relative Valuation）**：与可比公司或历史水平对比，得出倍数
- **绝对估值（Intrinsic Valuation）**：基于未来现金流折现，得出内在价值

两者互补，实务中通常并用。

---

## 2. 市盈率（PE Ratio / Price-to-Earnings）

**公式：** PE = 股价 / 每股盈利（EPS）= 市值 / 净利润

**变体：**
- **历史PE（Trailing PE）**：用过去12个月实际利润
- **预测PE（Forward PE）**：用未来12个月的盈利预测（分析师一致预期）
- **滚动PE（TTM PE）**：用最近4个季度/最近12个月（同历史PE）

**港股PE参考区间（2026年Q1）：**

| 行业/板块 | 典型PE区间 | 备注 |
|---------|-----------|------|
| 内地银行股 | 3-6x | 市场不相信利润可持续 |
| 电讯股 | 8-15x | 成熟行业，稳定但无增长 |
| 公用事业 | 10-18x | 稳定现金流，高息 |
| 消费蓝筹 | 15-25x | 李嘉诚系、本地消费 |
| 科技龙头 | 15-30x（腾讯等） | 成长股溢价 |
| 高成长科技 | 30-80x+ | 押注未来盈利增速 |
| 生物医药（有利润） | 20-50x | 高不确定性溢价 |

**港股整体PE与A股/美股对比：**
- 恒生指数历史平均PE：约10-12倍（A股沪深300约12-15倍，美股标普500约18-22倍）
- 港股长期折价约30-40%是结构性的，不是"便宜"信号

**PE的局限性：**
- 亏损公司无法计算PE
- 受利润质量影响（非经常性损益会扭曲）
- 行业之间不可比（银行3倍PE≠科技3倍PE）

---

## 3. 市净率（PB Ratio / Price-to-Book）

**公式：** PB = 股价 / 每股净资产 = 市值 / 股东权益

**最适用场景：**
- 金融行业（银行、保险、券商）：资产就是生意本身
- 资产密集型行业（地产、工业）

**港股银行股PB参考：**
- 内地国有大行：0.3-0.6x（低于1倍意味着市场认为账面资产有水分）
- 汇丰控股：0.8-1.1x
- 香港本地银行：1.0-1.5x

**PB<1的含义：** 市场认为该公司清算价值高于市值——不一定是买入信号，可能意味着资产质量差或盈利能力不足（ROE低）。

**PB与ROE的关系：**
- 合理PB = ROE / 股权成本（Ke）
- 若ROE = 8%，Ke = 10%，合理PB = 0.8
- 高ROE公司理应有高PB（如腾讯ROE>20%，PB合理超过3倍）

---

## 4. 市销率（PS Ratio / Price-to-Sales）

**公式：** PS = 市值 / 营业收入

**适用场景：**
- 亏损但高增长的公司（无法算PE）
- SaaS、新能源、互联网早期阶段

**参考区间（港股2026年）：**
- 传统行业：0.3-1.5x
- 消费/零售：0.5-2x
- 互联网平台（有利润）：2-8x
- 高成长SaaS/科技（港股较少）：5-20x

**PS的局限：** 完全不考虑利润率，两家PS相同的公司可能一家赚钱一家烧钱，价值天壤之别。需配合毛利率、经营利润率使用。

---

## 5. EV/EBITDA（企业价值/息税折旧摊销前利润）

**公式：**
- EV（企业价值）= 市值 + 净负债（总债务 - 现金）
- EV/EBITDA = EV / EBITDA

**为什么比PE更优：**
- 不受资本结构（杠杆）影响（PE受利息支出影响）
- 不受折旧政策影响（不同公司折旧方法不同）
- 便于有不同净债务水平的公司横向比较

**港股参考区间：**
- 传统制造/工业：4-8x
- 消费品：8-15x
- 科技平台：10-25x
- 房地产：5-12x（港股地产公司通常较低）

**局限：** 不适用于金融行业（银行/保险的EBITDA无意义）

---

## 6. PEG（市盈增长比率）

**公式：** PEG = PE / 盈利增长率（%）

**用途：** 调整增速后的相对估值，解决"高PE是否合理"的问题

**Lynch原则（彼得·林奇）：**
- PEG < 1：估值相对增速便宜
- PEG = 1：合理
- PEG > 2：估值相对增速偏贵

**示例：**
- 公司A：PE = 20x，增速20%，PEG = 1.0
- 公司B：PE = 10x，增速5%，PEG = 2.0
- 尽管A的PE更高，但增速调整后A更便宜

**港股使用注意：**
- 增长预测来自分析师一致预期（iFind、Bloomberg），可能不准确
- 港股很多公司增速不稳定，PEG使用前提是增长有一定可见度

---

## 7. DCF（折现现金流估值）

### 7.1 基本框架

**公式：**
$$内在价值 = \sum_{t=1}^{n} \frac{FCF_t}{(1+WACC)^t} + \frac{终值}{(1+WACC)^n}$$

其中：
- FCF = 自由现金流（经营现金流 - 资本支出）
- WACC = 加权平均资本成本
- 终值 = FCF_{n+1} / (WACC - 终期增长率g)

### 7.2 WACC的组成

WACC = (权益成本 × 权益比例) + (债务成本 × (1-税率) × 债务比例)

**权益成本（Ke）= 无风险利率 + β × 市场风险溢价**

**港股DCF参数参考（2026年）：**
- 无风险利率：约4.0-4.5%（参考美国10年期国债收益率，因港元与美元挂钩）
- 中国/香港市场风险溢价：约6-8%（高于美股的5-5.5%，反映额外风险）
- β（贝塔）：从Bloomberg/富途查，蓝筹约0.7-1.2，科技股约1.2-1.8
- 终期增长率g：通常2-3%（不超过GDP长期增速）

**典型WACC区间：**
- 稳定型蓝筹：8-10%
- 一般科技：10-13%
- 高风险成长：13-16%

### 7.3 DCF的实用限制

DCF对假设极度敏感。终增长率和WACC差1%，估值结果可能相差30-50%。

**实践中的使用方式：**
- 不要把DCF当作精确答案，而是作为"合理价值区间"的上下界
- 做多个情景（牛/基础/熊）的DCF，看各情景下的估值范围
- DCF估值只适合有可预测现金流的公司，不适合亏损早期公司

## 8. 亏损成长股估值（特殊框架）

对于无利润的科技/生物医药公司（港股18A章公司、新经济股早期阶段），PE/PB失效。

### 8.1 适用指标

**营收倍数（Revenue Multiple / EV/Sales）：**
用历史或预测营收替代利润，与同类型公司比较。

**GMV（总交易额）/ 用户数 / ARR（年度经常性收入）：**
平台类公司看GMV，SaaS类看ARR，消费类看MAU（月活跃用户）。

**经营杠杆（Operating Leverage）与盈亏平衡点（Breakeven Point）：**
核心问题：公司在什么时候能达到盈亏平衡？需要多少额外资金（现金跑道）？

**现金跑道（Cash Runway）：**
= 账上现金 / 每月净现金消耗（Monthly Burn Rate）
- 如果现金跑道 < 12个月，公司面临再融资压力（可能大规模配股稀释）

### 8.2 生物医药公司（18A章）特殊估值

采用**rNPV（风险调整后净现值）**方法：

**rNPV = Σ [各管线NPV × 临床成功概率 × 商业化成功概率]**

**临床成功概率参考（业界平均）：**
- Phase 1 → Phase 2 通过：约60%
- Phase 2 → Phase 3 通过：约40%
- Phase 3 → 获批上市：约60%
- 全程从Phase 1到上市：约15%

**实操简化：**
- 看公司的管线成熟度（几期临床）
- 看适应症的市场空间（TAM，Total Addressable Market）
- 比较已商业化的同类药物的市值

## 9. 港股估值折价的量化

**AH溢价（A股相对H股的溢价）：**

AH溢价指数 = (A股价格 / H股价格 - 1) × 100%

- 历史平均：约25-40%
- 2024年高点：部分公司A股溢价超过100%（即H股相当于A股5折）

**这意味着：港股投资者可用更低价格买到相同的公司。但AH溢价可以持续扩大，不是"无风险套利"。**

原因：两个市场资金池隔离，散户情绪差异，流动性差异。

## 10. 估值的综合运用

### 10.1 多方法印证（Triangulation）

单一估值方法有偏差，实务中通常3-4种方法并用：

```
稳定盈利型公司：PE + PB + EV/EBITDA + 股息贴现
高成长型公司：PEG + EV/Sales + DCF（远期）
亏损成长股：EV/Sales + 现金跑道分析 + rNPV（生物医药）
金融公司：PB + ROE分析 + 股息贴现（DDM）
```

### 10.2 安全边际（Margin of Safety）

格雷厄姆的核心原则：以显著低于内在价值的价格买入，留出安全边际。

**港股建议安全边际：**
- 稳定型公司：内在价值的70-80%（安全边际20-30%）
- 成长型公司：内在价值的60-70%（安全边际30-40%）
- 高风险公司：内在价值的50%以下（安全边际50%+）

原因：港股信息不对称高、老千股多、监管风险大，需要更大的安全边际。

## 关键认知清单

- [ ] PE最常用但有局限，亏损公司/周期底部用PE失效
- [ ] EV/EBITDA比PE更能跨资本结构比较，优先于PE
- [ ] DCF结果高度敏感于假设，当作区间而非精确答案
- [ ] 亏损成长股看现金跑道——烧钱速度决定配股稀释风险
- [ ] 港股安全边际要比美股更大，因为风险更高
- [ ] AH溢价不是套利机会，不要认为"H股便宜就必定会涨"
