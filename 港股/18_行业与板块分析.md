## 2. 主要板块深度分析

### 2.1 金融板块（港股最大单一行业）

**内地银行股（H股）：**

代表：工商银行（01398）、建设银行（00939）、招商银行（03968）、中国银行（03988）

**估值特征：**
- PE：4-7倍（全球最低估值之一）
- PB：0.35-0.7倍（低于账面价值）
- 股息率：5-8%（相对高息）

**为什么这么便宜？**
1. 市场担忧房地产贷款坏账（尤其2021年后）
2. 净息差（NIM）持续压缩（低利率环境）
3. 隐性坏账（地方政府融资平台/城投债）不透明
4. 流动性溢价低（缺乏外资配置意愿）

**分析框架：**
- NIM（净息差）：每降10bp，利润影响约1-2%
- 不良贷款率（NPL Ratio）：关键信用质量指标
- 资本充足率（CAR）：监管要求>10.5%（系统重要性银行更高）
- 拨备覆盖率：越高意味着对坏账的保护越充分（>150%合格）

**香港本地银行：**
汇丰（00005）、恒生银行（00011）——受美联储利率周期影响显著（净息差随加息扩大）

**保险股：**
友邦保险（01299）——香港及亚洲寿险龙头，以内含价值（Embedded Value, EV）估值
中国平安（02318）——综合金融，含银行+保险+科技

**保险股估值指标：**
- P/EV（市值/内含价值）：友邦历史约1.5-2.5倍
- NBV（新业务价值）：衡量新保单的价值创造能力
- NBV Margin（新业务价值率）：NBV / 首年保费

### 2.2 科技/互联网板块

代表：腾讯（00700）、阿里巴巴（09988）、美团（03690）、京东（09618）、百度（09888）、网易（09999）

**特点：**
- 是港股独有于A股的稀缺资产（A股无法直接投资这些公司）
- 外资重仓，受美股科技板块情绪联动
- 2021年监管周期后永久性提高了风险折价
- 现金流充裕，但增长进入成熟期

**估值方法：**
- 腾讯：分部估值（游戏+微信广告+金融科技+投资组合）
- 阿里巴巴：核心电商+云计算+国际+本地生活+菜鸟
- 美团：到家（外卖）+到店及酒旅+新业务

**重点关注指标：**

| 公司 | 核心指标 |
|------|---------|
| 腾讯 | MAU、DAU、广告收入增速、游戏流水 |
| 阿里巴巴 | GMV、取客成本、云计算营收增速 |
| 美团 | 日均订单量、单位经济模型（Unit Economics）、即时零售进展 |

### 2.3 医疗保健/生物医药（18A章公司为主）

代表：药明康德（02359）、百济神州（06160）、信达生物（01801）、心玛（09978，举例）

**两类公司区分：**
- **CRO/CDMO（合同研究/生产）**：如药明康德，类制造业，估值相对稳定
- **创新药（Biotech）**：18A章未盈利公司，高度不确定性，估值基于管线价值

**生物医药的分析要点：**
1. **核心管线（Core Pipeline）：** 处于什么临床阶段？适应症市场规模？
2. **资金储备：** 现金够烧多少个月？（Runway）
3. **BD（业务拓展/授权）能力：** 能否将管线授权给跨国药企，提前变现？
4. **团队背景：** 核心团队的行业经验

**18A章标识（"B"字头）的特殊风险：**
- 无盈利要求上市，部分公司可能永远无法商业化
- 若现金耗尽前未能融资或BD成功，面临清算或极大稀释配股

### 2.4 地产与物业管理

**内地地产开发商（2021年后高风险）：**
碧桂园（02007）、龙湖集团（00960）、华润置地（01109）

**2021年恒大危机后的市场重塑：**
- 内房股整体估值从高峰跌去70-90%，部分已停牌/清盘
- 现存内房股：央企背景（如华润置地）明显比民营房企溢价
- 行业仍在出清，新房销售持续低迷

**物业管理股：**
碧桂园服务（06098）、华润万象生活（01209）——从母公司地产风险中分离，有轻资产逻辑，但仍受母公司信用影响

**香港本地地产：**
长实集团（01113）、新鸿基地产（00016）、恒基兆业（00012）

- 受香港楼市影响（与美联储利率高度相关）
- 2022-2024年香港楼市调整，股价受压
- 2024年底港府撤销所有楼市调控措施，潜在复苏

### 2.5 能源板块

**中国能源（央企）：**
中国石油（00857）、中国石化（00386）、中国海洋石油（00883）

**特点：**
- 高股息率（5-8%）
- 受国际油价影响，同时有国内定价机制缓冲
- 国企改革（提升ROE、分红比例）是近年催化剂

**新能源（港股上市）：**
比亚迪（01211）——汽车+电池，估值较高（PE 20-30倍）
宁德时代（暂未在港股主要上市，但有传闻）
中广核电力（01816）——核电

### 2.6 消费与零售

**必选消费：**
华润啤酒（00291）、中国蒙牛（02319）、百威亚太（01876）

**可选消费（弱复苏环境下波动大）：**
泡泡玛特（09992）、李宁（02331）、安踏体育（02020）

**汽车（港股重要板块）：**
比亚迪（01211）、吉利汽车（00175）、理想汽车（02015）、小鹏汽车（09868）、蔚来（09866）

新能源汽车竞争激烈，价格战持续，分析需特别关注毛利率和现金消耗。

## 3. 行业研究方法论

### 3.1 行业分析框架（波特五力+供需分析）

**波特五力：**
1. 行业竞争强度（现有竞争者）
2. 新进入者威胁
3. 替代品威胁
4. 买方议价能力
5. 供方议价能力

**供需分析：**
- 供给侧：产能是否在扩张？行业竞争格局如何？
- 需求侧：终端需求的驱动因素是什么？是否可持续？

### 3.2 行业生命周期

| 阶段 | 特征 | 估值特点 |
|------|------|---------|
| 导入期 | 市场形成，竞争少，增速高但基数小 | 高估值，不看盈利 |
| 成长期 | 快速扩张，行业集中度提升 | 高PEG，成长溢价 |
| 成熟期 | 增速放缓，格局稳定，现金流好 | 中等PE，股息率升 |
| 衰退期 | 需求下滑，产能过剩 | 低PE，高不确定性 |

### 3.3 竞争优势（护城河）分析

判断公司是否有持续竞争优势（Warren Buffett的护城河概念）：

| 护城河类型 | 港股案例 |
|-----------|---------|
| 网络效应 | 腾讯微信（用户越多，价值越高）|
| 成本优势 | 宁德时代（规模化生产成本）|
| 转换成本 | 企业SaaS软件（客户更换系统成本高）|
| 无形资产（品牌/专利） | 中国飞鹤（高端奶粉品牌溢价）|
| 监管牌照 | 港交所（独家垄断牌照）|

## 4. 行业轮动的实操

### 4.1 港股行业轮动的驱动因素

```
中国政策放松（降准/降息）：
  → 银行股（NIM预期改善）
  → 地产股（融资环境改善）
  → 消费（消费信心回升预期）

美联储降息（外部流动性改善）：
  → 科技成长股（折现率下降）
  → 高负债行业（融资成本下降）

油价上涨：
  → 中国石油/海洋石油
  → 内地化工相关

人民币升值：
  → 含有较多人民币收入的公司（以港元计价后收入增加）
```

## 关键认知清单

- [ ] 内地银行股低PE是结构性折价（房贷坏账+NIM压缩），不是简单便宜
- [ ] 科技板块是港股相对A股的稀缺性所在，同时受外资情绪影响最大
- [ ] 内房股在2021年后大幅分化，央企与民企差距巨大，不可一概而论
- [ ] 18A章生物医药公司需要专业医药知识才能正确评估，新手不建议深度参与
- [ ] 行业ETF是在宏观判断正确时的有效工具，避免选股带来的个股风险
- [ ] 行业研究要先看供需格局和竞争结构，再看个股，自上而下的顺序
