# 第19章：90天行动路线图

---

## 第一阶段：第1-30天——建立基础

### 第1-7天：账户与工具准备

**账户开立：**
- [ ] 开立富途牛牛港股账户（或老虎证券），完成身份验证
- [ ] 入金5万港元（若从内地银行汇款，注意5万美元年度外汇额度）
- [ ] 填写W-8BEN表格（非美国人免税申报）
- [ ] 确认账户类型为现金账户（Cash Account），不开保证金账户

**工具准备：**
- [ ] 在披露易（hkexnews.hk）注册账户，设置公告提醒功能
- [ ] 下载富途牛牛App + TradingView（用于图表分析）
- [ ] 书签以下网址：
  - 港交所南下资金数据：hkex.com.hk
  - 披露易：hkexnews.hk
  - SFC持牌查询：apps.sfc.hk/licenseSearch
  - 恒生指数实时数据：hsi.com.hk

**建立信息流：**
- [ ] 订阅信报财经新闻或香港经济日报（至少免费版）
- [ ] 关注富途App的港股资讯板块
- [ ] 设置美国10年期国债收益率的日常提醒（TradingView可设置）

---

### 第7-14天：基础阅读与理解

**必读文件（从披露易下载）：**
- [ ] 恒生指数成分股名单（最新）+ 各成分股权重
- [ ] 选2-3家大型上市公司（如腾讯、汇丰或美团），下载其最新年报，阅读：
  - 管理层讨论与分析（MD&A）
  - 审计师报告（确认是"无保留意见"）
  - 现金流量表（核对经营现金流与净利润的关系）

**理解交易机制：**
- [ ] 在富途App模拟盘（Paper Trading）中完成以下操作练习：
  - 下一张限价买单
  - 下一张限价卖单
  - 查看买卖盘（Level 2）
  - 查看成交记录
- [ ] 计算一次买卖10万港元股票的全部费用（印花税+交易费等）

---

### 第14-30天：深度研究第一只候选股

**选股范围：** 市值>100亿港元 + 日均成交额>1亿港元 + Big4核数师

**研究框架（每只股票用以下模板）：**

```
公司基本信息：
  - 主营业务（用1-2句话说清楚公司做什么）
  - 市值：___亿港元
  - 核数师：
  - 过去3年配股次数：

财务指标（取最新年报数据）：
  - 收入（近3年）：___，___，___港元
  - 净利润（近3年）：___，___，___港元
  - 经营现金流（近3年）：___，___，___港元
  - 净债务/净现金：
  - 流动比率：

估值：
  - 当前PE：___倍  历史均值PE：___倍
  - 当前PB：___倍
  - 股息率：___%
  - 分析师一致目标价：___港元（vs 当前股价___港元）

风险点（至少3个）：
  1.
  2.
  3.

买入逻辑（如果买入，原因是什么）：

止损价：___港元（理由：）
目标价：___港元（理由：）
```

**第30天检查点：**
- [ ] 已完成至少2只股票的深度研究
- [ ] 已阅读这2只股票过去12个月内的所有重要公告
- [ ] 已理解恒生指数的主要成分和权重
- [ ] 每日例行：开盘前看美股收盘+债券收益率（持续21天）

## 第二阶段：第31-60天——首次入场

### 第31-35天：首次买入决策

**买入前检查清单（必须全部通过）：**
- [ ] 公司核数师是Big4或知名中型所 ✓
- [ ] 过去5年配股次数≤2次 ✓
- [ ] 日均成交额>1亿港元 ✓
- [ ] 市值>50亿港元 ✓
- [ ] 经营现金流为正（近3年中至少2年）✓
- [ ] 买入理由是基本面逻辑，非"感觉会涨" ✓
- [ ] 已确定止损价（跌幅上限：蓝筹-15%，成长股-20%）✓
- [ ] 此次买入不超过总资金的40% ✓

**买入操作：**
- 使用限价单
- 买入1-2手（先小仓位验证判断）
- 首次买入建议总金额≤2万港元（留足后续机会）

### 第35-60天：持仓管理与学习

**持仓期间每周必做：**
- [ ] 检查持仓公司有无新公告（在富途App或hkexnews.hk）
- [ ] 记录每周价格变动原因（是整体市场波动还是个股消息）
- [ ] 对照买入逻辑：逻辑是否仍然成立？

**学习进阶内容（同步进行）：**
- [ ] 学习计算P/B、EV/EBITDA、自由现金流（找一家公司实际计算）
- [ ] 阅读1-2份机构研报（通过富途账户或公开渠道获取）
- [ ] 研究恒生指数的历史PE（高点/低点/均值），了解当前估值位置

**南下资金追踪（正式开始）：**
- [ ] 建立一个简单表格，每天记录：南下净买入总额 + 自己持仓股的南下数据
- [ ] 连续30天后，分析南下资金与持仓股价格的相关性

**第60天检查点：**
- [ ] 已完成至少1笔真实交易，有记录可查
- [ ] 已理解AH溢价的计算和含义
- [ ] 已追踪南下资金30天，对自己持仓股的南下规律有初步感受
- [ ] 已能独立阅读一份港股公告并提取关键信息

---

## 第三阶段：第61-90天——体系化与进阶

### 第61-75天：扩展研究与第二只持仓

**新增研究方向：**
- [ ] 研究1个港股行业的整体格局（选择自己感兴趣且理解的行业）
- [ ] 对比同行业2-3家公司的估值（为什么龙头比老二估值高？）
- [ ] 理解该行业的周期性（在什么宏观条件下表现好/差）

**考虑第二只持仓：**
- 与第一只持仓的相关性尽量低（行业不同，宏观驱动因素不同）
- 用相同的买入前检查清单验证
- 第二只持仓金额≤1.5万港元（保持现金储备≥30%）

**宏观框架的实际应用：**
- [ ] 查阅最新FOMC会议结果，评估对港股的影响
- [ ] 查阅最新中国PMI数据，判断内地经济方向
- [ ] 综合两个数据，更新自己对港股整体仓位的判断

### 第75-90天：首次完整复盘

**第一笔交易的完整复盘（无论盈亏）：**

```
原始买入理由：
买入价格和时间：
卖出价格和时间（若已卖出）：
实际盈亏（绝对额和%）：
同期恒生指数涨跌：
自己的Alpha（超额/低于恒指的部分）：

复盘：
① 当时的买入逻辑现在回看是否正确？
② 实际结果与预期的差异在哪里？
③ 如果重来，买入决策会改变什么？
④ 止损是否执行（若有需要）？
⑤ 从这笔交易学到的最重要一点：
```

**衍生品初步了解（仅学习，不操作）：**
- [ ] 在富途App找到腾讯或恒指的认购权证，阅读其条款（行使价、到期日、兑换比率）
- [ ] 计算该权证的隐含杠杆（不实际购买，只是练习理解）
- [ ] 了解恒指期货的当月合约价格，计算当前基差（期货价格-现货指数）

**第90天终极检查点：**
- [ ] 已完成5+家公司的深度财务研究
- [ ] 持有1-2只股票，仓位合理（总资金≤60%在股票，≥20%现金储备）
- [ ] 建立了每日信息例行程序，持续21天以上
- [ ] 完成第一笔交易的完整书面复盘
- [ ] 理解恒生指数当前的估值水平（相对历史均值）
- [ ] 已能识别3-5个老千股的典型财务特征
- [ ] 对衍生品有概念性理解（不一定操作）

## 常见错误清单（90天内必须避免）

| 错误行为 | 正确替代 |
|---------|---------|
| 看新闻追热点买股（听说某概念会涨就买）| 先研究基本面，再确认进场时机 |
| 买入仙股或日成交额<500万港元的股票 | 只买蓝筹或流动性充足的股票 |
| 开启保证金账户使用孖展 | 90天内只用现金账户 |
| 因亏损急于翻本加仓摊平 | 亏损后先复盘，确认逻辑仍成立再考虑加仓 |
| 卖出止盈后立即追高重新买入 | 卖出后等新的买入信号，不要追 |
| 参与首日破发的热门IPO暗盘 | 暗盘只参考，不重仓操作 |
| 买入停牌股票 | 停牌股票一律回避 |
| 因社群荐股直接买入（未做尽调） | 社群信息只作线索，自己研究后才决策 |
| 看技术形态买仙股 | 小盘股技术分析无效 |
| 将账户总资金100%买入股票 | 保留至少20%现金 |

## 90天后的下一步

**90天的目标不是赚钱，而是建立系统：**
- 有可执行的研究流程
- 有明确的仓位管理规则
- 有每日信息例程
- 有书面的交易记录和复盘习惯

完成90天的基础阶段后，可以：
1. 深入学习衍生品（窝轮→牛熊证→期权，按顺序）
2. 扩展行业覆盖（从1-2个行业扩展到3-5个）
3. 考虑适度增加资金（但不要因为短期盈利就急于加大风险）
4. 开始追踪AH溢价套利机会（需要同时有A股账户）
