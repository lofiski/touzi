# 第09章：老千股·仙股·壳股识别与防范

---

## 1. 三类风险股的定义

### 1.1 老千股

广义的"老千股"（Problematic Stocks）是港股特有现象，指控股股东或庄家通过一系列合法或灰色手段，持续从小股东身上转移财富的上市公司。

**关键特征：手法合法，但动机是掠夺小股东。**

常见手法：
1. **高折价配股**：以市价打8折配股给特定机构，稀释现有股东，大股东同时认购维持控制权
2. **合股（Reverse Stock Split）+ 配股循环**：先合股（如10合1，股价×10），然后再大规模配股（大幅稀释），股价回到原来水平，散户持股价值归零
3. **关联交易**：将公司资产/现金以低价转让给大股东控制的关联公司
4. **频繁收购亏损业务**：以高价从关联方收购劣质资产，让公司承担损失

### 1.2 仙股

**定义：** 股价低于1港元的股票（"仙"来自英文"Cent"，即分）

**2026年现状：** 港股约有600-800只股票股价低于1港元，占全市场约25%

**仙股与老千股的关系：**
- 不是所有仙股都是老千股（部分是正常的小公司）
- 但绝大多数老千股最终沦为仙股
- 仙股的流动性极差，大买卖单容易造成剧烈价格波动

### 1.3 壳股

**定义：** 有上市地位但主营业务已失去或微不足道的公司

**壳的价值：** 香港上市资格本身有价值（省去IPO时间和成本），壳价历史上约2-5亿港元

**壳股的常见命运：**
- 被买壳方（注入新业务）收购 → 借壳上市 → 股价可能大涨（但买壳过程散户往往被摊薄）
- 长期停牌 → 最终退市
- 被新老千继续利用

## 2. 老千股的识别特征清单

### 2.1 公司治理红旗（最重要）

| 红旗 | 说明 |
|------|------|
| 大股东持股>60%，且仍在持续增加持股 | 大股东对剩余股东控制力极强，监督机制失效 |
| 频繁更换核数师（审计机构） | 通常是因为核数师发现问题或拒绝配合 |
| 核数师是不知名本地小所 | 审计质量存疑 |
| 执行董事全为大股东家族成员 | 无独立监督 |
| 独立非执行董事无相关资质/经验 | 花瓶董事，无法制衡大股东 |
| 公司秘书频繁更换 | 内部合规文化差 |

### 2.2 融资行为红旗

| 红旗 | 说明 |
|------|------|
| 在过去3年内进行超过3次配股 | 频繁融资，不断稀释小股东 |
| 每次配股折价>10% | 以不合理折价融资，损害现有股东 |
| 配股所得资金用途模糊（"一般营运资金"） | 无具体业务需求 |
| 频繁合股后再配股 | 老千股最经典手法 |
| 可换股债券（CB）大量发行 | 债转股后大幅稀释 |
| 供股（Rights Issue）比率过高（如10供8或更高） | 不跟供股的股东被极度摊薄 |

### 2.3 财务报表红旗

| 红旗 | 说明 |
|------|------|
| 现金多但仍持续配股融资 | 账面现金可能是虚构的（经典造假模式） |
| 应收账款集中于少数关联方 | 虚构收入的常见迹象 |
| 存货/固定资产大幅上升但收入未增 | 资产注水 |
| 长期高毛利率但经营现金流为负 | 利润不能转化为现金 |
| 财务报告反复延迟发布 | 账目有问题 |
| 多次发出"盈利警告" | 业绩持续不达预期 |
| 审计意见有"强调事项"或"持续经营"质疑 | 极高警示 |

### 2.4 K线/交易行为红旗

| 红旗 | 说明 |
|------|------|
| 股价长期呈现"步步高升"后突然暴跌 | 拉升出货模式 |
| 每次公告利好后股价不涨反跌 | 庄家借利好消息出货 |
| 日成交额极低（<100万港元）但股价相对稳定 | 无真实买卖，价格是控制的 |
| 成交量突然异常放大数十倍 | 短暂拉升出货 |
| 买卖差价（Spread）异常大 | 流动性极差 |

## 3. 经典老千手法详解

### 3.1 合股+配股循环（最常见）

**时间线示意：**

```
初始：股价0.1港元/股，总股本100亿股，市值10亿港元
↓
第1步：10合1（合股）
股价变为1港元/股，总股本变为10亿股，市值不变（理论上）

↓
第2步：大规模配股
向特定机构配售30亿股新股，每股0.8港元（折价20%）
募集资金2.4亿港元
总股本变为40亿股（稀释75%）

↓
结果：
- 新股东：以0.8港元/股成本买入
- 原有小股东：持股被稀释75%，但手上股价从1港元跌至约0.4港元（市场消化稀释）
- 大股东：同时认购部分新股，维持控制权比例，且手上有募得的2.4亿港元现金
- 小股东：财富几乎清零

↓
第3步：重复循环（数年内可能操作3-5次）
```

### 3.2 资产注入骗局

**典型流程：**
1. 大股东宣布将其私人持有的"优质资产"注入上市公司
2. 估值由大股东控制的评估机构给出虚高价格
3. 上市公司以"高价"收购，支付现金或发行新股
4. 实际资产价值远低于收购价 → 上市公司受损，大股东套现

### 3.3 假业绩+配股套现

1. 公司公布亮眼业绩（实为虚构）
2. 股价拉升
3. 大股东或关联方以高价减持/配股
4. 数月后，公司宣布核数师更换，或发出盈警
5. 股价暴跌，散户承受损失

## 4. 量化筛查方法

用以下条件做初步筛查，排除高风险标的：

### 4.1 必要条件（满足任一则回避）

```
□ 过去5年配股次数 > 3次
□ 最近一次配股折价 > 15%
□ 核数师不是Big4或知名中型所
□ 市值 < 5亿港元
□ 日均成交额 < 500万港元
□ 大股东持股 > 75%（且仍在增持）
□ 有未解除的停牌记录
□ SFC曾发出调查公告（sfc.hk→新闻及公告→监管行动）
□ 过去3年无论营业收入如何，现金流持续为负
```

### 4.2 信用评分参考

**直接查询SFC执法数据库：**
SFC官网→监管行动→历史执法案例，查看该公司或其管理层是否有违规记录。

**STOCKdio / 阿思达克（AAStocks）风险提示：**
部分财经网站对有配股历史的公司会标注警示。

## 5. 壳股投资的特殊风险

部分投资者试图通过买入壳股，押注被借壳收购后股价大涨。

**风险点：**
1. 壳价值是大股东的，不是小股东的（借壳时大股东以高价出售控股权，对小股东无直接好处）
2. 借壳过程通常伴随大规模供股/配股，小股东被稀释
3. 注入的新业务质量参差不齐，借壳成功≠新业务有价值
4. 等待借壳的时间可能数年，资金占用成本高
5. 部分壳股长期停牌，投资者资金彻底冻结

**结论：壳股不是普通投资者的正确猎场。**

## 6. 防范清单（实操）

**买入前必做的5项检查：**

1. **查配股历史：** 在披露易（hkexnews.hk）搜索公司名，看过去5年的通函（Circular）和公告，统计配股次数和折价幅度

2. **查核数师：** 看年报最后的"独立核数师报告"，确认核数师是Big4或知名中型所

3. **查大股东持股：** 查最新权益披露，确认大股东持股比例及近期变动趋势

4. **查SFC执法：** SFC官网搜索公司名或高管名字，看有无监管行动记录

5. **查现金流：** 看近3年现金流量表，确认经营现金流是否持续正数且与利润匹配

## 关键认知清单

- [ ] 仙股=流动性陷阱+老千股高危区，新手只看5亿市值以上股票
- [ ] 合股+配股循环是最经典的老千手法，出现2次以上配股即警惕
- [ ] 现金多但仍融资=账面现金可能是假的
- [ ] 核数师是无名小所=直接回避，无需进一步研究
- [ ] 壳股套利是专业游戏，散户没有信息优势
- [ ] 买入前5项检查（配股历史、核数师、大股东持股、SFC记录、现金流）缺一不可
