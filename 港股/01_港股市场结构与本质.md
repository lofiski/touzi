# 第01章：港股市场结构与本质

---

## 1. 港股是什么性质的市场

香港股票市场是**离岸市场（Offshore Market）**，不是内地A股那样的在岸市场。核心含义：

- **资金自由进出**：无外汇管制，美元/港元/人民币可自由兑换汇出
- **监管主体是香港**：SFC（证监会）、HKEx（港交所），不受中国证监会直接管辖
- **定价权由国际资金决定**：与全球风险偏好高度挂钩，而非内地流动性

这造成一个根本性特征：**同一家公司，A股和H股可以出现30%-80%的价格差异（AH溢价），且长期不收敛**。因为两个市场的资金池完全隔离。

---

## 2. 港股的三方资金结构

港股定价权由三类资金博弈决定，理解这个是看懂港股走势的基础。

### 2.1 外资（Global Institutional Money）

**来源：** 欧美养老金、主权基金、对冲基金、共同基金

**行为驱动因素：**
- 美联储利率周期（利率↑→美元资产吸引力↑→从新兴市场撤资）
- 美元指数（DXY↑→新兴市场压力↑）
- 全球风险偏好（VIX↑→外资撤离港股）
- MSCI指数权重变动（权重↑→被动基金强制流入）
- 地缘政治风险（中美关系、制裁名单）

**特点：**
- 持有港股超大盘蓝筹的核心仓位
- 决定港股的估值中枢
- 撤退时流动性急剧下降，跌幅远超预期

**数据追踪：** 港交所每日公布的南北向资金流向、Bloomberg外资持仓变化

### 2.2 南下资金（Southbound via Stock Connect）

**来源：** 内地机构和散户通过沪深港通买入港股

**行为驱动因素：**
- 内地流动性（央行降准/降息→南下增加）
- A股与H股价差（H股折价扩大→南下抄底）
- 政策导向（国家队指引方向）
- 内地经济预期

**特点：**
- 2014年沪港通开通后，对港股影响持续增大
- 偏好高息蓝筹（内银、内险、能源）和科技龙头
- 不能买所有港股——仅限港股通标的（约500只）
- 每日有额度上限（当前：北向520亿/天，南向520亿/天）

**数据追踪：** 港交所每日14:00公布余额，Wind/Bloomberg有历史数据

### 2.3 本地及套利力量

**做市商（Market Makers）：** 主要在衍生品市场，提供窝轮、牛熊证流动性

**套利者（Arbitrageurs）：** 套利AH价差、ADR与港股价差，维持跨市场定价效率

**本地机构：** 香港本地基金、家族办公室，规模相对较小

## 3. 港股的核心结构特征

### 3.1 上市公司构成

截至2026年Q1，港股上市公司约2600家：

| 类型               | 数量（约） | 市值占比 |
| ---------------- | ----- | ---- |
| H股（内地企业，在港上市）    | ~300  | ~45% |
| 红筹股（注册在境外，业务在内地） | ~200  | ~20% |
| 港资/外资企业          | ~500  | ~15% |
| 内地民营企业（非H股）      | ~800  | ~15% |
| 其他               | ~800  | ~5%  |

**实质：港股约80%的市值来自与中国大陆经济高度相关的公司。**

这决定了港股不是一个能完全规避中国风险的市场。

### 3.2 主要指数

| 指数                 | 成分股数量         | 特征            |
| ------------------ | ------------- | ------------- |
| 恒生指数（HSI）          | 82只（2024年扩编后） | 综合蓝筹指数，最主要的基准 |
| 恒生科技指数（HSTECH）     | 30只           | 科技股，波动更大      |
| 恒生国企指数（HSCEI，国企指数） | 50只           | H股+红筹，衍生品重要标的 |
| 恒生中国企业指数（HSCEI）    | 同上            | 国企指数即HSCEI    |
| 恒生综合指数（HSCI）       | ~500只         | 含中小盘，港股通覆盖基础  |

**为什么恒指成分股调整很重要：**
被纳入恒生指数的公司，追踪恒指的ETF和被动基金会强制买入；被剔除则强制卖出。调整日前后可能有明显的价格波动。

### 3.3 港股的估值折价：为什么长期低于A股和美股

港股整体PE长期低于A股和美股，这不是"价值洼地"，而是结构性原因：

**原因1：流动性折价**
机构主导的市场，换手率低，缺乏散户热情炒高估值的机制。

**原因2：地缘政治折价**
外资对中国相关资产要求更高的风险溢价（Risk Premium），体现为更低的估值倍数。

**原因3：监管不确定性折价**
2021年以来，中国监管对多个行业的突然收紧，令外资永久性提高了对港股的折现率。

**原因4：信息不对称折价**
内地公司在港上市，外资分析师覆盖少，信息透明度低于美国公司，要求折价。

**错误理解：** "港股便宜，迟早回到A股的估值水平" → 这不是规律，而是过于乐观的假设。

## 4. 港股与A股、美股的结构性差异

| 维度     | 港股               | A股              | 美股                             |
| ------ | ---------------- | --------------- | ------------------------------ |
| 市场性质   | 离岸，资金自由流动        | 在岸，外汇管制         | 离岸（对外资），资金自由                   |
| 主要监管   | SFC + HKEx       | 中国证监会 + 上交所/深交所 | SEC + FINRA                    |
| 散户占成交量 | ~15-20%          | ~70-80%         | ~15-20%                        |
| 涨跌停机制  | 无                | ±10%（ST±5%）     | 个股无强制停牌（有circuit breaker触发全市场） |
| 交割周期   | T+2              | T+1（含当日卖出）      | T+1（2024年起）                    |
| 做空机制   | 可（指定卖空股票，需借股）    | 极有限（融券池小）       | 自由                             |
| 退市机制   | 宽松，壳股泛滥          | 逐步收紧            | 严格，财务不达标强制退市                   |
| 衍生品    | 发达（窝轮、牛熊证、期权、期货） | 有限              | 非常发达                           |
| 信息语言   | 中英文双语（部分仅中文）     | 中文              | 英文                             |
| 结算货币   | 港元（HKD）          | 人民币（CNY）        | 美元（USD）                        |
| 港股通覆盖  | 约500只可被内地投资者购买   | N/A             | N/A                            |

## 5. 港元联系汇率制度对港股的影响

港元自1983年起与美元挂钩，汇率锁定在 **7.75-7.85 HKD/USD** 区间（联系汇率制度，Linked Exchange Rate System）。

**对股票投资的含义：**

1. **港股本质上是以美元计价的**：对内地人民币投资者，还有人民币兑港元的汇率风险（港元随美元波动）
2. **香港无独立货币政策**：美联储加息→香港必须跟随加息→港股估值承压（折现率↑）
3. **港元汇率危机风险**：历史上曾有对冲基金做空港元（1997-1998年），但联系汇率制度迄今维持
4. **人民币升值对南下资金的影响**：人民币升值→南下资金的港元购买力↑，对港股有边际支撑

## 6. 2026年港股市场现状（快照）

- **总市值：** 约36-38万亿港元（受宏观环境影响，波动较大）
- **日均成交额：** 约1000-1500亿港元（2024年低迷期约700-900亿）
- **南下资金累计净买入：** 约3万亿港元（自2014年沪港通开通以来）
- **恒生指数点位区间：** 2024年低点约14,000点，2025年反弹后约18,000-21,000点区间震荡
- **主要宏观背景：** 美联储降息周期（2024年下半年启动）、中国经济弱复苏、地缘政治持续存在折价

## 关键认知清单

- [ ] 港股=离岸市场，资金可自由进出，与A股完全隔离
- [ ] 定价权：外资（全球风险偏好）+ 南下（内地流动性）+ 本地套利力量
- [ ] 港股低估值是结构性折价，不是简单的"价值洼地"
- [ ] AH溢价长期存在且不必然收敛，是两个独立市场的结果
- [ ] 港元与美元挂钩，美联储政策直接影响港股估值
- [ ] 港股约80%市值与中国经济相关，无法用它来分散中国风险
