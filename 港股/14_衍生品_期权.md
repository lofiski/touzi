# 第14章：衍生品进阶——港股期权

---

## 1. 港股期权概览

### 1.1 港股期权市场结构

港股期权在**香港期货交易所（HKFE）**交易，通过**香港期权结算所（HKCC）**清算。

**与窝轮的根本区别：**

| 维度 | 期权（Options） | 窝轮（Warrants） |
|------|----------------|----------------|
| 发行方 | 市场参与者（买方卖方均为市场） | 投资银行单方面发行 |
| 买方/卖方 | 均可做（买期权/卖期权） | 散户只能买，不能卖空 |
| 标准化 | 标准化合约（港交所规定） | 每只产品条款不同 |
| 清算 | 中央清算（安全） | 发行商信用风险 |
| 流动性 | 视标的而定 | 视做市商报价 |

### 1.2 港股期权的可交易标的

**指数期权：**
- 恒生指数期权（HSI Options）：最活跃，流动性最好
- 国企指数期权（HSCEI Options）

**个股期权（Stock Options）：**
约70-80只个股有期权，包括：
腾讯（00700）、汇丰（00005）、友邦（01299）、中国平安（02318）、美团（03690）、阿里巴巴（09988）、工商银行（01398）等主要蓝筹

**期权合约查询：** HKEX官网期权页面，可查所有可交易期权合约及当前报价

## 2. 期权基础概念

### 2.1 四种基本期权头寸

| 头寸 | 操作 | 权利/义务 | 最大收益 | 最大损失 |
|------|------|----------|---------|---------|
| 买入认购期权（Long Call） | 付权利金，买看涨期权 | 有权按行使价买入 | 无限 | 权利金 |
| 卖出认购期权（Short Call） | 收权利金，卖看涨期权 | 有义务按行使价卖出 | 权利金 | 无限 |
| 买入认沽期权（Long Put） | 付权利金，买看跌期权 | 有权按行使价卖出 | 行使价-0（理论） | 权利金 |
| 卖出认沽期权（Short Put） | 收权利金，卖看跌期权 | 有义务按行使价买入 | 权利金 | 行使价（巨大） |

**新手从买入期权（Long Call/Long Put）开始，最大损失已知（权利金）。**

### 2.2 关键术语

**行使价（Strike Price / Exercise Price）：** 期权合约规定的买卖标的物的价格

**到期日（Expiry Date）：** 港股个股期权通常到期于每个月的最后交易日（第三个星期五前后），指数期权到期时间略有不同

**权利金（Premium）：** 买入期权支付的价格，卖出期权收取的价格

**价内（In-the-money, ITM）：** 
- 认购期权：标的价格 > 行使价
- 认沽期权：标的价格 < 行使价

**价外（Out-of-the-money, OTM）：**
- 认购期权：标的价格 < 行使价
- 认沽期权：标的价格 > 行使价

**价平（At-the-money, ATM）：** 标的价格 ≈ 行使价

## 3. 港股期权合约规格

### 3.1 恒生指数期权（HSI Options）

| 参数 | 数值 |
|------|------|
| 合约乘数 | 每点50港元 |
| 最小变动 | 1点 |
| 到期日 | 每月最后营业日前一个营业日（通常是第三个星期四） |
| 行使方式 | 欧式（只能在到期日行使） |
| 结算 | 现金结算 |
| 结算价 | 到期日上午恒指成分股开市5分钟内成交平均价（HSI开市报价指数） |

**合约价值计算：**
恒指在20,000点，买入1张HSI认购期权（行使价20,000），权利金500点：
- 权利金成本：500 × 50 = 25,000港元
- 若恒指到期时升至21,000点：到期价值 = (21,000 - 20,000) × 50 = 50,000港元
- 净利润：50,000 - 25,000 = 25,000港元（100%回报）

### 3.2 个股期权（Stock Options）合约规格

| 参数 | 通常值 |
|------|--------|
| 合约股数 | 500股/手（视股票而定） |
| 到期日 | 每月最后营业日（美式期权可提前行使） |
| 行使方式 | 美式（可在到期前任何时间行使） |
| 结算 | 实物交割（实际交付股票）或现金结算（视合约） |

**注意：** 个股期权为美式期权，可提前行使，但提前行使通常不划算（放弃了时间价值）。

## 4. Greeks（期权风险指标）

### 4.1 Delta（Δ）

**定义：** 标的价格变动1元，期权价格变动多少元

| 期权类型      | Delta范围 |
| --------- | ------- |
| 认购期权      | 0 到 +1  |
| 认沽期权      | -1 到 0  |
| ATM（价平）期权 | 约±0.5   |
| 深度价内期权    | 接近±1    |
| 深度价外期权    | 接近0     |

**使用场景：**
- 对冲：持有100股股票（Delta=+100），卖出2张Delta=-50的认购期权，总Delta≈0（Delta中性）
- 方向押注：Delta越高，方向性越强

### 4.2 Gamma（Γ）

**定义：** 标的价格变动1元，Delta变动多少

- ATM期权Gamma最大（对标的价格变动最敏感）
- 到期日临近，Gamma急剧增大
- 卖出期权的人面临负Gamma风险（标的大幅波动对卖方不利）

### 4.3 Theta（Θ）

**定义：** 每过一天，期权价格损耗多少（时间值损耗速率）

- 买入期权：Theta为负（每天损失时间价值）
- 卖出期权：Theta为正（每天"赚"时间价值）
- ATM期权Theta绝对值最大
- 到期日临近，Theta急剧增大

### 4.4 Vega（V）

**定义：** 隐含波动率变动1%，期权价格变动多少

- 买入期权：做多波动率（Vega正）
- 卖出期权：做空波动率（Vega负）
- 波动率上升：对期权买方有利
- 波动率下降（IV Crush）：对期权买方不利

### 4.5 Rho（ρ）

**定义：** 利率变动1%，期权价格变动多少

港股期权中Rho影响相对较小，通常在分析中可以次要考虑。

## 5. 常用期权策略

### 5.1 新手适合的策略

**买入认购期权（Long Call）：**
- 看涨标的
- 最大损失：权利金
- 适合：有明确上涨催化剂（如业绩公告、政策出台）

**买入认沽期权（Long Put）：**
- 看跌标的，或为现有股票持仓购买"保险"
- 最大损失：权利金
- 作为保护性用途（Protective Put）：持有100股腾讯+买入认沽期权，限制下行风险

### 5.2 进阶策略（熟悉Greeks后）

**备兑认购期权（Covered Call）：**
- 持有股票 + 卖出认购期权
- 目的：在持股的同时通过收权利金增加收益
- 风险：若股价大涨，超过行使价部分收益受限

**现金担保认沽（Cash-Secured Put）：**
- 卖出认沽期权 + 持有对应资金（若被行使则买入股票）
- 相当于：愿意以（行使价-权利金）的有效成本买入股票
- 适合：想在目标价买入某股票，同时赚取等待期的权利金

**价差策略（Spread）：**
- 牛市认购价差（Bull Call Spread）：买低行使价Call + 卖高行使价Call
- 降低成本，但同时限制最大收益
- 适合：有明确目标价的方向性判断

**跨式（Straddle）：**
- 买入相同行使价和到期日的Call + Put
- 押注标的将大幅波动（但方向不明）
- 适合：业绩公告前，不知涨跌但知道会大幅波动

## 6. 港股期权的特殊注意事项

### 6.1 隐含波动率的港股特性

港股个股期权的隐含波动率通常高于美股同类公司（因为监管风险、地缘政治等不确定性）：

- 腾讯IV：通常30-50%
- 阿里巴巴IV：40-70%（更高，因监管不确定性）
- 美股科技巨头：通常20-35%

高IV意味着期权权利金贵，买方成本高。

### 6.2 流动性问题

港股个股期权的流动性远不如美股期权：
- 买卖差价（Spread）可能很宽（达期权价格的5-20%）
- 部分到期月份和行使价几乎无成交
- 应集中在临近月份（最近1-2个月到期）和ATM行使价

### 6.3 结算风险（个股期权）

港股个股期权以**实物交割**为主，即行使期权需要实际买卖股票，需要确保账户有足够资金或股票。

现金结算方式目前主要适用于指数期权。

## 7. 期权的成本

| 费用 | 金额 |
|------|------|
| 权利金 | 期权定价（主要成本） |
| 交易费（每张合约） | 约3-6港元/张 |
| 结算费 | 约1-3港元/张 |
| 印花税 | 不适用（期权免印花税） |
| 佣金 | 视券商，通常每张合约20-50港元 |

## 关键认知清单

- [ ] 买期权最大损失=权利金，卖期权最大损失理论上无限（卖认购）或极大（卖认沽）
- [ ] 新手只做Long Call/Long Put，不卖期权
- [ ] IV高时买期权贵，考虑策略而非单边买
- [ ] 港股个股期权流动性差，只交易ATM+最近月份
- [ ] Theta是持有期权的确定性损耗，每天"在流逝"
- [ ] 期权行使前确认账户有足够资金/股票（实物交割）
