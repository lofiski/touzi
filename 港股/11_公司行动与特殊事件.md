# 第11章：公司行动与特殊事件

---

## 1. 配股（Placing）

### 1.1 定义

上市公司向特定专业/机构投资者（不向公众散户）发行新股，以募集资金。

### 1.2 折价机制

配股价通常低于市价，折价幅度一般为：
- 蓝筹大公司：3-8%折价
- 中型公司：8-15%折价
- 小公司/老千股：15-40%折价（高折价是警示信号）

### 1.3 对现有股东的影响

**稀释效应（Dilution）：**
- 总股本增加→每股盈利（EPS）下降→理论上股价下跌
- 实际影响取决于：稀释比例、集资用途、市场对管理层的信心

**典型反应：**
- 合理配股（小幅稀释+清晰用途）：股价轻微下跌后恢复
- 频繁大规模配股（老千手法）：股价持续走低，不断摊薄

### 1.4 配股后的价格调整

配股后，股价理论上应调整至**理论除权价（TERP，Theoretical Ex-rights Price）**：

```
TERP = (配股前市值 + 配股所得资金) / 配股后总股本
```

**示例：**
- 配股前：股价10港元，股本10亿股，市值100亿
- 配股：发行1亿新股，配股价8港元，融资8亿
- TERP = (100亿 + 8亿) / 11亿 = 9.82港元

## 2. 供股（Rights Issue）

### 2.1 供股 vs 配股的区别

| 维度 | 配股（Placing） | 供股（Rights Issue） |
|------|----------------|---------------------|
| 认购对象 | 特定机构/专业投资者 | 所有现有股东按比例 |
| 是否可放弃 | 不影响现有股东（只是被稀释） | 现有股东可选择认购或放弃 |
| 价格 | 通常折价市价 | 通常大幅折价（20-50%） |
| 时间 | 较快（数天） | 较慢（数周，需股东审批） |

### 2.2 供股权（Nil-paid Rights）交易

供股宣布后，现有股东获得供股权（Rights）。供股权本身可在市场上买卖（"nil-paid rights"），直至供股截止日。

**供股权的价值（理论）：**
供股权内在价值 = TERP - 供股价

**示例：**
- 供股比例：2供1（每持2股有权再购1股）
- 供股价：4港元，当前市价：8港元
- TERP = (2×8 + 1×4) / 3 = 6.67港元
- 供股权理论价值 = 6.67 - 4 = 2.67港元

### 2.3 供股的选择

| 选择 | 结果 |
|------|------|
| 认购（Subscribe） | 按供股价买入新股，维持持股比例不变 |
| 出售供股权 | 将供股权在市场上卖出，获得部分补偿，但持股比例被稀释 |
| 放弃 | 什么都不做，供股权到期作废，持股比例大幅稀释（最差结果） |

**重要：** 若供股比例很高（如10供9，即每10股有权再买9股），而你放弃参与，你的持股比例和股票价值将被严重稀释。这是老千公司常用手段——用超高比例供股，知道小股东无法跟进，从而达到稀释效果。

## 3. 私有化（Privatisation）

### 3.1 触发条件

大股东（通常控股40-70%）认为公司在港股市场估值长期被低估，选择收购小股东持股，让公司退市。

**动机：**
- 股价长期低于内在价值
- 维持上市地位成本高（合规、披露）
- 准备业务重组，不希望在公开市场操作

### 3.2 私有化类型

**协议安排（Scheme of Arrangement）：**
- 通过法院批准
- 需要75%股东赞成（以股份价值计算）
- 且反对票不超过10%（以股份数量计算）
- 批准后强制所有股东以要约价出售

**全面收购要约（General Offer）：**
- 大股东直接向全体股东发出收购要约
- 若收购后持股超过90%，可强制收购剩余股份（强制收购，Compulsory Acquisition）

### 3.3 私有化要约价格

通常较公告前股价有20-40%溢价，但也有案例溢价仅5-10%（小股东可能拒绝）。

**判断是否接受要约的框架：**
- 要约价 vs 公司内在价值（DCF估算）
- 要约价 vs 历史交易价格（过去12个月均价）
- 同类公司的并购溢价水平
- 大股东的要约意愿（协议安排通过率取决于独立股东投票）

### 3.4 私有化套利策略

**基本策略：** 发现私有化要约后，以低于要约价的市价买入，等待私有化完成，赚取价差。

**风险：**
- 私有化要约被否决（小股东集体反对）→ 股价暴跌回原来水平
- 要约被监管机构调查延迟
- 大股东撤回要约
- 流动性风险（等待期数月）

**历史成功率：** 港股私有化要约一旦提出，最终完成率约80%。被否决的案例相对少见，但存在。

## 4. 分拆上市（Spin-off）

### 4.1 什么是分拆

母公司将旗下某子公司或业务独立上市，母公司股东通常按比例获得子公司股份，或子公司通过IPO向公众发行。

**港股常见分拆类型：**
- **IPO分拆**：子公司独立IPO，母公司可能减持部分持股
- **实物分拆（Spin-off in Specie）**：母公司将子公司股份按比例分配给现有股东

### 4.2 分拆对股价的影响

**分拆宣布后的常见效应：**
- 母公司：通常短期上涨（"解锁价值"）
- 子公司（若为IPO）：价格在IPO时确定

**分析框架（Sum-of-the-parts，SotP）：**
对于集团型公司，通过分拆可以更清晰地对每个业务单独估值：
```
母公司合理价值 = 各子公司分别估值之和 - 母公司运营折价（Conglomerate Discount）
```
若当前股价 < SotP估值，存在套利空间。

## 5. 要约收购（Takeover Bid）

### 5.1 触发条件

第三方试图收购上市公司超过30%的股权，触发强制全面收购要约义务（见第02章）。

### 5.2 对被收购公司股东的影响

- 若要约价有溢价：直接受益
- 若要约价过低：可联合其他小股东拒绝
- 若触发价格战（多个收购方竞标）：要约价可能进一步提升

## 6. 合并（Merger）

### 6.1 港股常见合并类型

- 同一母公司下的子公司合并（常见于国企改革）
- 市场竞争者合并（整合行业）
- 反向合并（借壳，见第09章）

### 6.2 对股东的影响

合并通常需要股东批准（独立股东投票）。合并比率（Exchange Ratio）决定各方股东最终持有的新合并公司股份数量。

## 7. 股息（Dividend）与股份回购（Buyback）

### 7.1 港股股息文化

**派息时间：**
- 中期股息（Interim Dividend）：中期业绩公告时宣布
- 末期股息（Final Dividend）：全年业绩公告时宣布

**关键日期：**
- **除息日（Ex-dividend Date）**：在此日或之后买入，不享受本次股息；此日前一天买入才享受
- **股息登记日（Record Date）**：通常在除息日后2个工作日
- **派息日（Payment Date）**：股息实际到账日

**除息效应：** 除息日，股价理论上下跌股息金额（实际因市场因素会有偏差）。

### 7.2 股份回购

公司用自有资金在市场上买回自己的股票，减少流通股本，提升EPS。

**对股东的正面意义：**
- 表明管理层认为公司被低估
- 提升每股盈利（EPS）和每股净资产（NAV/Share）
- 减少流通股，理论上支撑股价

**回购数据查阅：** 港交所每日公布上市公司回购数据（hkex.com.hk）

**注意：** 老千股也会进行象征性小额回购作为信号，不要单独因回购而买入，需结合整体分析。

## 关键认知清单

- [ ] 供股放弃（什么都不做）是最差选择，必须决策：认购还是卖出供股权
- [ ] 配股折价>15%是警示信号，高折价+频繁配股=老千手法
- [ ] 私有化要约一旦宣布，套利空间存在，但有被否决风险
- [ ] SotP（分部估值求和）是分析集团型公司的核心方法
- [ ] 除息日股价下跌=正常除权，不是利空信号
- [ ] 回购是积极信号，但老千公司也可能象征性操作，不可单独依赖
