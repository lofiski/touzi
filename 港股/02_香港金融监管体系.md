# 第02章：香港金融监管体系

---

## 1. 三大监管机构

### 1.1 香港证券及期货事务监察委员会（SFC）

**性质：** 独立法定机构，负责监管证券及期货市场

**核心职能：**
- 审批证券/期货/资产管理公司牌照（9类受规管活动）
- 调查市场失当行为（内幕交易、市场操纵）
- 审查上市公司收购合并（《收购守则》执行）
- 对港交所上市规则拥有最终否决权

**对投资者的重要性：**
- SFC官网（sfc.hk）可查询任何持牌机构和个人的牌照状态
- 收到可疑荐股/投资推介，在SFC查是否持牌是最基本的验证步骤
- SFC的执法公告是了解港股违规模式的重要资料

### 1.2 香港交易及结算所（HKEx / 港交所，股票代码：0388）

**性质：** 上市公司，同时是香港唯一的证券和期货交易所运营商

**主要子公司：**
- 香港联合交易所（联交所，SEHK）：股票交易
- 香港期货交易所（期交所，HKFE）：期货和期权交易
- 香港中央结算（HKSCC）：结算交收

**上市主板 vs GEM（创业板）：**

| 维度     | 主板（Main Board） | GEM（Growth Enterprise Market） |
| ------ | -------------- | ----------------------------- |
| 盈利要求   | 需要（多种测试可选）     | 无盈利要求                         |
| 市值要求   | 最低5亿港元         | 最低1.5亿港元                      |
| 营业记录   | 3年             | 2年                            |
| 监管力度   | 较强             | 较弱                            |
| 风险     | 较低             | 较高，老千股集中地                     |
| 股票代码位数 | 4位或5位          | 5位（以0开头）                      |

**注意：** GEM原意是为中小企业提供融资平台，但实践中成为部分老千股的温床，投资者须格外谨慎。

### 1.3 香港金融管理局（HKMA）

**性质：** 香港的中央银行功能机构，非独立法定机构（实为财政司辖下）

**核心职能：**
- 维持港元联系汇率制度（7.75-7.85区间）
- 监管银行业（包括持牌银行的证券业务）
- 管理外汇基金（香港的主权财富基金，2024年底约4万亿港元）
- 发行港元

**对股票投资者的直接影响：**
- HKMA维护联系汇率→港元稳定→港股以美元计价的稳定性
- HKMA的银行监管影响汇丰、恒生等港股上市银行的经营环境

## 2. 上市规则体系

### 2.1 主板上市资格测试（选择其一）

**盈利测试（最常见）：**
- 最近3个财政年度合计盈利≥5000万港元
- 最近1个财政年度盈利≥2000万港元
- 前2个财政年度合计盈利≥3000万港元

**市值/收益/现金流测试：**
- 上市时预期市值≥20亿港元
- 最近1个经审计财政年度收益≥5亿港元
- 最近3个财政年度经营业务产生现金流合计≥1亿港元

**市值/收益测试（适合高营收但亏损公司）：**
- 上市时预期市值≥40亿港元
- 最近1个经审计财政年度收益≥5亿港元

### 2.2 特殊上市章节（重要，影响大量科技/生物医药公司）

**第18A章（未有收益的生物科技公司）：**
- 无需盈利，无需收益
- 市值≥15亿港元
- 已进入至少一种核心产品的第二期临床试验
- 标识：股票代码旁显示"B"字样（如09969.HK）

**第18C章（特专科技公司，2023年新增）：**
- 针对人工智能、先进硬件、先进材料、新能源、新食品等五大特专科技行业
- 商业化公司：市值≥60亿港元；未商业化公司：市值≥100亿港元

**第19C章（同股不同权/WVR架构）：**
- 允许创始人持有超级投票权股份（如腾讯、美团的架构）
- 投票权比例可达10:1甚至更高

**第二上市（Secondary Listing）：**
- 已在纽交所/纳斯达克/伦交所等认可交易所主要上市
- 可豁免部分港交所规定
- 代表公司：阿里巴巴、百度、京东（通过二次上市回港）

**双重主要上市（Dual Primary Listing）：**
- 与第二上市不同，需同时满足两个交易所的全套规定
- 不能获得豁免，但可被纳入恒生指数和港股通

## 3. 信息披露制度

### 3.1 强制披露要求

| 文件类型   | 频率     | 截止时间                  |
| ------ | ------ | --------------------- |
| 年度业绩公告 | 年度     | 财政年度结束后4个月内           |
| 中期业绩公告 | 半年度    | 期末后2个月内（主板），3个月内（GEM） |
| 季度业务更新 | 部分公司需要 | 视乎个别要求                |
| 内幕消息公告 | 即时     | 知悉后尽快，通常当日            |
| 主要交易   | 按规模分类  | 达到一定比例门槛须公告甚至股东批准     |

### 3.2 披露易（HKExnews）

**网址：** hkexnews.hk

所有上市公司的公告、年报、通函等均在此发布，免费。

**常用功能：**
- 搜索特定公司的所有历史公告
- 设置公司公告的电子邮件提醒
- 查看股东权益披露（大股东持仓变动）

### 3.3 主要/须予披露交易分类

公司进行收购/出售资产时，按交易规模与公司资产/利润的比率（percentage ratio）分类：

| 类别       | 比率门槛     | 要求          |
| -------- | -------- | ----------- |
| 股东特别大会交易 | ≥25%     | 公告 + 独立股东批准 |
| 主要交易     | 25%-100% | 公告 + 股东批准   |
| 须予披露交易   | 5%-25%   | 公告（无需股东批准）  |
| 一般情况     | <5%      | 无强制披露       |

## 4. 收购合并规则（《收购守则》）

### 4.1 强制要约门槛

任何人通过购买股份，持股比例达到或超过 **30%**，必须向全体股东发出强制全面收购要约（Mandatory General Offer），收购价不低于过去6个月的最高购入价。

**对投资者的意义：**
- 发现某股东持股逼近30%，可能是私有化前兆
- 私有化要约价通常有溢价，是特殊投资机会（但也有风险）

### 4.2 私有化（Privatisation）流程

1. 大股东或收购方发出要约
2. 独立财务顾问出具公平意见
3. 独立股东投票（通常需≥75%赞成，且反对票不超过10%）
4. 法院批准（计划安排方式）
5. 撤销上市地位，退市

## 5. 持牌机构与投资者保护

### 5.1 九类受规管活动

| 类型 | 活动 |
|------|------|
| 第1类 | 证券交易 |
| 第2类 | 期货合约交易 |
| 第3类 | 杠杆式外汇交易 |
| 第4类 | 就证券提供意见 |
| 5类 | 就期货合约提供意见 |
| 第6类 | 就机构融资提供意见 |
| 第7类 | 提供自动化交易服务 |
| 第8类 | 提供证券保证金融资 |
| 第9类 | 提供资产管理 |

**验证方法：** SFC官网→「监管人员资料搜寻器」，输入公司或个人名称，查看持牌状态和牌照类型。

### 5.2 投资者赔偿基金

**由来：** 针对持牌交易商倒闭导致的客户损失

**赔偿上限：** 每名受害客户最多 **50万港元**

**注意：** 仅覆盖持牌中介人倒闭的损失，不覆盖投资亏损本身。

## 关键认知清单

- [ ] SFC负责监管，港交所负责运营，HKMA负责货币和银行——三者职能不重叠
- [ ] GEM创业板高风险，新手尽量不碰
- [ ] 18A章（生物医药）、18C章（特专科技）公司无盈利要求，估值逻辑与普通公司完全不同
- [ ] 所有公告在hkexnews.hk免费查阅，这是做研究的基础数据源
- [ ] 大股东持股达30%触发强制收购要约——是监察私有化机会的信号
- [ ] 任何向你推介投资的人，都应先在SFC查证其持牌状态
