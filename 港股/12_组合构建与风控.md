## 1. 5万港币的资金现实

### 1.1 成本结构影响

以5万港元为基础，每次买卖的成本率：

| 买卖各1万港元 | 买卖各5万港元 |
|-------------|-------------|
| 印花税：20港元（买+卖各10元） | 印花税：100港元（买+卖各50元） |
| 杂费：约12港元 | 杂费：约40港元 |
| 合计：约32港元（0.32%） | 合计：约140港元（0.28%） |
| 若免佣：0.32% | 若免佣：0.28% |

**结论：**
- 5万港元若分散成5只股，每只1万港元，单只市值太小
- 每次买卖成本约0.3%，一来一回约0.6%
- 如果你买卖频率高，成本积累相当可观

### 1.2 每手门槛的约束

| 股票 | 参考价格 | 每手股数 | 1手成本 |
|------|---------|---------|--------|
| 腾讯（00700） | ~350港元 | 100股 | 35,000港元 |
| 阿里巴巴（09988） | ~75港元 | 100股 | 7,500港元 |
| 中国平安（02318） | ~40港元 | 500股 | 20,000港元 |
| 汇丰控股（00005） | ~65港元 | 400股 | 26,000港元 |
| 美团（03690） | ~110港元 | 100股 | 11,000港元 |

*价格为撰写时约参考，实际以市价为准*

**腾讯一手就需要35,000港元，5万港元只够买1手腾讯+少量其他。**

### 1.3 5万港元的建议持仓数量

**2-3只股票为宜。**

- 持仓过多（>5只）：每只仓位过小，跟踪成本高，实质上是伪分散
- 持仓过少（1只）：单股风险过高，一旦个股出问题影响巨大
- 2-3只：可以深度研究每只，同时保持一定分散

## 2. 仓位管理框架

### 2.1 固定比例模型（新手推荐）

将资金分为三层：

| 层级 | 比例 | 用途 |
|------|------|------|
| 核心仓位 | 60-70% | 已深度研究、确信度高的标的，长期持有 |
| 卫星仓位 | 20-30% | 短期机会、打新、事件驱动，动态调整 |
| 现金储备 | 10-20% | 随时应对机会或紧急情况，不要满仓 |

**5万港元示例分配：**
- 核心仓：35,000港元（1-2只股票）
- 卫星仓：10,000港元（打新孖展或机会性持仓）
- 现金：5,000港元

### 2.2 单只股票最大仓位限制

- 新手期：单只股票不超过总资金40%
- 熟悉后：可适当提高，但建议不超过60%
- 特殊情况（如打新）：临时100%认购，中签后立即决策

### 2.3 加仓规则

**不要在亏损时摊平（Dollar-Cost Averaging in Loss）：**

摊平适用的前提：你当初的逻辑仍然成立。如果股价下跌的原因是公司基本面变化（而非市场情绪波动），摊平只会加大亏损。

**正确的加仓时机：**
- 股价下跌是市场整体原因（指数跌，个股跟跌）→ 可考虑小幅加仓
- 公司发布正面消息，价格上涨方向确认 → 可考虑追加
- 财报验证逻辑 → 加仓

## 3. 止损框架

### 3.1 为什么港股特别需要止损

- 无涨跌停，极端情况股价可以单日跌70-90%
- 老千股和流动性风险可能让止损单无法执行（无买盘）
- 监管事件（如某个行业突然被整治）可以让行业内所有股票同时崩塌

### 3.2 止损方式

**价格止损（固定幅度）：**
买入后，跌超过X%触发止损。

| 投资类型 | 建议止损幅度 |
|---------|------------|
| 蓝筹股、防御型 | -15% 至 -20% |
| 中型成长股 | -20% 至 -25% |
| 小盘/事件驱动 | -10% 至 -15%（更严格，因流动性风险高） |

**技术止损（跌破关键位）：**
跌破50日均线、或跌破重要支撑位，触发止损。

**逻辑止损（最重要）：**
当初买入的逻辑已不成立（如：押注的新产品发布失败；押注的政策落地未如期），不管盈亏立即止损。

### 3.3 止损的执行纪律

**止损前必须回答的问题：**
1. 导致下跌的原因是什么？
2. 这个原因是否改变了我的投资逻辑？
3. 如果我现在才知道这个信息，我还会买入吗？

如果第3题的答案是"不会"，立即止损。

## 4. 风险管理的量化框架

### 4.1 最大可承受亏损（MAL）

**个人层面：** 确认你账户总资金亏损多少，你的生活不受影响：

```
MAL = min(可接受的绝对亏损额, 总资金 × 30%)
```

对5万港元账户：
- 如果MAL = 15,000港元（30%），每只股票最大风险敞口约5,000-7,500港元

### 4.2 凯利公式（仓位优化参考）

**Kelly Criterion：**
f* = (p × b - (1-p)) / b

其中：
- f* = 应押注的资金比例
- p = 胜率（成功概率）
- b = 盈亏比（盈利/亏损的比率）

**示例：**
- 胜率 p = 60%
- 盈亏比 b = 2（赚2元 vs 亏1元）
- f* = (0.6 × 2 - 0.4) / 2 = 0.4 → 应押注总资金的40%

**实践中：** 通常使用1/2 Kelly或1/4 Kelly（半凯利），因为对胜率和盈亏比的估计本身存在误差，全凯利在估计错误时波动极大。

### 4.3 相关性控制

尽量持有相关性较低的股票，避免集中风险：

**高相关性（不好）：** 同时持有多只内地银行股（走势高度相关，宏观风险一旦来袭全体下跌）

**低相关性（更好）：** 持有一只内地银行股 + 一只科技股 + 现金，三类资产在不同宏观环境下表现差异大

## 5. 港股特有的风控注意事项

### 5.1 停牌风险

港股公司停牌（Suspension of Trading）非常常见，且停牌期可能极长（数月至数年）。

**停牌常见原因：**
- 重大交易或收购（需要披露）：通常较短，数天至数周
- 财务问题（无法按时发布财报）：可能数月至数年
- 监管调查：时间不定

**风控措施：**
- 持仓前看公司近年是否有停牌记录（hkexnews.hk可查）
- 一旦所持股票停牌，等待官方公告，不要恐慌，也不能买卖（无法交易）
- 如果停牌超过6个月且无明确复牌时间表，准备最坏打算

### 5.2 货币风险

持有港股 = 持有港元资产（港元与美元挂钩）

对人民币投资者：
- 人民币升值时，港元资产换回人民币有汇损
- 人民币贬值时，港元资产换回人民币有汇益

5万港元约合人民币45,000-47,000元（视汇率），汇率波动约±3-5%可带来约1,400-2,350元的汇率盈亏，在5万港元规模下不算小。

### 5.3 流动性风险

小盘股和仙股可能无买盘，紧急情况下无法卖出。

**实操防范：**
- 只持有日均成交额>500万港元的股票（建议新手>1000万港元）
- 不持有市值<10亿港元的股票（建议新手>30亿港元）

每次交易必须记录：


### 6.2 月度复盘清单

```
□ 本月盈亏（绝对额和%）
□ 与恒生指数对比（Alpha是多少）
□ 每笔交易复盘：哪些判断对，哪些错
□ 止损是否执行（没执行的原因）
□ 持仓逻辑是否仍然成立
□ 下个月的操作计划
```
