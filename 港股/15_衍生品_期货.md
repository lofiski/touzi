## 2. 恒生指数期货（HSI Futures）

### 2.1 合约规格（最重要）

| 参数 | 数值 |
|------|------|
| **合约乘数** | 每点50港元 |
| **最小变动单位** | 1点（= 50港元） |
| **到期月份** | 当月、下月、3月周期中的最近两个季月（共4个到期月） |
| **最后交易日** | 每月倒数第2个营业日 |
| **最后结算日** | 到期日后1个营业日 |
| **结算价格** | 到期日香港时间08:45-09:15恒指开市期间的平均指数值（AHSI） |
| **交易时间** | 09:15-12:00, 13:00-16:30（+夜市16:30-翌日01:00） |
| **初始保证金** | 约100,000-120,000港元/张（视时期HKFE设定） |
| **维持保证金** | 约80,000-100,000港元/张 |

**合约价值计算：**
恒指在20,000点时，1张HSI期货合约价值 = 20,000 × 50 = 1,000,000港元（100万港元）

这意味着：**100万港元的恒指敞口，只需约10-12万港元保证金（约10倍杠杆）。**

### 2.2 小型恒生指数期货（Mini-HSI，MHI）

**合约乘数：每点10港元**（HSI的五分之一）

| 参数 | 数值 |
|------|------|
| 合约价值（20,000点时） | 200,000港元 |
| 初始保证金 | 约20,000-25,000港元/张 |
| 最小变动 | 1点（= 10港元） |

**MHI适合的投资者：** 资金量相对较小的散户，用于短期对冲或方向性交易。

## 3. 期货的核心机制

### 3.1 逐日盯市（Mark-to-Market / Daily Settlement）

期货与股票的最大不同：**每天结算盈亏，账户每日更新。**

- 若持有多头（看涨）且当日恒指上涨500点：账户自动增加500×50=25,000港元
- 若持有多头且当日恒指下跌500点：账户自动扣除25,000港元

### 3.2 追加保证金（Margin Call）

当账户资金低于**维持保证金**水平，经纪商发出追加保证金通知（Margin Call）。

**若未能在规定时间内补足保证金，经纪商有权强制平仓（Stop Out）。**

**实操原则：** 永远保持账户余额远高于维持保证金水平，为市场波动留出缓冲。建议：账户总资金 = 保证金 × 2 以上。

### 3.3 基差（Basis）

**基差 = 期货价格 - 现货价格（恒生指数现价）**

通常情况：
- 期货价格 > 现货价格（正基差，正向市场）：反映持仓成本（利率-股息）
- 期货价格 < 现货价格（负基差，逆向市场，Backwardation）：市场恐慌或预期下跌

**基差的实际意义：**
若正基差过大，套利者会买现货卖期货，将基差压缩回合理水平。若负基差扩大，暗示市场对未来悲观。

### 3.4 展仓（Rolling Over）

期货合约有到期日，若想持续持有敞口，需在到期前**将当月合约平仓，同时买入下月合约（展仓）**。

**展仓成本：**
= 下月合约价格 - 当月合约价格

正向市场中，展仓有额外成本（持仓越久，累积成本越高）。

## 4. 期货的使用场景

### 4.1 对冲（Hedging）

**场景：** 持有大量港股蓝筹组合，担心短期市场下跌。

**操作：** 卖出恒指期货（做空），建立空头对冲。

**对冲数量计算：**

```
所需期货张数 = 股票组合市值 × Beta / (恒指期货合约价值)
```

**示例：**
- 股票组合市值：100万港元，Beta=0.9
- 恒指当前：20,000点，合约价值：20,000×50=100万港元
- 所需张数 = 100万 × 0.9 / 100万 = 0.9张 ≈ 1张

卖出1张恒指期货，可对冲约90%的市场风险。

**注意：** 对冲不是免费的，若市场上涨，期货空头亏损，但股票盈利。对冲的目的是减少波动，不是提高收益。

### 4.2 方向性交易（Directional Trading）

纯粹押注指数方向，利用期货杠杆放大收益（和风险）。

**这是港股期货最常见的散户用法，也是风险最高的用法。**

### 4.3 套利（Arbitrage）

**指数套利：** 期货基差异常时，做多一边做空另一边，等待基差收敛。
**日历套利（Calendar Spread）：** 做多近月合约，做空远月合约，押注月间价差变化。
**跨市场套利：** 恒指期货 vs 对应ETF（盈富基金02800）价差套利。

这些策略需要专业系统和极低交易成本，散户通常不具备优势。

## 5. 恒指期货夜市（After-hours Trading）

**时间：** 每日16:30-01:00（第二天凌晨）

**重要性：**
- 可追踪美股走势对香港市场的影响
- 美国经济数据公布（如非农就业、CPI等）通常在港股收市后发布，夜市可以即时反应
- 夜市成交量较白市低，波动可能更大

**夜市持仓的额外风险：** 流动性低，若出现极端行情，买卖差价急剧扩大。

## 6. 股票期货（Individual Stock Futures）

### 6.1 可交易标的

约40-50只港股主要蓝筹有对应股票期货，包括：腾讯、汇丰、友邦、中国平安、美团、阿里巴巴等。

### 6.2 与期权的比较

| 维度 | 股票期货 | 个股期权 |
|------|---------|---------|
| 方向性 | 双向（多/空），对称 | 非对称（买方权利，卖方义务） |
| 时间价值 | 无（类似持仓成本） | 有（Theta消耗） |
| 杠杆 | 固定杠杆比例 | 通过选择Delta管理 |
| 复杂度 | 较低 | 较高（Greeks管理） |

## 7. 期货风控要点

### 7.1 常见错误

| 错误 | 后果 |
|------|------|
| 过度杠杆（持张数超过资金承受能力） | 一次大波动引发Margin Call，强制平仓 |
| 持仓跨越重大事件（美联储议息、财报季等）不设止损 | 隔夜跳空，损失超出预期 |
| 将期货当长线持有 | 展仓成本累积，基差不利 |
| 夜市低流动性大仓操作 | 难以平仓，实际价格偏差大 |

### 7.2 止损设置

期货的止损必须更严格，因为杠杆放大波动：

**建议最大单笔亏损：不超过总交易资金的2-3%**

以100万港元账户为例：
- 单笔最大亏损 = 100万 × 2% = 20,000港元
- 20,000港元 ÷ 50港元/点 = 400点 → 止损设在买入价-400点（多头）

## 8. A50期货（新华富时中国A50指数期货）

### 8.1 基本信息

| 参数 | 数值 |
|------|------|
| 交易所 | 新加坡交易所（SGX） |
| 标的 | 新华富时中国A50指数（50只A股龙头）|
| 合约货币 | 美元 |
| 合约乘数 | 每点1美元（或人民币，视合约） |
| 交易时间 | 覆盖亚洲全天及部分夜市 |

**为什么港股投资者要关注A50期货：**
- A50期货代表A股开盘前的情绪，是港股蓝筹（尤其是内地企业H股）的早期预警指标
- A50夜盘大跌→暗示次日港股中资板块可能承压
- A50是外资交易A股的主要替代工具，其方向代表外资对中国股市的短期判断
