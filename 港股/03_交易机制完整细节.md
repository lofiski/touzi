# 第03章：港股交易机制完整细节

---

## 1. 交易时间

| 阶段         | 时间（香港时间）          | 说明           |
| ---------- | ----------------- | ------------ |
| 开市前时段（竞价）  | 09:00-09:30       | 只能输入竞价盘，不能撤单 |
| 持续交易时段（上午） | 09:30-12:00       | 正常交易         |
| 午市休市       | 12:00-13:00       | 不能交易         |
| 持续交易时段（下午） | 13:00-16:00       | 正常交易         |
| 收市竞价时段     | 16:00-16:08/16:10 | 随机结束，防止操纵    |

**与A股对比：**
- A股：09:30-11:30，13:00-15:00（14:57分停止申报）
- 港股午休1小时，全天交易时间5.5小时 vs A股4小时

**收市竞价时段的特殊性：**
收市竞价（Closing Auction Session）在16:00-16:08到16:10之间随机结束（具体时间不可预测），防止有人在最后一秒操控收市价。这段时间内，只能输入竞价盘，成交价为等待撮合的单一价格。

## 2. T+2 结算制度

港股采用 **T+2** 结算：今天买入，后天（第2个交易日）资金和股票才正式交割。

**实际操作含义：**
- 你可以**当天卖出已买入但未结算的股票**（因此实际效果类似T+0）
- 但**卖出所得资金需等T+2才能提走或再用**（部分券商允许提前使用，视条款而定）
- 如果T+0当天买入又卖出，从账面看是可以的，但风险是买入当天需要足够资金或额度

**与A股对比：**
- A股T+1：今天买，明天才能卖（当天买当天不能卖）
- 港股理论上可以当天买当天卖（效果类似T+0），但资金结算是T+2

## 3. 无涨跌停机制

港股没有涨跌停板，任何股票在任何交易日可以涨跌任意幅度。

**历史极端案例（说明风险量级）：**
- 某公司发布利润警告，当日暴跌70-90%
- 老千股在配股/合股操作后，一天内蒸发80%以上市值
- 正面：好消息也可以一天翻倍（但机构早已知道，散户通常是高位接盘）

**有限制的机制：**
**波动性控制机制（VCM，Volatility Control Mechanism）：** 当股价5分钟内偏离参考价±10%，暂停交易5分钟（冷却期）。适用于恒生指数和国企指数成分股及部分ETF，**不适用于所有股票**，也不限制最终涨跌幅度。

## 4. 每手（Lot Size）制度

港股的最小交易单位是"手"（Lot），不同股票每手股数不同，是港股特有机制。

**典型每手股数：**

| 每手股数 | 适用场景 |
|---------|---------|
| 100股/手 | 大部分蓝筹股（腾讯、汇丰、友邦等） |
| 200股/手 | 部分股票 |
| 500股/手 | 中价位股票 |
| 1000股/手 | 低价股 |
| 2000-10000股/手 | 仙股、低价股 |

**实际影响：**
- 购买腾讯（约350港元/股，每手100股）：最小买入金额约35,000港元
- 购买某仙股（0.05港元/股，每手10,000股）：最小买入500港元

**为什么重要：**
1. 决定了买一手的最低资金门槛
2. 对小资金投资者，高价股可能根本买不起"一手"
3. 部分券商提供"碎股"（不足一手）交易，但买卖价差较大

## 5. 双柜台（Dual Counter）制度

2023年港交所正式推出双柜台模式，允许部分股票同时有**港元柜台**和**人民币柜台**交易。

**机制：**
- 同一家公司、同一只股票，分别有港元和人民币两个交易代码
- 投资者可用港元或人民币买卖
- 做市商负责维持两个柜台之间的价差合理

**2026年现有双柜台股票（约）：** 腾讯、阿里巴巴、汇丰、友邦、美团等约100只

**主要代码区分：**
- 港元柜台：原有代码（如00700 腾讯控股）
- 人民币柜台：在原代码前加"8"（如80700 腾讯控股人民币）

**是否需要用人民币柜台：**
对大多数港元账户投资者，没有必要。人民币柜台主要方便持有离岸人民币（CNH）的投资者，避免汇兑损失。

## 6. 暗盘（Grey Market）交易

暗盘是港股特有的**盘后交易市场**，主要用于新股（IPO）挂牌前一天的交易。

**时间：** 通常在 IPO 前一天的 16:00-18:00

**机制：**
- 仅部分券商提供暗盘交易（富途、老虎、辉立等互联网券商通常提供）
- 报价基于场外询价（OTC），由做市商提供买卖盘
- 流动性远低于正常交易时段
- 价格可作为新股上市首日走势的参考

**注意：**
- 暗盘成交价不计入正式收市价
- 暗盘价格与正式开盘价可能有较大差异
- 暗盘流动性差，买卖价差（Spread）可能很宽

## 7. 沽空（Short Selling）机制

### 7.1 什么是沽空

沽空（Short Selling）：先借入股票卖出，后买回还给出借人，从股价下跌中获利。

**港股沽空条件：**
- 只有**指定卖空证券清单**上的股票才能沽空（约900只，主要是蓝筹和流动性好的股票）
- 必须为"有担保沽空"（Covered Short Selling）：下单时已借到股票
- 裸卖空（Naked Short Selling）在港股违法

### 7.2 沽空比率（Short Selling Ratio）

**计算：** 沽空成交额 / 当日总成交额

**参考意义：**
- 某股沽空比率持续高（>5-10%）：机构看空信号
- 突然大幅升高：可能是对冲基金建立做空头寸
- 沽空比率过高后若股价不跌，可能引发"轧空"（Short Squeeze）

**数据来源：** 港交所每日公布（hkex.com.hk），或通过Wind/Bloomberg查阅历史数据

### 7.3 散户如何做空（理论上）

通过券商的**孖展（保证金融资）**账户借入股票进行沽空，但：
- 需要开立保证金账户
- 借股成本（利率）高
- 对时间有压力（股票可能被召回）
- 新手不建议

## 8. 订单类型

### 8.1 限价盘（Limit Order）

指定价格或更好的价格成交。若市价未达到指定价格，订单不成交，挂在队列中等待。

**港股最常用订单类型**，因为无涨跌停，市价盘在流动性差的股票上风险极大。

### 8.2 市价盘（At-auction Order / Market Order）

以当前市场最优价格立即成交。在港股：
- 持续交易时段的市价盘：以当时最优对手盘价格成交
- 竞价时段的竞价市价盘：参与开盘/收盘价格竞价

**风险：** 流动性差的股票，市价盘可能以极不利的价格成交（价差吃亏）。

### 8.3 增强限价盘（Enhanced Limit Order）

允许在限价以内，同时与多个价位的卖盘/买盘成交（最多10个价格档次）。一般主板交易用不到。

### 8.4 特别限价盘（Special Limit Order）

允许限价盘在下盘瞬间，与不超过10个价格档次的对手盘成交。此后未成交部分变成普通限价盘。

**实际操作建议：**
- 绝大多数情况：用限价盘
- 急需成交：用限价盘但设稍宽的价格，而非市价盘
- 仙股/低流动性股票：永远用限价盘，且要检查当前买卖盘深度

## 9. 费用完整拆解

### 9.1 交易费用构成

以通过互联网券商（如富途）买卖10万港元股票为例：

| 费用项目 | 收取方 | 金额/比率 | 10万港元示例 |
|---------|--------|----------|-------------|
| 佣金 | 券商 | 0（部分券商免佣）至0.05% | 0-50港元 |
| 印花税 | 香港政府 | 买卖双方各0.1% | 各100港元 |
| 交易征费 | SFC | 0.0027% | 2.7港元 |
| 交易费 | HKEx | 0.005% | 5港元 |
| 结算费 | HKSCC | 0.002%（最低2港元/最高100港元）| 20港元 |
| 股票组合费 | 港交所 | 0.002%（最低30港元）| 20港元（实取30港元） |

**合计（10万港元买入+10万港元卖出）：**
- 印花税：100+100=200港元（**最大单项成本**）
- 其他杂费合计约：~60港元
- 佣金（若免佣）：0港元
- **总成本约0.26%（单次买入）或0.52%（一买一卖）**

**关键点：印花税是港股交易最大的成本，且按双边计费（买和卖各0.1%）。**

### 9.2 历史印花税变化

| 期间 | 印花税率（单边） |
|------|----------------|
| 1993-2021年4月 | 0.1% |
| 2021年8月起 | 0.13%（曾上调，后来调回） |
| 2024年11月起 | 恢复至0.1% |

*注：2021年的印花税上调是港股成交量大幅萎缩的原因之一，2024年底恢复原税率是政府提振市场的举措。*

### 9.3 其他可能费用

| 费用 | 说明 |
|------|------|
| 过户费 | 将股票从券商账户实物过户时收取，通常2-5港元/手 |
| 托管费 | 部分传统券商收取，互联网券商通常免收 |
| 汇兑费 | 若需将港元换成其他货币，收汇兑差价 |
| 孖展利息 | 使用保证金融资时按日计息，年化通常5-8% |
| 美国预扣税 | 持有在港上市的美国ADR，股息被预扣30% |

## 10. 港股通 vs 直接开港股账户对比

### 10.1 港股通（南向）

**什么是港股通：** 内地投资者通过在内地开立的证券账户，经港股通机制买卖指定港股。

**前提条件：**
- 需在具有港股通资格的内地券商开户
- 证券账户+资金账户中沪深市场的资产合计≥**50万人民币**（目前规定）

**可买标的限制：**
- 仅限港股通股票（约480-500只），以恒生综合大、中、小型指数成分股为基础
- 不包括GEM股票（创业板）
- 不包括18A章未盈利生物医药股（**关键限制**）

**交易货币：**
- 以人民币换汇后，以港元成交
- 换汇由中国结算自动处理

**税务：**
- 港股通买卖的股息：H股收取20%所得税（自动代扣）；非H股不征
- 资本利得：目前暂免征税

**额度：**
- 南向（内地→港股）：每日额度520亿人民币
- 实际使用率通常远低于上限，极少出现额度用完情况

### 10.2 直接开香港券商账户

**前提条件：**
- 年满18岁，有效身份证件
- 无需50万资产门槛
- 可在网上完成（部分券商）

**优势：**
- 可买全部港股（包括GEM、18A章生物医药等）
- 可参与打新（港股通不能参与IPO认购）
- 可进行暗盘交易
- 可使用港元直接投资，无汇兑风险
- 可参与权证、牛熊证、期权、期货（视券商而定）

**劣势：**
- 需要港元或外币资金划入
- 资金汇款有汇兑成本
- 需了解香港税务和账户管理

### 10.3 综合对比

| 维度 | 港股通 | 直接香港账户 |
|------|--------|------------|
| 资产门槛 | 50万人民币 | 无（视券商而定） |
| 可买股票范围 | ~500只 | 全部港股 |
| IPO打新 | 不可以 | 可以 |
| 暗盘交易 | 不可以 | 可以（视券商） |
| 衍生品（窝轮等） | 不可以 | 可以（视券商） |
| 货币 | 人民币（自动换汇） | 港元/美元等 |
| 股息税（H股） | 20%代扣 | 无预扣（需自申报） |
| 开户便利性 | 便利（内地券商） | 较便利（互联网券商） |
| 资金安全 | 受内地法律保障 | 受香港法律保障（≤50万赔偿基金） |

## 关键认知清单

- [ ] 港股实质T+0（可当天买卖），但资金结算T+2
- [ ] 每手股数因股而异，影响最低买入金额
- [ ] 印花税0.1%是最大成本项，双边收取，一来一回共0.2%
- [ ] 沽空只限指定股票清单，且必须有担保，裸卖空违法
- [ ] 港股通可买范围约500只，缺失IPO打新和衍生品功能
- [ ] 无涨跌停，流动性差的股票必须用限价盘
- [ ] 暗盘仅适用于IPO前一天，是了解新股情绪的参考，不宜重仓
