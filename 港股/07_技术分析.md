# 第07章：技术分析在港股的应用与局限

---

## 1. 技术分析在港股的有效性前提

技术分析基于"价格已包含所有信息"（弱式有效市场假说），通过历史价格和成交量预测未来走势。

**港股特殊性导致技术分析有额外局限：**
1. 仙股和小盘股被庄家/老千控制，K线是人为制造的，技术形态无效
2. 中资科技股受政策突变影响，无论技术形态多好，一个监管政策可以让所有支撑线失效
3. 港股流动性不均匀，成交量信号噪音大
4. 大量港股日成交额<1000万港元，机构无法大量进出，技术信号更难产生自我实现的预言效果

**技术分析在港股最有效的范围：**
- 恒生指数本身（流动性充足，机构参与度高）
- 50亿港元以上市值、日成交额超过1亿港元的股票
- 判断大势方向（趋势）比判断个股精确点位更有用

## 2. K线基础

### 2.1 单根K线

```
        │  ← 上影线（高点到收盘/开盘的较高者）
        ●
       ███  ← 实体（开盘价到收盘价）
        ●
        │  ← 下影线
```

- **阳线（白/绿）**：收盘 > 开盘（港股习惯用红色表示上涨，与A股相同，与美股相反）
- **阴线（黑/红）**：收盘 < 开盘

**重要单K形态：**

| 形态 | 特征 | 信号含义 |
|------|------|---------|
| 锤子线（Hammer） | 小实体+长下影线，出现在下跌末端 | 潜在反转向上 |
| 吊颈线（Hanging Man） | 小实体+长下影线，出现在上涨末端 | 潜在反转向下 |
| 射击之星（Shooting Star） | 小实体+长上影线，出现在上涨末端 | 潜在反转向下 |
| 十字星（Doji） | 开盘≈收盘，实体极小 | 多空均衡，方向待定 |
| 大阳线 | 实体超过前几根K线的范围 | 趋势加速信号（需配合成交量） |

### 2.2 组合K线形态

| 形态 | 组成 | 信号 |
|------|------|------|
| 吞噬形态（Engulfing） | 第二根实体完全包住第一根 | 反转信号（阳吞阴=看涨，阴吞阳=看跌） |
| 启明星（Morning Star） | 下跌+小实体+大阳线 | 底部反转 |
| 黄昏星（Evening Star） | 上涨+小实体+大阴线 | 顶部反转 |
| 三白兵（Three White Soldiers） | 连续三根阳线，逐步推高 | 上升趋势确认 |
| 三黑鸦（Three Black Crows） | 连续三根阴线，逐步下跌 | 下降趋势确认 |

**重要提醒：K线形态需要结合成交量和趋势背景才有意义，单独看形态胜率很低。**

## 3. 均线（Moving Averages）

### 3.1 类型

- **SMA（简单移动平均）**：过去N个收盘价的算术平均
- **EMA（指数移动平均）**：对近期数据加权更高，反应更快

### 3.2 常用周期

| 均线 | 常用周期 | 用途 |
|------|---------|------|
| 短期 | 5日、10日 | 短线趋势 |
| 中期 | 20日、50日 | 中期趋势，关键支撑/阻力 |
| 长期 | 100日、200日 | 长期牛熊分界 |

**港股惯用：** 10日、20日、50日、250日（一年交易日约250天）

**金叉（Golden Cross）：** 短期均线上穿长期均线 → 看涨信号
**死叉（Death Cross）：** 短期均线下穿长期均线 → 看跌信号

### 3.3 均线在港股的局限

- 港股午休造成每天只有5.5小时交易，日K线的时间跨度和A股（4小时）不同
- 对于机构主导的大盘股，均线支撑有一定有效性；对于小盘股，均线支撑可以被轻易穿破

## 4. 量价关系

**基本原则：**

| 价量关系 | 解读 |
|---------|------|
| 价升量增 | 趋势健康，多头有力 |
| 价升量缩 | 趋势可能减弱，动能不足 |
| 价跌量增 | 恐慌性抛售，可能接近底部（极端量时） |
| 价跌量缩 | 下跌动能减弱，但未确认底部 |

**港股量能参考：**
- 恒生指数成分股：日成交量是否高于过去20日均量
- 成交量的绝对量远不如A股，不能直接套用A股的量能标准

## 5. 技术指标

### 5.1 MACD（移动平均收敛散度）

**计算：**
- MACD线 = 12日EMA - 26日EMA
- 信号线（Signal Line）= MACD线的9日EMA
- 柱状图（Histogram）= MACD线 - 信号线

**信号：**
- MACD线上穿信号线 → 买入信号（金叉）
- MACD线下穿信号线 → 卖出信号（死叉）
- 柱状图由负转正 → 动能转强
- 背离（Divergence）：价格创新高但MACD不创新高 → 顶背离，谨慎

### 5.2 RSI（相对强弱指数）

**计算：** RSI = 100 - [100 / (1 + 平均上涨/平均下跌)]，通常取14日

**参考区间：**
- RSI > 70：超买，可能回调（但强势股可以长期维持高RSI）
- RSI < 30：超卖，可能反弹
- 50线上方：总体处于上升趋势中

**港股特殊性：** 在港股市场下跌期间，RSI可以长时间维持在30以下而继续跌（2022年港股就有这种情况）。超卖不等于买入。

### 5.3 布林带（Bollinger Bands）

**计算：**
- 中轨 = 20日SMA
- 上轨 = 中轨 + 2倍标准差
- 下轨 = 中轨 - 2倍标准差

**信号：**
- 价格触及上轨：超买区，阻力
- 价格触及下轨：超卖区，支撑
- 带宽收窄（Squeeze）→ 即将出现大方向突破

### 5.4 成交量指标：OBV（On-Balance Volume）

**逻辑：** 上涨日加当日成交量，下跌日减去当日成交量，累积计算。

**用途：** 判断资金流向（OBV上升而价格未涨 → 资金悄悄流入）。

## 6. 支撑与阻力

**支撑位（Support）：** 价格多次下跌到某位置后反弹，该位置形成买盘聚集

**阻力位（Resistance）：** 价格多次上涨到某位置后回落，该位置形成卖盘聚集

**常见支撑/阻力来源：**
- 重要均线（50日、200日）
- 历史高低点
- 整数关口（心理价位，如恒指20,000点、腾讯400港元）
- 成交密集区（大量筹码换手的价格区间）

**支撑/阻力互换：** 被有效突破的支撑变阻力，被有效突破的阻力变支撑。

---

## 7. 趋势分析

### 7.1 趋势线

**上升趋势线：** 连接一系列上升低点，价格回踩不破 → 趋势有效
**下降趋势线：** 连接一系列下降高点，价格反弹不破 → 趋势有效

### 7.2 趋势强度：ADX指标

ADX（平均趋向指数）：
- ADX < 20：无趋势（横盘整理）
- ADX 20-40：趋势形成
- ADX > 40：强趋势
- ADX > 60：极强趋势，可能过热

**使用建议：** 趋势跟踪策略在ADX>25时效果好；均值回归策略在ADX<20时效果好。

---

## 8. 港股特有的技术形态注意事项

### 8.1 "仙股假突破"

低价仙股（<0.1港元）经常出现放量突破的假象，实际是庄家拉升出货。

**识别：** 成交量突然异常放大（超过过去20日平均的3-5倍以上），但成交额仍然极小（几十万港元），往往是陷阱。

### 8.2 停牌复牌后的缺口

港股公司停牌（Suspension）公告重大事项期间，无法交易，复牌后通常以缺口（Gap）方式跳开。

**特殊性：** 港股停牌期间有时长达数年（部分公司因财务问题长期停牌），复牌后跌幅可能极大。不建议持有停牌股票。

### 8.3 配股/供股除权

公司大规模配股后，股价会出现明显下跌，这不是技术上的"破位"，而是正常的除权价格调整。但频繁配股本身是警示信号（见第10章）。

---

## 9. 技术分析的建议使用方式

**适合用技术分析做的事：**
- 确定买入/卖出的时机（基本面已选好公司后，用技术找入场点）
- 设置止损位（跌破关键支撑/均线离场）
- 判断大势方向（恒指的趋势状态）

**不适合用技术分析做的事：**
- 在没有基本面研究的情况下，仅凭形态买卖
- 对仙股/低流动性股票做技术分析
- 在重大政策/业绩公告前，依赖技术信号持有高仓位

**总结：技术分析是港股投资的辅助工具，而非核心方法论。基本面决定"买什么"，技术分析辅助决定"什么时候买"。**

---

## 关键认知清单

- [ ] 港股技术分析对大盘股有一定有效性，对小盘/仙股无效
- [ ] RSI超卖≠买入，港股可以连续数月处于RSI<30
- [ ] 仙股放量突破通常是庄家陷阱，不要追
- [ ] 停牌股票复牌后有极大跌幅风险，持有停牌股是高危行为
- [ ] MACD背离在宏观下行期（如2022年港股）可持续很长时间
- [ ] 技术分析配合基本面使用，单独用技术分析选股在港股胜率极低
