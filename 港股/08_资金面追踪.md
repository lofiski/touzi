# 第08章：资金面追踪

---

## 1. 南下资金（港股通南向）

### 1.1 数据定义

**南下资金** = 内地投资者通过沪港通和深港通买入港股的净资金流入

港交所每个交易日14:00更新当日南向额度使用情况，收市后发布日度净买入数据。

### 1.2 数据查阅

| 来源 | 内容 | 免费/付费 |
|------|------|---------|
| 港交所官网（hkex.com.hk/Market-Data/Securities-Prices/Southbound-Trading）| 当日数据 | 免费 |
| 富途牛牛/老虎证券App | 南向资金总额及个股 | 免费 |
| Wind | 历史数据、个股追踪 | 付费 |
| iFind | 同Wind | 付费 |

### 1.3 解读框架

**总量层面：**
- 日均净买入>50亿港元：南下积极流入，偏多信号
- 日均净买入0-20亿港元：中性，方向不明
- 净卖出：南下撤退，偏空信号（但南下出现净卖出的频率较低）

**个股层面（更有价值）：**
- 某只股票连续多日南下净买入且规模持续扩大：内地资金建仓信号
- 南下持股比例接近30%（港股通持股上限）：该股可能被接近封顶，后续南下买力减弱

**局限性：**
- 南下数据只报告净额，不区分是机构还是散户
- 南下"聪明钱"并不总是对的（2021年内地资金抄底中资科技股，后来继续跌）
- 数据有1-2天延迟（T日数据T+1公布）

### 1.4 南下资金偏好的板块（历史规律）

| 偏好方向 | 原因 |
|---------|------|
| 内银股（工行、建行、招行H股） | AH折价大、高股息 |
| 内险股（中国平安、中国人寿H股） | AH折价、内地保险龙头 |
| 能源（中国石油、中国神华H股） | 高息防御 |
| 科技龙头（腾讯、美团、阿里）| 港股独有，A股买不到 |
| AH折价扩大时抄H股 | 套利逻辑 |

## 2. 外资流向追踪

### 2.1 外资与港股的关系

外资（Global Institutional Money）是港股历史上最重要的定价力量，也是最难追踪的资金。

**外资流出港股的触发因素：**
- 美联储加息→美元资产吸引力上升，从新兴市场撤资
- VIX（恐慌指数）飙升→全球风险资产抛售
- MSCI指数调整→被动基金强制调仓
- 地缘政治恶化→对中国相关资产的折价扩大

### 2.2 可追踪的外资指标

**EPFR Fund Flow（全球基金流向）：**
- EPFR Global提供的机构级数据（付费），追踪全球数千只基金的资金流向
- 免费版：部分数据见EPFR每周发布的新闻稿

**港交所沽空数据（作为外资代理指标）：**
外资机构（对冲基金）是港股做空的主要参与者，沽空比率上升往往与外资看空有关。

**恒生指数期货持仓（CFTC报告）：**
香港期货市场没有直接公布类似CFTC的持仓报告，但港交所每月发布期货/期权的持仓数据。

**Bloomberg/Reuters外资持仓：**
付费数据，机构级追踪。个人投资者可参考各大投行定期发布的资金流向报告（部分公开）。

### 2.3 MSCI指数调整对港股的影响

**MSCI每年4次审查：** 2月、5月、8月、11月（生效时间通常在审查后约3-4周）

**纳入/剔除的影响：**
- 被纳入MSCI指数：跟踪该指数的被动基金必须按权重买入，产生强制性买盘
- 权重提升：被动基金增持
- 被剔除：被动基金强制卖出（有时伴随大跌）

**数据来源：** MSCI官网（msci.com）有免费的指数构成查询

## 3. 恒指期货持仓分析

### 3.1 恒指期货基本信息

| 参数 | 恒指期货（HSI Futures） | 小型恒指期货（Mini-HSI） |
|------|------------------------|------------------------|
| 合约乘数 | 每点50港元 | 每点10港元 |
| 保证金 | 约10-12万港元/张 | 约2-3万港元/张 |
| 最小变动 | 1点 | 1点 |
| 到期日 | 每月最后营业日前两个营业日 | 同 |

### 3.2 大户持仓分析

港交所每日公布恒指期货的**大客户持仓报告**（Large Open Interest Position Report）：
- 披露持仓超过一定数量的大客户（合并持仓，不披露身份）
- 可观察大户的净多/净空方向

**解读框架：**
- 大户净多仓增加：看涨信号
- 大户净空仓增加（且沽空比率同步上升）：大机构做空信号
- 但港交所数据不如期货市场发达地区（如CFTC）详细

## 4. 沽空比率（Short Selling Ratio）

### 4.1 市场层面

**计算：** 当日全市场沽空成交额 / 全市场总成交额

**历史参考：**
- 港股整体沽空比率通常在 10-15% 之间
- 超过 18-20%：市场整体悲观情绪高，大量机构在做空（历史上见于重大下跌前）
- 低于 8%：做空意愿低，相对乐观

### 4.2 个股层面

**个股沽空数据：** 港交所每日公布各股沽空股数及金额（hkex.com.hk→市场数据→沽空数据）

**解读：**
- 某股沽空比率突然从2%升至15%+：机构正在建立做空头寸，高度警示
- 连续高沽空比率但股价不跌：可能存在"轧空"（Short Squeeze）潜力
- 沽空比率逐渐下降：空头回补（买入平仓），短期利多

### 4.3 每月沽空数据（月度持仓量）

港交所每月公布**沽空未平仓合约（Short Interest）**，即当月末所有尚未回补的沽空股数。

这是更长期的做空信号，比日度沽空比率更能反映机构的中期看法。

## 5. AH溢价指数

### 5.1 定义与计算

**恒生沪深港通AH股溢价指数（HSAHP）：**

由港交所发布，追踪同时在A股和H股上市的公司的价格差异。

**指数 > 100：** A股溢价（A股更贵）
**指数 = 100：** 等价
**指数 < 100：** 极少发生（H股更贵）

**2024-2025年历史区间：** 约125-165（A股平均比H股贵25%-65%）

### 5.2 AH溢价对港股投资的含义

**溢价扩大（如从130升至160）：**
- 表示A股相对H股变贵
- 对港股投资者：H股相对便宜，南下资金可能增加
- 但这不意味着H股会自动涨，溢价可以持续扩大

**溢价收窄（如从160降至130）：**
- 通常是A股下跌或H股上涨导致
- 南下资金套利动机减弱

**个股层面使用：**
查找溢价最高的个股，理解南下资金可能的偏好。例如，某内银H股比A股折价50%，南下资金买入有明确的套利逻辑。

**数据：** 港交所官网、富途、iFind均有HSAHP历史数据

## 6. ADR溢价（美国存托凭证价差）

### 6.1 什么是ADR

在美国上市的中国公司（如阿里巴巴BABA、百度BIDU、京东JD、拼多多PDD等）以ADR形式在纽约证券交易所或Nasdaq交易。

**ADR与港股H股/主要上市的关系：**
- 理论上应等价（汇率调整后）
- 实际上有时价差：由于两地交易时间不重叠（纽约与香港时差13小时），消息传播会造成价格差异

### 6.2 ADR如何预判港股次日走势

**使用方法：**
1. 港股收盘后（16:00），看美股ADR的夜盘走势
2. 若腾讯ADR（OTC市场，代码TCEHY）大涨3%，暗示港股腾讯次日有上涨预期
3. 若阿里巴巴港股（09988.HK）与BABA纽约价差扩大，存在套利空间

**局限性：**
- 部分中国公司的ADR流动性极差，价格参考意义有限
- 美股夜盘本身流动性低，一个大单可以扭曲ADR价格

**可追踪的主要中概ADR：**

| ADR代码 | 对应港股代码 | 公司 |
|---------|------------|------|
| BABA | 09988 | 阿里巴巴 |
| JD | 09618 | 京东 |
| BIDU | 09888 | 百度 |
| NTES | 09999 | 网易 |
| TCEHY | 00700 | 腾讯（OTC ADR，非正式） |
| NIO | 09866 | 蔚来 |

## 7. 综合资金面分析框架

**每日例行追踪（5分钟）：**

```
1. 南下净买入总额（富途App/港交所网站）
2. 恒生指数沽空比率（港交所网站）
3. 美股主要指数收盘（昨晚）：标普500、纳斯达克
4. 美元指数（DXY）：上涨→新兴市场压力↑
5. 美国10年期国债收益率：上涨→港股估值压力↑
6. VIX恐慌指数：>25需注意风险情绪
```

**每周追踪（30分钟）：**

```
1. 南下资金周净买入/净卖出
2. 个股南下持仓变化（重点持仓股）
3. 沽空比率趋势变化（个股）
4. AH溢价指数变化
5. 北向资金（A股方向，理解内地流动性）
```

**每月追踪（2小时）：**

```
1. 港交所月度沽空持仓量报告
2. MSCI指数审查结果（2/5/8/11月）
3. 中国PMI数据（制造业/非制造业）→内地经济健康度
4. 美联储议息会议结果（每6-8周一次）
5. 外资代理指标：Bloomberg新兴市场资金流向
```
