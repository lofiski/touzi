# 第16章：数据工具与研究资源

---

## 1. 免费官方数据源（必备）

### 1.1 披露易（HKExnews）

**网址：** hkexnews.hk

**内容：** 所有港交所上市公司的官方公告、年报、通函、招股说明书

**常用功能：**
- 搜索框输入股票代码或公司名 → 查全部历史公告
- 设置电子邮件提醒：订阅特定公司，有新公告时自动通知
- 权益披露查询：查大股东持仓变动（权益披露类别）
- 沽空数据：每日更新各股沽空数据

**实操技巧：**
- 查配股历史：搜索"配股"或"Placing" → 筛选"通函"类别
- 查合股记录：搜索"合股"或"Share Consolidation"
- 查核数师：在年报中搜索"独立核数师报告"首页

### 1.2 港交所官方市场数据

**网址：** hkex.com.hk/Market-Data

**包含：**
- 各指数实时/历史数据（恒生指数、国企指数、恒生科技指数等）
- 南向/北向资金每日数据
- 期货/期权持仓报告（每日/每月）
- 沽空统计（每日）
- 港股通成分股名单（可查某股是否在港股通范围内）

### 1.3 SFC（证监会）

**网址：** sfc.hk

**重要功能：**
- 持牌机构/人士查询（公众持牌搜索器）
- 执法行动公告（Enforcement Actions）：查某公司/个人是否有违规记录
- 产品注册：查窝轮/牛熊证的注册信息

## 2. 零售级数据平台（免费/部分付费）

### 2.1 富途牛牛（Futu）

**适用场景：** 行情、财务数据、研究报告、资金流向

**免费功能：**
- 港股/美股/A股实时行情
- 财务数据（利润表、资产负债表、现金流）
- 分析师一致预期（EPS预测、目标价）
- 南下资金数据（个股+总量）
- 沽空比率

**付费功能（权益+）：**
- 更多历史数据
- 详细资金流向分析

### 2.2 老虎证券（Tiger Trade）

类似富途，功能略有差异，部分数据在富途付费需要而老虎免费，建议两者都装。

### 2.3 AAStocks（阿思达克）

**网址：** aastocks.com

**特点：** 港股财经数据的老牌来源，部分机构级数据的免费替代品

**常用功能：**
- 港股历史行情数据（比富途更长的历史）
- 公司公告即时推送
- 分部财务数据
- 供股/配股历史

### 2.4 彭博港股通（Bloomberg港股Screener）

**免费版（bloomberg.com/quote）：** 可查港股基本行情和部分财务数据

**付费Bloomberg Terminal：** 机构级，每年约2-3万美元，个人投资者通常不必要

### 2.5 Wisesheets（Google Sheets插件）

将港股数据直接导入Google Sheets，适合自建财务模型。有免费层级（每月有限额）。

## 3. 研究报告获取

### 3.1 免费渠道

**券商研报（通过账户）：**
- 富途/老虎账户用户可查看部分转载的研报
- 汇丰、中信等传统大行的部分报告在公司官网公开

**HKEX披露易：**
年报中的管理层讨论与分析（MD&A）是最权威的公司研究资料，完全免费。

**公司投资者关系（IR）页面：**
大型上市公司（腾讯、美团、阿里巴巴等）的官网IR页面通常有季度数据更新、演示文稿（Earnings Presentation）等，价值高且免费。

### 3.2 付费研报渠道

| 来源 | 特点 | 价格 |
|------|------|------|
| Bloomberg Intelligence | 机构级覆盖 | 附属Bloomberg Terminal |
| Wind（万得） | 内地机构最常用 | 机构订阅约10万+元/年 |
| iFind（同花顺机构版） | Wind替代品，价格较低 | 数万元/年 |
| Refinitiv（路孚特） | 外资机构常用 | 昂贵 |

**散户获取研报的实际方式：**
1. Telegram/微信群中流传的研报（注意版权，部分为盗版）
2. 雪球、老虎社区等用户分享的投行研报摘要
3. 部分券商的本地研究（富途有独立研究部）

## 4. 信息流构建（Information Flow）

### 4.1 每日必看清单

**开盘前（09:00前）：**
```
1. 美股三大指数前一日收盘：道指、纳斯达克、标普500
2. 美国10年期国债收益率
3. 美元指数（DXY）
4. 港元兑人民币汇率
5. A50期货（新加坡SGX，夜盘走势）
6. 恒生期货（HKFE夜市收盘价 vs 上日收盘）
7. 主要中概ADR（阿里、百度、京东等）夜盘走势
8. 金价/油价（若持有相关股票）
```

**收盘后（16:00后）：**
```
1. 南向资金今日净买入总额及个股明细
2. 今日沽空比率（全市场及持仓股）
3. 重要公告（持仓公司是否有公告）
```

### 4.3 社群与论坛

| 平台 | 特点 | 参考价值 |
|------|------|---------|
| 富途社区（牛牛） | 用户讨论，有部分专业投资者 | 中等 |
| 雪球（中文） | A股为主，但有港股讨论区 | 中等 |

## 5. 港股数据分析工具

### 5.1 选股工具（Screener）

**富途选股器（免费）：**
条件筛选：市值、PE、PB、股息率、南下持仓变化等

**Finviz（偏美股）：** 对港股覆盖有限

**自建Excel/Google Sheets模型（推荐）：**
将披露易公告数据和财务数据整合，建立自己的财务模型，这是最能建立能力的方法。

### 5.2 技术分析工具

**TradingView：** 支持港股（需调整时区和代码格式），功能全面，免费层有限制，付费版约15-30美元/月

**富途/老虎App内置图表：** 足够用于基本技术分析

### 5.3 估值工具

**Damodaran数据集（免费）：** NYU教授Damodaran每年更新各行业的估值倍数、Beta、风险溢价数据，网址：pages.stern.nyu.edu/~adamodar/

**港交所统计数据：** 港交所定期发布各指数的市盈率、市账率等统计数据

## 6. 港股特殊信息渠道

### 6.1 恒指成分股调整预测

恒生指数公司（Hang Seng Indexes）每季度审核成分股，调整结果在审核完成后约2-3周生效。

**预测来源：** 富途、Bloomberg、各大投行的指数研究报告

### 6.2 港股通成分股变动

港股通标的的调整（每年3月和9月，基于恒生综合指数调整）也会影响南下资金的可投资范围。

被纳入港股通后，南下资金可以买入，相当于增加了一个买盘来源，短期有利。

### 6.3 大股东权益披露追踪

根据证券及期货条例，持股超过5%的股东每次变动须在3个营业日内披露。

**查询方法：** 披露易→公告类别→权益披露

**应用：** 追踪大股东（包括基金、主权基金）的增减持行为，作为信号参考。
