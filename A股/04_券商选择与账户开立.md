## 2. 佣金谈判

A股佣金没有统一标准，**可以谈判，且差距很大**。

### 2.1 标准佣金 vs 可谈判佣金

| 资金量 | 未谈判默认佣金 | 可谈判下限 |
|--------|-------------|-----------|
| <10万 | 0.1%-0.3% | 0.03%-0.05% |
| 10-50万 | 0.05%-0.1% | 0.025%-0.03% |
| 50-200万 | 0.03%-0.05% | 0.015%-0.025% |
| >200万 | 0.02%-0.03% | 0.01%-0.015% |
| >500万 | 0.01%-0.02% | 万分之2-5（协议定） |

**监管规定：** 目前佣金下限为万分之2.5（0.025%），低于此违规。

### 2.2 如何谈判佣金

1. 开户前明确说明资金量，要求"更低佣金"
2. 对比多家券商的报价
3. 活跃度高的账户（月交易额>100万）可要求进一步降低
4. 互联网券商（东财）通常直接给低佣金，无需谈判

### 2.3 佣金以外的成本

- **融资利率：** 年化约4.5-6%（各券商差异大，资金量大可谈判）
- **融券费率：** 年化约8-12%
- **国债逆回购：** 不收费（甚至有收益）

## 3. 开户流程

### 3.1 所需材料

- 本人有效身份证（二代居民身份证）
- 银行卡（用于出入金）
- 手机号（验证码）

### 3.2 开户步骤（以东方财富为例）

1. 下载东方财富App → 证券 → 开户
2. 填写个人信息，上传身份证照片
3. 银行卡绑定
4. 视频验证（按指引完成）
5. 等待审核（通常当日或次日）
6. 开户成功后，需到所在地交易所系统激活账户（通常自动完成）

### 3.3 特殊权限开通（需主动申请）

| 权限      | 申请条件                          | 时间         |
| ------- | ----------------------------- | ---------- |
| 科创板交易权限 | 证券账户资产≥50万元 + 24个月股票交易经验      | 需主动申请，当日开通 |
| 创业板交易权限 | 证券账户资产≥10万元 + 24个月股票交易经验      | 需主动申请      |
| 北交所交易权限 | 证券账户资产≥50万元 + 24个月股票交易经验      | 需主动申请      |
| 融资融券账户  | 账户资产≥50万元 + 开户满6个月            | 单独申请       |
| 股指期货账户  | 开立期货公司账户，资金≥50万元 + 20题测试      | 期货公司另行开户   |
| ETF期权账户 | 开户满6个月，资产≥50万元，通过知识测试，有模拟交易经历 | 按等级申请      |

**注意：** 股指期货和ETF期权需要在**期货公司**（而非证券公司）开立账户，大多数证券公司有旗下期货子公司（如中信期货、华泰期货等）。

## 4. A股的一户多账户制度

每位投资者在上交所和深交所各有一个账户（通过中证登登记），理论上只有一个证券账户。但可以在多家券商开立账户（多个交易账户，对应同一个证券账户）。

**实操含义：**
- 可以同时在A券商和B券商开户
- A券商账户买的股票，理论上可以通过指定交易转托管至B券商（费时但可行）
- 实际上大多数人将持仓集中在一家券商，便于管理

## 5. 资金安全

### 5.1 证券账户资金的法律保护

- 客户的**证券（股票）**存托于中国证券登记结算公司（中证登），不在券商资产负债表内
- 若券商破产，股票是安全的（直接挂在投资者名下，通过中证登可查）
- 客户的**现金（保证金）**存于券商在银行开设的客户保证金存款账户，受监管隔离

### 5.2 投资者保护基金

**证券投资者保护基金：**
- 覆盖范围：证券公司破产时，对客户的现金及证券损失
- 赔偿上限：每名投资者50万元人民币

## 6. 港股通账户（A股账户自带，无需单独开立）

持有A股证券账户的投资者，若满足以下条件，可直接申请开通港股通权限：

**条件：**
- A股证券账户中的资产（包括现金+股票市值）≥**50万元人民币**
- 具体由券商审核

**功能：** 开通后可通过A股账户，以人民币换汇买港股通标的（约500只港股）

**限制：** 只能买港股通标的，不能打港股新，不能买窝轮/牛熊证/港股期权，详见港股手册第03章。
