# 第17章：A股数据工具与研究资源

---

## 1. 官方免费数据源（必备）

### 1.1 巨潮资讯网（cninfo.com.cn）

**A股信息披露的官方平台，等同于港股的披露易。**

**功能：**
- 搜索任何上市公司的全部历史公告（年报/季报/重大事项等）
- 下载招股说明书、定增预案、股权激励方案等
- 设置公告提醒功能（需注册账号）
- 查询问询函及公司回复

**必知技巧：**
- 公告类型筛选："年报"/"季报"/"定期报告"/"重大事项"/"股权变动"
- 搜索关键词：可以在公告全文中搜索关键词（如"商誉减值"/"违规"/"补贴"）

### 1.2 上交所/深交所/北交所官网

- sse.com.cn（上交所）
- szse.cn（深交所）
- bse.cn（北交所）

**主要用途：**
- 行业统计数据
- 北向资金每日数据（沪深各交易所分别公布）
- 融资融券余额（每日更新）
- 龙虎榜（每日盘后发布）

### 1.3 中国证监会（csrc.gov.cn）

- 行政处罚决定书：执法案例（查公司或高管是否有违规记录）
- 上市公司监管部（查科创/创业板审核动态）

### 1.4 中国人民银行（pbc.gov.cn）

- 货币政策报告（季度）
- 金融数据：M1/M2/社会融资规模/信贷数据（每月10日前后发布）

## 2. 零售级专业平台

### 2.1 同花顺（ithink.com.cn / App）

**最适合A股散户的综合平台之一。**

**核心功能（免费）：**
- 全市场实时行情
- K线图+技术指标（MACD/KDJ/BOLL/成交量等）
- 基本面数据（财务报表、估值数据）
- 资金流向（大单/中单/小单的流向）
- 主力追踪（机构席位、龙虎榜）
- 筹码分布图（A股特色）
- 板块热度地图

**付费功能（iFinD，机构版）：**
- 历史数据库（全市场历史）
- 研报数据库
- 量化数据接口（API）

### 2.2 东方财富（eastmoney.com / App）

**A股散户使用量最大的财经平台，东方财富证券的母平台。**

**核心功能：**
- 实时行情和资讯（更新最快）
- 北向资金（每日实时更新）
- 龙虎榜（每日盘后）
- 大宗交易数据
- 融资融券数据
- 股吧（散户情绪参考）
- 研报中心（部分研报免费）
- 全球财经日历（经济数据发布时间）

**东方财富Choice数据（付费，机构版）：**
- 与Wind接近但价格较低
- 量化研究的重要数据源

### 2.3 Wind（万得，wind.com.cn）

**A股最权威的机构级数据终端。**

**覆盖内容：** 全市场历史行情、财务数据、研究报告、宏观数据、基金数据、债券数据、期货期权数据

**价格：** 个人版约2万-5万元/年；机构版更贵

**替代方案（免费/低价）：**
- AkShare（Python库）：通过代码获取公开金融数据，免费
- Tushare Pro（Python库）：部分免费，付费层级数据更全
- 东方财富iFinD：比Wind便宜

## 3. 研报获取

### 3.1 免费渠道

**巨潮资讯网：** 上市公司接受机构调研的纪要（在公司公告→调研活动栏目）

**东方财富研报中心（eastmoney.com/data/report）：**
- 部分主流券商研报可免费查看（有延迟）

**各大券商App：** 开户后通常可查看该券商发布的研报（中信/华泰/国君等）

### 3.2 付费渠道

| 来源                | 特点     | 价格        |
| ----------------- | ------ | --------- |
| Wind研报库           | 全市场研报  | 附属Wind订阅  |
| 东方财富Choice研报      | 较全     | 数千至数万元/年  |
| 慧博（huibo.com）     | 研报专项聚合 | 部分免费，部分付费 |
| 海外投行研报（Bloomberg） | 国际视角   | 非常昂贵      |

### 3.3 研报的正确使用方式

研报的价值：
- 行业深度报告（了解行业结构、市场空间、竞争格局）
- 公司调研纪要（了解管理层表述，但需批判性阅读）
- 财务模型参考（分析师的盈利预测）

研报的局限：
- 卖方（Sell-side）研报存在利益冲突（券商为承销商时不会唱空）
- "买入"推荐比例远高于"卖出"（行业默规）
- 盈利预测往往过于乐观
- 研报的目标价可信度有限（历史准确率不高）

**使用原则：** 重视行业判断，参考不轻信盈利预测，忽略目标价作为买入信号。

## 4. A股特色数据工具

### 4.1 龙虎榜数据库

**东方财富→数据→龙虎榜**（免费）：每日更新

**Choice历史龙虎榜**（付费）：可追溯特定营业部的历史交易战绩

**分析框架：** 统计某营业部过去1年在龙虎榜的买卖记录，计算其买入后5日/10日/20日的平均超额收益，判断该营业部是否具备"聪明钱"属性。

### 4.2 筹码分布工具

**同花顺/东方财富App内置**（免费）：每只股票均有筹码分布图

**解读要点：**
- 筹码高度集中（锁仓）：主力高度控盘
- 筹码分散（平均分布）：无明显主力
- 成本峰值位置：上方是压力，下方是支撑

### 4.3 宏观数据日历

**东方财富/同花顺App→全球财经日历**：列出国内外重要经济数据发布时间

**重要国内数据：**
- 每月1日前后：官方PMI（制造业/非制造业）
- 每月上旬：财新PMI
- 每月10日前后：CPI/PPI
- 每月15日前后：工业增加值/消费/固定投资
- 每季末月下旬：GDP数据（季报）
- 每月中旬：社会融资规模/M1/M2

## 5. A股量化与数据接口

### 5.1 开源Python数据库

**AkShare（akshare.xyz）：**
- 完全免费，无需注册
- 覆盖A股、港股、美股、期货、ETF、宏观数据
- 安装：`pip install akshare`
- 数据来源于公开网站，实时性有限

**Tushare Pro（tushare.pro）：**
- 免费层有限制，积分制（通过赞助获得更高权限）
- 数据质量高于AkShare
- 覆盖全市场历史数据、财务数据、龙虎榜等

### 5.2 数据接口示例（AkShare）

```python
import akshare as ak

# 获取A股股票列表
stock_list = ak.stock_info_a_code_name()

# 获取某股票历史K线数据
df = ak.stock_zh_a_hist(symbol="600519", period="daily", 
                          start_date="20230101", end_date="20251231", 
                          adjust="qfq")  # qfq=前复权

# 获取北向资金数据
north_fund = ak.stock_connect_hsgt_north_net_flow_in_em()
```

## 6. 信息流日程（A股）

**每日例行（10分钟）：**
```
① 美股前一日收盘（标普500/纳斯达克/道指）
② 人民币汇率（离岸CNH/在岸CNY）
③ A50期货（SGX夜盘）
④ 沪深两市今日成交额（判断市场活跃度）
⑤ 北向资金净流入/净流出（收盘后查）
⑥ 融资余额变化（每周查即可）
```

**每周例行（30分钟）：**
```
① 融资余额周度变化趋势
② 龙虎榜重要席位的本周动向
③ 主要宽基指数估值（沪深300 PE/PB vs 历史均值）
④ 当周宏观数据发布及市场反应
```

**每月例行（2小时）：**
```
① 月度宏观数据综合评估（PMI+CPI+信贷）
② 主要持仓公司公告回顾
③ 行业ETF资金流向（北向+融资的行业分布）
④ 下月重要事件日历（政策发布/财报季/数据公布）
```
