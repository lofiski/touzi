# 第15章：衍生品进阶——A股股指期货

---

## 1. A股股指期货概览

A股股指期货在**中国金融期货交易所（中金所，CFFEX）**交易，共有四个主要合约：

| 合约       | 代码  | 标的指数     | 合约乘数   | 覆盖范围           |
| -------- | --- | -------- | ------ | -------------- |
| 沪深300期货  | IF  | 沪深300指数  | 每点300元 | 大盘蓝筹（沪+深各150只） |
| 上证50期货   | IH  | 上证50指数   | 每点300元 | 超大盘（上交所50只）    |
| 中证500期货  | IC  | 中证500指数  | 每点200元 | 中型股（500只）      |
| 中证1000期货 | IM  | 中证1000指数 | 每点200元 | 小型股（1000只）     |
|          |     |          |        |                |

**2015年股灾后的限制（后逐步放开）：** 2015年市场崩溃后，证监会对股指期货实施严格限制（日内交易手数限制、保证金提高、手续费提高）。2019年以来逐步放开，2023年已基本恢复至正常水平。

## 2. 合约规格详解

### 2.1 沪深300期货（IF）—— 最重要

| 参数    | 数值                            |
| ----- | ----------------------------- |
| 合约乘数  | 每点300元人民币                     |
| 最小变动  | 0.2点（= 60元/张）                 |
| 到期月份  | 当月、下月、季月×2（3月、6月、9月、12月）      |
| 最后交易日 | 到期月份第三个周五                     |
| 结算方式  | 现金结算                          |
| 结算价   | 最后交易日沪深300指数最后2小时算术平均价        |
| 交易时间  | 09:30-11:30, 13:00-15:00（无夜市） |
| 初始保证金 | 合约价值的12%（实际约15-18万元/张，视指数点位）  |

**合约价值计算（IF为例）：**
沪深300指数在4000点时：
- 每张合约价值 = 4000 × 300 = 120万元
- 初始保证金 ≈ 120万 × 12% = 14.4万元
- 每点价值 = 300元

### 2.2 四个合约的定位

| 合约         | 对冲适用场景          | 风格偏向  |
| ---------- | --------------- | ----- |
| IF（沪深300）  | 持有沪深主板蓝筹        | 价值+蓝筹 |
| IH（上证50）   | 持有超大盘股（四大行、茅台等） | 极度偏价值 |
| IC（中证500）  | 持有中型成长股         | 成长+中盘 |
| IM（中证1000） | 持有小型股           | 小盘+成长 |

## 3. A股股指期货的特殊现象：长期贴水

### 3.1 贴水（Contango in Reverse / Backwardation）

**A股股指期货长期处于贴水状态：**

期货价格 < 现货（指数）价格 → 期货贴水

这与全球大多数市场的期货正向溢价（升水）相反。

**原因：**
1. **机构对冲需求（卖方压力）：** 持有A股大量现货的机构（公募基金、险资）大量买入股指期货空头对冲，压低期货价格
2. **T+0套利限制：** A股现货T+1，无法完全实现无风险套利将期货价格拉回合理水平
3. **量化中性策略：** 大量量化对冲基金做多个股+做空期货，持续增加空头压力

**贴水的量化：**

```
当月合约贴水率 = (期货价格 - 现货指数) / 现货指数
年化贴水率 = 当月贴水率 × (252 / 到期剩余交易日)
```

**历史贴水水平（IC/IM最明显）：**
- IF（沪深300）：年化贴水约1-5%（相对温和）
- IC（中证500）：年化贴水约5-15%（较大）
- IM（中证1000）：年化贴水约10-20%（最大）

### 3.2 贴水对不同策略的影响

**对多头（持有期货合约看涨）：**
- 每次展仓（换月），都需要以贴水的价格买入新合约
- 即使现货指数不涨，持有期货多头也会因贴水而产生损失
- 年化贴水10%意味着：现货涨10%，期货多头可能只赚0%

**对空头（对冲持仓）：**
- 每次展仓，从旧合约到新合约，可以获得贴水收益
- 持有现货+做空期货的"量化对冲"策略，贴水收益是一个重要的正回报来源

**结论：** 在贴水环境下，直接持有股指期货多头不划算（贴水是持续的成本）。个人投资者用期货的主要场景是对冲（空头），而非投机（多头）。

## 4. 股指期货的使用

### 4.1 对冲（最主要的专业用途）

**场景：** 持有100万元沪深300成分股组合，担心短期市场下跌，但不想卖股票。

**操作：**
```
需要对冲的张数 = 持股市值 × Beta / (IF指数点位 × 300)

示例（沪深300在4000点）：
需要张数 = 100万 × 1.0 / (4000 × 300) = 100万 / 120万 ≈ 1张（向下取整）

卖出1张IF期货合约（空头）

结果：
若市场下跌5%（指数从4000→3800）：
  股票损失：100万 × 5% = 5万元
  期货盈利：1张 × 200点 × 300元 = 6万元
  净效果：基本对冲
```

### 4.2 股指期货的交易费用

| 费用        | 沪深300期货（IF） | 中证500（IC） | 中证1000（IM） |
| --------- | ----------- | --------- | ---------- |
| 手续费（开仓）   | 约2.3元/张     | 约4.5元/张   | 约4.5元/张    |
| 手续费（平仓当日） | 约3.45元/张    | 约6.8元/张   | 约6.8元/张    |
| 印花税       | 无           | 无         | 无          |
| 保证金       | 约12-15%     | 约12-15%   | 约15-18%    |
|           |             |           |            |

**注意：** 平今仓（当日开仓当日平仓）手续费是平仓普通手续费的1.5倍，不鼓励日内频繁交易。

## 5. 开户条件

**在中金所开立期货账户的要求：**
- 通过期货公司（非证券公司）开立账户
- 资金要求：中金所规定金融期货账户资金≥**50万元人民币**
- 知识测试：须通过期货基础知识测试（20题，满分通过）
- 有2年以上的股票或期货投资经历证明

**开户渠道：** 主要证券公司旗下的期货子公司（如中信期货、华泰期货、国泰君安期货等）均可开立。

---

## 6. 展仓的实务

期货合约有到期日，持续持有需定期**展仓（Roll Over）**：

**展仓时间：** 通常在到期日前1-3周，当月合约流动性开始下降时，换至下月/下季度合约

**展仓成本：**
在贴水市场中，从近月移至远月：
- 近月价格（如3800点） → 远月价格（如3770点）
- 从3800点空头合约平仓，重新在3770点建立空头
- 展仓获益（3800-3770=30点×300=9000元/张）

**贴水越深，做空者展仓收益越高。**
