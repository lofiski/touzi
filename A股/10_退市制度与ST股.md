# 第10章：退市制度与ST股

---

## 1. A股退市制度概述

A股历史上退市数量极少（长期每年仅个位数），壳资源因此极为稀缺和昂贵。但2020年以来，注册制改革配套的**退市新规**大幅提高了退市频率。

**退市数量变化：**
- 2020年以前：每年2-10家退市
- 2021-2022年：每年20-30家
- 2023-2024年：每年40-50家以上（退市常态化开始）

---

## 2. ST制度

### 2.1 ST（Special Treatment）

**触发条件（满足任一）：**
- 最近两个会计年度净利润均为负值
- 最近一年末净资产为负值
- 最近一年的财务报告被注册会计师出具保留意见、无法表示意见或否定意见的审计报告
- 最近一年被证监会实施行政处罚

**"ST×××"的市场影响：**
- 涨跌停幅度从±10%降至±5%
- 被部分基金/指数强制剔除（无法买入）
- 对散户的警示标志，流动性下降

**摘帽条件：**
满足摘星/摘帽条件（通常是盈利恢复、财务指标达标），经交易所审核后可恢复正常交易。

### 2.2 \*ST（退市警示）

**触发条件（2024年退市新规，满足任一）：**
- 最近两年扣非净利润均为负值，且每年净利润为负
- 最近一年末净资产为负值
- 最近一年审计报告为非标准意见（保留/否定/无法表示）
- 近两年ROE均<0%

**\*ST的含义：** 公司已进入退市风险警示状态，若次年仍不改善，面临退市。

---

## 3. 退市触发条件（2024年退市新规）

### 3.1 财务类退市指标

| 指标   | 退市标准                         |
| ---- | ---------------------------- |
| 营业收入 | 最近1年营业收入<3000万元（主板1亿元）       |
| 净利润  | 最近1年扣非净利润<0 且 营业收入<1亿元（配合使用） |
| 净资产  | 最近1年末净资产<0                   |
| 审计意见 | 最近1年审计报告为"无法表示意见"或"否定意见"     |

**关键变化（2024年起）：** 主板退市的营业收入门槛从3000万提升至1亿元，大幅扩大了退市范围。

### 3.2 规范类退市

| 情形   | 说明                    |
| ---- | --------------------- |
| 信息披露 | 连续120天未按规定披露年报/半年报    |
| 持续经营 | 被审计师出具"持续经营存在重大疑虑"的意见 |
| 股权分布 | 股东人数或持股比例不符合上市条件      |
| 公司治理 | 实际控制人无法联系，无法正常经营      |

### 3.3 交易类退市

| 指标  | 退市标准                          |
| --- | ----------------------------- |
| 成交量 | 连续20个交易日每日成交量均低于100万股         |
| 股价  | 连续20个交易日收盘价低于面值（1元/股），即"面值退市" |
|     |                               |

**面值退市（1元退市）是A股最常见的退市方式之一：**
一旦股价连续接近1元，散户大量抛售（怕退市）→ 股价进一步下跌 → 形成负反馈 → 加速退市

**典型操作提示：** 股价跌至1.5元以下时应高度警惕；1.2元以下是红色警戒区。

## 4. 退市流程

```
触发退市条件（年报/财务数据触发）
    ↓
交易所作出退市决定
    ↓
退市整理期（Delisting Arrangement Period）：15个交易日
    • 股票名称后加标识（如"×××退"）
    • 涨跌停幅度：±10%
    • 期间股价通常大幅下跌（散户恐慌性抛售）
    ↓
整理期满：从交易所摘牌
    ↓
转入全国中小企业股份转让系统（新三板）挂牌（部分公司）
    • 或直接终止上市（无转让场所）
```

**退市整理期的风险：**
退市整理期通常是散户最后的出逃机会，但也是流动性最差的时段。很多人在退市整理期中无法找到买家。

## 5. 借壳上市（A股特有重要概念）

### 5.1 借壳逻辑

上市公司的"壳"（上市地位）在A股有独立价值，因为IPO需要时间和门槛。

**借壳流程（简化）：**
1. 外部优质公司（注入方）找到一家主营业务已失去但上市地位仍在的壳公司
2. 以定增+股权转让的方式，将优质资产注入壳公司，同时取得壳公司的控制权
3. 壳公司更名，主营业务变为注入方的业务
4. 由于借壳绕开了IPO排队，股价往往大涨

### 5.2 注册制对借壳的影响

注册制改革缩短了IPO时间，降低了借壳的相对吸引力。但借壳仍然存在，尤其是：
- 被借壳方资质达不到科创板/创业板IPO条件
- 境外公司回A股（无法直接IPO时）

### 5.3 对散户的风险

- 借壳消息通常在公告前已被内部人士提前知晓，散户往往在高位才获知消息
- 借壳后注入资产的质量参差不齐，短期大涨后的基本面未必支撑
- 重组停牌期间资金被锁定，有重组失败的风险

## 6. 避免被退市公司"坑"的实操指南

### 6.1 财务预警信号

```
高危信号（出现任何一个，立即核查）：
□ 净利润依赖政府补贴（扣非净利润为负）
□ 审计意见有"强调事项"涉及持续经营
□ 公司连续2年亏损
□ 净资产持续下降，接近0
□ 公司年报/半年报延期发布
□ 审计师出具保留意见
□ 股价已低于1.5港元（面值退市风险区）
□ 公司存在大额诉讼且金额超过净资产20%
```

### 6.2 退市公司的处理

**发现持仓公司触发退市条件时：**
1. 不要等到退市整理期才出逃（流动性最差）
2. 在年报公告后、\*ST处理前出逃（流动性还在）
3. 如果已在退市整理期，分多笔挂单出售，接受折价
4. 任何情况下，持有退市股等"奇迹发生"是最差策略

## 关键认知清单

- [x] 注册制配套退市改革后，A股退市常态化，每年40-50家，不再是小概率事件
- [x] 主板营收退市门槛提升至1亿元（2024年），更多公司面临退市风险
- [x] 面值退市（股价连续20天<1元）是最常见退市方式，1.5元以下已进入危险区
- [x] 退市整理期是流动性最差的时段，应在此前出逃
- [x] 扣非净利润持续为负，本质上是公司靠政府补贴才不亏损，是退市预警
- [x] 借壳消息往往在高位才到散户手里，追高买入借壳概念风险极大
