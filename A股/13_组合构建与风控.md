# 第13章：A股组合构建与风控框架

---

## 1. A股风控的特殊性

与港股相比，A股的风控有两个独特挑战：

**挑战1：T+1制度使当日止损不可能**

买入当天无法卖出，意味着：
- 隔夜利空（如政策突变、业绩雷）可能在次日开盘直接跌停
- 跌停板流动性陷阱可能延续多天
- 风险暴露时间窗口：**从买入到最早可卖出，最短也有隔夜等待**

**挑战2：±20%（科创/创业板）的涨跌停放大单日风险**

相比主板±10%，科创/创业板±20%意味着单只股票两天内可能损失36%（-20%×-20%复合）。

## 2. 仓位管理框架

### 2.1 三档仓位模型

| 档位  | 仓位比例                 | 适用市场状态           |
| --- | -------------------- | ---------------- |
| 轻仓  | 30-40%股票，60-70%现金/货基 | 市场趋势不明朗，或个人研究不充分 |
| 正常仓 | 60-70%股票，30-40%现金    | 市场中性，有清晰投资逻辑     |
| 满仓  | 80-90%股票，10-20%现金    | 确定性极高的机会（谨慎使用）   |

**新手建议：** 前6个月全程不超过轻仓（30-40%），让自己有足够现金应对机会和错误。

### 2.2 单只股票最大仓位

| 研究深度              | 最大仓位       |
| ----------------- | ---------- |
| 深度研究（读过3年年报+研报）   | 40%以内      |
| 中度研究（读过年报摘要+财务数据） | 25%以内      |
| 浅度研究（听说+技术面）      | 10%以内（不建议） |

### 2.3 市值分布建议（新手）

| 市值段     | 建议持仓比例 | 原因              |
| ------- | ------ | --------------- |
| 300亿以上  | 60-70% | 流动性好，信息透明       |
| 50-300亿 | 20-30% | 中型成长股，流动性可接受    |
| 50亿以下   | 0-10%  | 流动性风险+退市风险，谨慎参与 |

## 3. A股的止损框架

### 3.1 T+1下的止损策略调整

由于T+1，次日开盘是**最早可执行止损的时机**。

**止损决策树：**
```
持仓出现亏损
    ↓
问题1：导致下跌的原因是什么？
    ├─ 整体市场下跌（指数也跌）→ 问题2
    └─ 个股特定利空（公告/业绩/政策）→ 问题3

问题2：指数带动的下跌
    ├─ 个股基本面未变 + 跌幅<15% → 持有或小幅加仓
    └─ 指数系统性下跌（-10%+）→ 减仓等待，保留现金

问题3：个股特定利空
    ├─ 利空属于一次性事件（诉讼/偶然亏损）→ 评估影响后决定
    └─ 利空改变了核心业务逻辑（政策打击/主营崩塌）→ 无论亏损多少，立即止损
```

### 3.2 止损幅度参考

| 股票类型      | 建议止损幅度       | 原因            |
| --------- | ------------ | ------------- |
| 沪深主板蓝筹    | -15%至-20%    | 流动性好，止损可执行    |
| 科创/创业板成长股 | -20%至-25%    | 波动性更大，给予更多空间  |
| 题材小盘股     | -10%至-15%    | 下跌往往更剧烈，需更严格  |
| 连续跌停中的股票  | 等跌停打开后第一时间止损 | 别等"解套"，避免更大损失 |
|           |              |               |

### 3.3 特殊情况：连续跌停的处理

**连续跌停是A股最危险的情况之一：**

**第1天跌停：**
- 评估利空性质（一次性？还是持续影响？）
- 关注跌停封单量（封单越大，次日越难打开）
- 不要在第一天跌停时在跌停板上排队卖出（通常无法成交，且次日可能继续跌停）

**第2天跌停：**
- 反映市场认为利空未充分消化
- 在跌停板上排队挂单可以，但成交概率低
- 如果连续2个跌停，第3天通常会有博反弹资金介入，但也可能继续

**跌停打开时的操作：**
若决定止损，在跌停打开的瞬间挂市价卖出（或稍低于市价的限价卖出），优先于等待进一步反弹。

## 4. 分散与集中的权衡

### 4.1 A股特有的板块相关性

A股板块联动性极强，买5只不同行业的股票，在宏观下行时往往同步下跌（相关性0.6-0.8）。

**真正有效的分散：**
- 行业分散（非重叠）
- 宏观驱动因素分散（消费类vs出口类vs内需政策类）
- 市值分散（大盘+中盘）
- 风格分散（价值+成长）

**无效的伪分散：**
- 同时持有6只新能源股（高相关性）
- 持有10只股票但仓位极小（无法深度研究）

### 4.2 建议持仓数量

| 资金量      | 建议持仓数量 | 原因                |
| -------- | ------ | ----------------- |
| <10万元    | 1-3只   | 资金分散后每只仓位太小，跟踪成本高 |
| 10-50万元  | 3-5只   | 可以深度研究，有一定分散      |
| 50-200万元 | 5-8只   | 足够分散，可覆盖多个行业      |
| >200万元   | 8-15只  | 增加分散，减少个股风险       |

## 5. 现金管理

### 5.1 闲置资金工具

A股账户的闲置资金不要放在保证金账户躺着（几乎0收益）：

| 工具           | 年化收益率        | 流动性       |
| ------------ | ------------ | --------- |
| 货币市场基金（余额宝类） | 1.5-2.5%     | 实时赎回（T+0） |
| 国债逆回购        | 1.5-4%（期限不同） | 到期后自动到账   |
| 短期理财（T+1）    | 2-3%         | 次日到账      |
| 证券账户现金       | 0.3-0.5%（活期） | 即时        |

**推荐：** 闲置资金用货币基金（场内货币基金如华宝添益，代码511990，每天可实时申购赎回）或国债逆回购。

### 5.2 国债逆回购（A股重要现金管理工具）

**什么是国债逆回购：** 将闲置资金短期出借给需要资金的机构，以国债为质押，获得固定利息收入。

**操作：** 在A股账户中，搜索"GC001"（上交所1天期，代码204001）或"R-001"（深交所，代码131810）

**收益率：** 通常高于货币基金，年末/季末资金需求旺时可达5-10%（年化）

**风险：** 几乎无风险（以国债为质押），到期日自动还款

## 6. 仓位管理工具（期货对冲，进阶）

持有大量A股现货的投资者，可以用股指期货对冲系统性风险：
- 卖出沪深300股指期货（IF）对冲大盘蓝筹
- 卖出中证500期货（IC）对冲中型成长股
- 具体见第15章《股指期货》

**新手阶段不建议使用期货对冲，建议直接通过减仓来降低风险，而非用复杂工具对冲。**

## 7. 心理与纪律

A股特有的极端波动对心理有额外考验：

**涨停板的诱惑：** 看到某题材板块连续涨停，极易产生"我错过了"的FOMO情绪。解药：确认自己在什么价位、什么逻辑下买入，而非追高。

**跌停的恐惧：** 持仓股跌停，会产生"赶快卖掉"的冲动，即使T+1当天无法卖出。解药：第一时间分析跌停原因，不感情用事。

**连涨后的过度自信：** 组合连续上涨后，最危险，这时候往往加大仓位甚至加杠杆。解药：记住市场随机性，加仓必须有新的逻辑支撑，不能仅仅因为"最近运气好"。

## 关键认知清单

- [ ] T+1无法当日止损，买入决策必须考虑隔夜风险
- [ ] 连续跌停时，在跌停板排队卖出通常无效，等跌停打开后第一时间出逃
- [ ] A股板块联动性强，真正有效的分散需要不同宏观驱动因素的组合
- [ ] 闲置资金用货币基金或国债逆回购，不要放着浪费
- [ ] 国债逆回购（GC001/R-001）是无风险的短期收益工具，季末收益率可达5-10%
- [ ] 持仓连续上涨时不能随意加大仓位，这是风险积累最快的时刻
