# 进阶第08章：周期与牛熊史

> **本章核心问题：A股的牛熊有规律吗？顶和底长什么样？**
> 「太阳底下没有新鲜事。」——A股三十年，牛市的剧本换了名词、没换结构。
> 复盘历史不是为了预测点位，而是为了在下一次剧本重演时，**认出自己身处第几幕**。

---

## 1. 历次牛熊完整复盘

### 1.1 1996-2001：庄股牛（散户启蒙时代）
- **驱动**：降息周期+人民日报社论定调「恢复性上涨」+庄家控盘时代（见第03章）；
- **形态**：绩优股与庄股齐飞，1999年「5·19行情」（网络股行情，A股第一次科技泡沫）；
- **终结**：2001年国有股减持政策出台（融资市逻辑碾压市场），叠加庄股资金链断裂（中科系、德隆系），开启四年大熊市；
- **首次验证的规律**：政策既能造牛（社论）、也能杀牛（减持）——**A股牛熊的第一变量从来是供需政策，不是经济**。

### 1.2 2005-2007：超级牛（6124，至今未被逾越）
- **驱动三重奏**：股权分置改革（消除制度悬疑，大小股东利益首次一致）+人民币升值周期（外资热钱涌入）+企业盈利爆发（重工业化黄金期）；
- **形态**：998点→6124点，两年六倍。全民炒股：菜市场谈股票、基金一日售罄、开户排队；
- **顶部特征**（背下来）：2007年10月，全A市盈率约55倍以上；单月新增开户数百万级；「死了都不要卖」成为流行歌；央行连续加息提准无人在乎——**利空失效是顶部最可靠的指纹**；
- **终结**：估值极限+大小非解禁潮+全球金融危机，6124→1664（跌83%）。

### 1.3 2008-2009：四万亿反弹
- 政策强刺激（四万亿基建），1664→3478翻倍反弹后陷入长熊；
- **规律**：强刺激反弹是「政策牛」的标准样本——快、猛、不问基本面，刺激退坡即见顶。

### 1.4 2013-2015：杠杆牛与股灾三部曲（必须精读的一轮）

**上半场（2013-2014中）：创业板结构牛。** 移动互联网产业浪潮+并购重组松绑（第07章的「三高并购」正是此时埋雷），创业板独立走牛，主板趴着——「结构牛」的原型。

**下半场（2014末-2015.6）：全面疯牛。** 驱动是纯粹的资金与杠杆：
- 降息降准周期启动+「改革牛」「国家牛市」的官媒叙事背书；
- **杠杆工具全面开花**：两融余额从4000亿→2.27万亿；场外配资（3-10倍杠杆，恒生HOMS系统分仓）估计上万亿；伞形信托；
- 上证2000点→5178点，创业板PE超过140倍；「市梦率」「一人一句涨停」时代。

**股灾三部曲：**
1. **2015.6-7 第一波**：证监会严查场外配资（去杠杆触发）→ 高杠杆盘强平 → **流动性螺旋**：跌停→无法卖出→卖其他能卖的→全面跌停（「千股跌停」一词诞生，当年出现十余次）→ 国家队万亿救市；
2. **2015.8 第二波**：汇改引发人民币贬值恐慌，救市资金被套，二次探底；
3. **2016.1 第三波：熔断惨案**。引入指数熔断机制（跌5%暂停15分钟、跌7%收市）——本意维稳，实际制造了「磁吸效应」的极端版：跌近5%时所有人抢跑 → 触发熔断 → 恢复交易即奔7% → 全天收市。**4个交易日触发4次熔断，机制存活7天即废除**。
- **这一轮的全部教训**：杠杆决定了下跌的方式（不是阴跌而是踩踏）；救市底不是最终底；坏的制度设计会放大它想抑制的风险；**涨得有多疯，杠杆有多高，跌下来就有多碎**。

### 1.5 2016-2018：漂亮50与至暗时刻
- 2016-2017：供给侧改革+外资流入，上证50慢牛（茅台从200到700+），中小创持续杀估值——**大小盘风格的极端分化年**；
- 2018：去杠杆+贸易战双杀，全年阴跌25%+，**股权质押危机**（大量民企质押爆仓边缘）触发政策底（10月刘鹤讲话+纾困基金），2449政策底 → 2019.1.4 2440市场底——**政策底领先市场底三个月，教科书样本**。

### 1.6 2019-2021：结构牛（核心资产+新能源）
- 外资+公募定价权时代，抱团茅指数（复盘见第06章）；2020疫情后全球放水，新能源产业趋势爆发（宁德时代、隆基）；
- 2021.2.18 抱团崩塌，但新能源续命至2021.11——**同一轮牛市里，不同主线的顶可以差九个月**：看着上证指数做交易毫无意义，A股早已是「结构市」。

### 1.7 2022-2024.9：三年熊与「924」大逆转
- 驱动：地产下行+疫情反复+中美博弈+外资流出，沪指跌至2635；微盘股2024.2流动性危机（第06章）；
- **2024年9月24日**：央行、金监局、证监会联合发布会——降准降息+**创设互换便利（SFISF）与回购增持再贷款（央行工具直接对接股市，历史首次）**+政治局9月开经济会议（罕见）；
- 市场反应：6个交易日上证暴涨20%+，成交额从5000亿飙到3.4万亿（历史天量），国庆假期开户潮——**典型的「政策逼空牛」起点形态：踏空者的绝望比套牢者的绝望更有购买力**；
- 随后进入巨震分化阶段——政策牛的第一波永远是估值修复脉冲，之后能否走远取决于基本面接力（这是所有政策牛的统一剧本）。

## 2. 规律总结：A股牛熊的结构性剧本

### 2.1 牛市三段论（每一轮都适用）

```
第一段：绝望中重生（政策驱动）
  没人相信，暴力脉冲，踏空是主流情绪。特征：政策密集出台、成交量骤放、券商股先涨。
第二段：犹豫中上涨（资金与盈利接力）
  震荡上行，主线形成，增量资金（基金发行/两融）持续入场。最长、最舒服、最该重仓的一段。
第三段：疯狂中死亡（散户与杠杆定价）
  加速上涨、垃圾股鸡犬升天、全民入场、利空失效。最赚钱也最危险的一段。
```

### 2.2 「三底」时序模型

```
政策底（政策密集转向）→ 市场底（指数最低点）→ 经济底（盈利拐点）
     领先1-6个月            领先2-4个季度
```
- 政策底可识别（政策工具的密度和级别），市场底只能事后确认；
- 正确姿势：政策底出现后**分批建仓、不加杠杆、容忍最后一跌**。

### 2.3 顶部与底部特征对照清单

| 维度 | 顶部区域 | 底部区域 |
| --- | --- | --- |
| 成交额 | 历史天量，连续万亿级 | 极度萎缩（地量见地价） |
| 开户/基金发行 | 开户排队、爆款基金一日罄 | 基金发行失败、清盘潮 |
| 两融余额 | 快速膨胀至历史高位 | 长期萎缩后企稳 |
| 估值分位 | 全A PE历史90%+分位 | 历史10%以下分位、破净股数量创纪录 |
| 舆论 | 出圈：不炒股的人开始谈股票 | 出圈：「A股」成为自嘲梗、财经媒体流量枯竭 |
| 利空/利好反应 | 利空失效（都是「洗盘」） | 利好失效（都是「诱多」） |
| IPO节奏 | 大提速、超募常态 | 实质性放缓/暂停 |
| 产业资本 | 减持潮、清仓式减持 | 增持回购潮、险资举牌 |
| 政策姿态 | 提示风险、查配资、降温 | 密集喊话、真金白银入场 |

**用法**：单项信号无意义，**命中6项以上才构成区域判断**；且顶/底是「区域」不是「点」——特征出现后市场往往还能惯性运行数周到数月。

### 2.4 风格轮动：另一层周期

大小盘风格3-4年一摆（2013-2015小、2016-2018大、2019-2021大盘成长、2021-2024小微盘、2024后再平衡……）。驱动因子：增量资金属性（外资/公募进场利好大盘，游资/散户/量化主导利好小盘）+相对估值差极值回归。**「今年有效的选股方法」大概率是风格红利而非你的能力**——把风格贝塔误认为alpha，是老手最常见的死法。

---

## 3. 本章总结

1. **A股牛熊的第一变量是「政策×资金供需」，不是经济**：1996社论牛、2001减持熊、2015杠杆牛、2024逼空牛，全部由政策与资金结构解释；经济（盈利）只决定牛市第二段的成色。
2. **牛市三段论与三底时序是最可靠的两个结构模型**——不预测点位，只判断「现在是第几幕」。
3. **顶部的统一指纹是「利空失效+全民入场+杠杆高企」，底部的统一指纹是「利好失效+成交冰点+产业资本增持」**。
4. **杠杆决定下跌的形态**：无杠杆的熊市是阴跌，高杠杆的熊市是踩踏（2015、2024.2）——判断市场的杠杆水平，就是判断风险的形状。
5. **结构市时代看指数做交易已经失效**：同一轮牛市不同主线的顶可以相差九个月，风格周期是独立于牛熊的第二层周期。

> 历史的每一轮循环里，散户都扮演同一个角色：第三段进场，第一段割肉。
> 为什么明知剧本仍然重演？答案不在市场，在人脑。见第09章《人性解剖》。
