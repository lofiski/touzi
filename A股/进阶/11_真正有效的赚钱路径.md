# 进阶第11章：真正有效的赚钱路径

> **本章核心问题：在这个融资市+博弈场里，到底有哪些被验证过的赚钱方法？**
> 本章的写法与市面上所有「财富密码」相反：每条路径都诚实标注
> **收益来源（赚谁的钱）、门槛、容量、衰减风险、适合谁**。
> 记住第一性原理：**说不清赚谁的钱的策略，就是别人赚你钱的策略。**

---

## 1. 评估任何策略的五问框架

拿到任何一个「赚钱方法」，先过这五关：

1. **赚谁的钱？**（对手方是谁，他为什么愿意亏这笔钱——制度让利？别人的恐慌？行为偏差？）
2. **为什么轮得到我？**（这钱为什么没被机构/量化赚走——容量太小他们看不上？需要的耐心他们没有？）
3. **容量和拥挤度如何？**（多少钱、多少人在做会把它做死？现在处于生命周期哪一段？）
4. **最大回撤/尾部风险是什么？**（策略失效时怎么死？会不会一次回吐多年利润？）
5. **它匹配我的性格、时间、资金吗？**

---

## 2. 路径逐条盘点

### 2.1 制度让利型（新手就该从这里开始）

**① 打新（新股申购）**
- 赚谁的钱：发行定价机制让利（历史上）；
- 现状：注册制+全面市场化定价后，**破发常态化，「无风险」时代已结束**——必须逐只判断发行估值，从福利变成了技能；
- 结论：作为持仓的附赠彩票可以，作为策略已衰减。北交所/可转债打新同理，窗口期属性，有肉时吃、破发潮时停。

**② 可转债策略**
- 赚谁的钱：条款博弈的钱——发行人**促转股的刚需**（不想还钱→有动力让转债涨到130元触发强赎）+债底保护的不对称性；
- 经典打法：低价+低溢价「双低轮动」、下修博弈（临近回售期的下修动机）、条款套利；
- 诚实的风险披露：2021年后信用风险打破「转债不违约」信仰（搜特、蓝盾退市转债归零），双低策略因拥挤大幅衰减；监管收紧炒作；
- 结论：**仍是散户风险收益比最好的战场之一**（T+0、有债底、条款透明），但需要真研究条款和信用，无脑轮动的红利期已过。适合：愿意读募集说明书的耐心型玩家。

**③ 各类折溢价套利（ETF/LOF/要约收购/分红套利等）**
- 赚谁的钱：定价时滞与规则缝隙；
- 现状：几乎全部被量化和专业套利者抹平，单次收益薄、机会稍纵即逝；
- 结论：作为知识储备值得懂，作为主策略容量与频率都不够。

### 2.2 长钱复利型（适合绝大多数人的主路径）

**④ 宽基指数：低估买入+极限耐心**
- 赚谁的钱：**牛短熊长结构下，恐慌者割在低位的筹码 + 国运本身**；
- 打法：全A/沪深300估值分位<20%时分批买入并持续定投，分位>80%后分批卖出，中间什么都不做（一轮周期3-7年，交易次数个位数）；
- 为什么轮得到你：这个策略要求「数年不动」，**基金有排名压力做不了，游资嫌慢看不上——耐心是散户少数没被剥夺的武器**；
- 风险：需要忍受买入后继续跌30%的可能，以及漫长的无聊；
- 结论：**对90%的人，这就是正确答案**。它不性感，但它是极少数「收益来源永不枯竭」的策略——因为人类的恐慌与贪婪永不枯竭。

**⑤ 红利低波（高股息策略）**
- 赚谁的钱：市场对「无成长」的过度厌恶（成长溢价的反面）+分红的现金流本身；
- A股加成：新「国九条」强化分红要求、险资与国家队天然买盘、利率下行期资产荒；
- 风险：拥挤后股息率被买低（2024年起已明显拥挤）；「价值陷阱」（分红不可持续的周期股伪装成红利股）；
- 结论：适合厌恶波动、需要现金流的资金，**买之前核查分红的可持续性**（盈利稳定性+分红率历史）。

**⑥ 深度基本面选股（价值/成长/困境反转）**
- 赚谁的钱：市场短期化带来的错误定价——机构受排名约束无法持有「两年后才兑现」的逻辑，你可以；
- 门槛（必须诚实）：真实的财务分析能力+产业认知+第07章的全套排雷技能+忍受长期跑输的心理结构。**这是所有路径中门槛最高的，远高于它看起来的样子**；
- 散户的现实优势区：自己职业半径内的行业（第10章第2环信息）+ 机构覆盖不到的小市值公司；
- 结论：值得作为终身能力去建设，但**在能力建成之前，别用主仓位练手**——用第④条打底，拿10-20%仓位练。

### 2.3 博弈型（少数人的窄门）

**⑦ 情绪/题材交易（打板、龙头、低吸）**
- 赚谁的钱：接力资金的时间差+散户的追涨冲动（第04章全部内容）；
- 门槛：全职盯盘、数年复盘、极强的止损执行力、承受50%+回撤的心理结构；
- 衰减：量化侵蚀溢价+监管压制空间，模式性价比十年来持续下行；
- 结论：**万里挑一的职业选手赛道**。判断自己是否适合的唯一诚实方法：拿一笔亏光不心疼的钱做满一年、每天复盘，看数据（不是感觉）说话。

**⑧ 量化/程序化（个人）**
- 现实：个人在高频领域对机构毫无胜算（速度、数据、成本全面碾压）；个人可行域在**低频规则化策略**（估值轮动、动量、事件驱动的自动执行）——本质是用程序锁住人性，赚的还是第④⑤⑥条的钱；
- 结论：编程能力是放大器不是edge本身，先有正期望逻辑再谈自动化。

### 2.4 伪路径黑名单（认清它们省下的钱最多）

| 伪路径 | 真相 |
| --- | --- |
| 荐股群/直播喊单/收费课带单 | 你不是客户，你是产品（接盘侠/流量/会费）——真能稳定盈利的人不需要赚你999 |
| 「跟着龙虎榜大佬买」 | 你看到的是他昨天的操作，你的买入正是他今天的退出流动性 |
| 高换手技术分析（每天画线短炒） | 手续费+滑点的确定性损耗>不确定的信号价值；指标是描述工具不是预测工具 |
| 内幕消息 | 到你耳朵里的「内幕」在食物链第6环，且真内幕交易违法 |
| 满仓梭哈一只「十倍股」 | 单票集中的破产概率数学（第12章）足以否决一切「确定性」 |

## 3. 组合方案：把路径装配成系统

**大多数人的合理结构（示意）：**

```
70%  核心仓：宽基指数低估定投 + 红利低波（路径④⑤）
        ——收益来源：周期与国运，几乎不需要盯盘
20%  卫星仓：能力圈内的深度选股 或 可转债策略（路径⑥②）
        ——收益来源：认知差，用它建设长期能力
10%  学费仓：任何你想尝试的博弈（路径⑦等）
        ——功能：满足手痒+测试天赋，亏完即停，绝不补充
```

**这个结构的深意**：它承认人性（手痒需要出口→10%仓给它），承认能力建设需要过程（20%仓练手），并保证在你最蠢的时期资产也在正期望轨道上（70%仓）。

**动态规则**：只有当卫星仓/学费仓用**两年以上的实盘数据**证明超越核心仓，才允许上调其比例——用数据而非感觉给自己升级权限。

## 4. 本章总结

1. **五问框架是策略的照妖镜**：赚谁的钱、凭什么是你、容量几何、怎么死、配不配你——五问全过才配进你的账户。
2. **散户的三大真实edge**：耐心（无排名压力）、小（无容量约束）、职业半径（第2环信息）。有效路径全部构建在这三者之上；无效路径全部是拿自己的短板（信息、速度、纪律）去撞机构的长板。
3. **对90%的人，答案是无聊的**：低估位置的宽基+红利打底，能力圈选股为辅，把主要人生精力投入本业——**A股最被低估的策略是「少交易」**。
4. **博弈型路径是真实存在的窄门**，但入场费是全职投入+数年学费+万里挑一的筛选率——用10%的学费仓测试自己，让数据而不是梦想做决定。
5. **一切策略都在衰减**（打新、双低、红利……无一例外）：拥挤度监控不是可选项，是策略的一部分。
