# 进阶第01章：融资市的政治经济学

> **本章核心问题：A股到底是为谁服务的？**
> 想彻底懂A股，第一步不是学K线、不是学财报，而是搞清楚这个市场的出生证明上写的是什么。
> 一切看似荒谬的现象——指数十几年不涨、IPO永不停歇、退市难如登天、政策一句话顶一万份研报——
> 在你理解了A股的「基因」之后，全部变得逻辑自洽。

---

## 1. 出生证明：A股为什么被创造出来

### 1.1 1990年的真实语境

上交所1990年12月开市，深交所同月试营业。表面上这是「改革开放引入市场经济」，但更具体的动因是：

- **80年代末国企大面积亏损**，银行贷款已经背不动了，财政也背不动了；
- 需要一个新的融资渠道，把民间储蓄导入国企——**股市就是这个渠道**；
- 早期上市指标是按省、按部委**分配**的，上市是一种「政策资源」，而不是市场选择。

这决定了A股的第一性原理：

> **A股首先是一个融资工具，其次才是一个投资场所。**
> 它的第一使命从来不是「让投资者赚钱」，而是「为需要钱的企业（早期是国企，后来是战略产业）低成本地筹到钱」。

### 1.2 「为国企解困」的历史遗产

90年代有一个公开的提法叫「国企三年脱困」，股市承担了明确的政治任务。这段历史留下了至今仍在起作用的遗产：

| 历史遗产 | 至今的表现 |
| --- | --- |
| 上市是稀缺资源、需要审批 | 壳价值、借壳炒作、退市难（壳还有用） |
| 融资优先于回报 | 分红文化长期薄弱，圈钱—再融资—减持一条龙 |
| 政府对市场负有「维稳」责任 | 政策市：跌多了会救，涨疯了会压 |
| 股票背后是「单位」不是「企业」 | 大量公司治理形同虚设，大股东=公司本身 |

### 1.3 使命的三次升级

A股的融资使命并没有消失，只是服务对象换了三代：

```
1990-2005   为国企解困融资（脱困、改制、剥离坏账后上市）
2005-2018   为经济转型融资（中小板、创业板：民企、地产链、消费）
2019-至今   为科技突围融资（科创板、注册制、北交所：半导体、硬科技、专精特新）
```

**科创板是理解当下A股的钥匙**：它2019年的火速推出（从宣布到开板仅259天），直接背景是贸易战与科技封锁。国家需要一个市场化渠道给「卡脖子」行业输血，让全民储蓄参与国家的科技军备竞赛。这不是阴谋论，这是公开的顶层设计——你可以在历次中央文件里读到「提高直接融资比重」这句话被重复了二十年。

## 2. 指数悖论：为什么上证指数十几年不涨

这是每个A股投资者最大的困惑，也是理解融资市最好的切入点。

### 2.1 悖论的表象

- 2007年上证指数最高6124点，此后近二十年再未接近；
- 3000点被反复穿越几十次，成为全民梗；
- 但同期：中国GDP翻了几倍，A股**总市值**从十几万亿涨到八九十万亿，上市公司数量从1500家涨到5000多家。

**市值涨了好几倍，指数原地踏步——钱去哪了？**

### 2.2 拆解：指数不涨的四个机制

**机制一：IPO持续抽血 + 高价发行。**
指数不涨不代表市场没扩容。总市值的增长大部分来自**新增股票**，而不是存量股票上涨。而且新股常以极高市盈率发行（注册制后动辄50-100倍PE），上市即是估值巅峰——等于新股民一进场就接下了透支未来多年成长的价格。

**机制二：解禁与减持的持续供给。**
一家公司IPO时流通盘可能只有10-25%，剩下的限售股在1-3年后陆续解禁。这意味着A股永远面临着一堵「未来卖压之墙」。产业资本（成本可能是几毛钱）对二级市场投资者（成本几十块）拥有碾压性的成本优势——**这是A股最大、最持久的不对等博弈**。

**机制三：指数编制的失真。**
上证指数是总市值加权、包含大量低增长巨型国企（银行、两桶油），且历史上新股上市第11天就计入指数（往往在爆炒的高位计入，随后阴跌拖累指数；2020年修改规则后有所改善）。它系统性地低估了市场中优质部分的回报。沪深300全收益指数、万得全A的长期表现远好于上证综指。

**机制四：牛短熊长的结构。**
散户主导+政策驱动的市场，涨起来是脉冲式的（几个月透支几年的涨幅），然后用数年时间消化。指数的「路径」极差，即使终点不算太差。

### 2.3 一笔诚实的总账

把A股当成一个整体资金池，每年的流入流出大致是：

```
流出（从二级市场拿走的钱）             流入（回馈给二级市场的钱）
────────────────────────             ────────────────────────
IPO募资                               现金分红
再融资（定增/配股/可转债）            回购注销（历史上极少，近年增加）
大股东与高管减持
印花税
券商佣金
基金管理费
```

在历史上的大多数年份，**左边远大于右边**。这就是「融资市」三个字的定量含义：市场作为整体，长期在给实体经济和中介机构输血，二级市场投资者整体是出血方。个体想赚钱，本质上是在一个**负和的池子里争夺相对优势**（结构性机会、错误定价、别人的错误）。

> 2023-2024年后情况在边际改善：新「国九条」强调分红回购、严控IPO与减持。这正是下一节要讲的「钟摆」。

## 3. 政策钟摆：融资市与投资市的永恒摇摆

### 3.1 钟摆模型

监管层面临一个永恒的两难：

- **想要融资功能**（服务实体、科技突围）→ 需要多发新股 → 抽血 → 市场下跌 → 没人买新股 → 融资功能丧失；
- **想要市场上涨**（财富效应、居民信心、化解质押风险）→ 需要暂停/放缓IPO、限制减持、引入长钱 → 市场回暖 → 融资冲动再起 → 回到第一步。

于是A股三十年呈现出一个清晰的钟摆运动：

```
市场火热 → IPO提速、再融资松绑、减持汹涌 → 供给压垮需求 → 熊市
   ↑                                                        ↓
牛市启动 ← 暂停IPO、限制减持、国家队进场、鼓励分红 ← 市场冰点、舆论沸腾
```

**历史上A股有过9次IPO暂停**，每一次都发生在市场极度低迷时。IPO节奏本身就是最诚实的市场温度计：
- IPO大提速 = 监管认为市场「承受得起」= 往往是顶部区域；
- IPO实质性暂停/锐减 = 市场跌到监管痛点了 = 往往是底部区域。

### 3.2 政策语言解码表

政策市里，读懂官方语言是基本功。以下是长期有效的翻译对照：

| 官方表述 | 实际含义 |
| --- | --- |
| 「活跃资本市场，提振投资者信心」 | 跌到影响大局了，托底政策要来了 |
| 「提高直接融资比重」 | IPO和再融资要放量，供给增加 |
| 「引导中长期资金入市」 | 短期没人买，动员保险/社保/汇金来买 |
| 「严厉打击违规减持/财务造假」 | 民愤太大，先办几个典型 |
| 「防止资金空转、脱实向虚」 | 涨太快了，要压杠杆、查配资 |
| 「健全常态化退市机制」 | 壳与垃圾股逻辑走弱（但执行看力度） |
| 「稳步推进注册制/全面注册制」 | 长期供给扩容，小盘股稀缺性下降 |

### 3.3 「政策底 ≠ 市场底」的机理

政策转向后市场往往还要再跌一段（历史上政策底到市场底通常间隔1-6个月），因为：
1. 政策从表态到落地有时滞；
2. 深套的资金把每次反弹当逃命机会（解套盘压力）；
3. 基本面（盈利）还在惯性下滑；
4. 只有当空头力量衰竭+增量资金真实进场，市场底才成立。

但反过来，**当政策组合拳密集到「不达目的不罢休」的程度时，做空/空仓就是在跟国家意志作对**——2024年「924」行情（央行创设互换便利与回购增持再贷款、多部委联合发布会）是教科书级案例：政策工具直接给股市提供弹药，市场在几个交易日内暴涨20%+。在A股，「Don't fight the Fed」的本地版本是「**别跟政治局作对**」。

## 4. 维稳逻辑：看不见的顶和看得见的底

### 4.1 市场的政治功能清单

A股对于治理体系而言，不只是融资渠道，还是：

- **社会情绪的稳定器**：两亿多股民、七亿多基民（含货基）背后是家庭财产，暴跌是社会稳定问题；
- **系统性风险的传导节点**：股权质押（2018年危机）、两融、雪球结构（2024年初）——跌破临界点会引发连锁爆仓，所以存在「不能让它跌穿」的隐形红线；
- **政策信号的放大器**：想扶持某个产业，最便宜的方式是让它的板块涨——财富效应吸引资本、人才、舆论自动涌入（2019-2021新能源、2023-2025 AI与半导体皆是如此）；
- **重要时点的「氛围组」**：重大会议、重要纪念日前后，市场往往被期待「平稳运行」。

### 4.2 这给交易者的三条推论

1. **A股的极端下跌有底**（国家队会出手），但底的位置只有事后才知道——不能因为「会救」就提前满仓抄底，救市往往发生在你想象不到的更低位置。
2. **A股的疯牛有顶**（涨得太疯监管会降温：查配资、收紧两融、暂缓ETF申购、媒体喊话），2015年和2024年10月初都验证过——在A股，**过热本身就是利空**。
3. **政策扶持的产业方向是A股最可靠的长线主线**，因为它同时驱动基本面（补贴订单）、资金面（引导资金）、情绪面（媒体叙事）三重力量。

## 5. 把第一章压缩成五句话

1. **A股的基因是融资市**：它为筹钱而生，投资者回报是副产品，不是目标函数。
2. **指数悖论不是谜团，是设计的必然结果**：高价IPO+持续解禁+失真编制+牛短熊长。
3. **市场在「融资功能」与「财富效应」之间钟摆运动**，IPO节奏是最诚实的温度计。
4. **暴跌有隐形的底，疯牛有隐形的顶**，因为市场承担着维稳与信号功能。
5. **在A股，最大的基本面是政策**——不是因为投资者愚昧，而是因为政策真的能改变企业的现金流、市场的资金供给和游戏规则本身。
