# 进阶第07章：大股东的一百种收割姿势

> **本章核心问题：与你博弈的终极对手不是庄家、不是机构，而是「生产股票的人」。**
> 游资赚你的钱要冒险，量化赚你的钱要建系统，
> 而大股东赚你的钱，只需要**卖出他几乎零成本得到的东西**。
> 这一章是全书最重要的「防身术」——它未必让你多赚，但能让你避开最深的坑。

---

## 1. 起点：为什么说「上市即巅峰」

一家公司IPO时，各方的动机高度一致地指向**定价最大化**：
- 大股东：发行价越高，同样稀释比例募到的钱越多、身价越高；
- 投行：承销费=募资额×费率，且超募部分费率更高；
- 老股东/PE/VC：等着解禁退出，市值越高越好；
- 地方政府：本地上市公司市值是政绩。

**没有任何一方的激励是「给二级市场留出上涨空间」。** 所以：
- IPO招股书是公司一生中财务数据最漂亮的时刻（上市前突击调节利润是常规操作）；
- 注册制下新股常以50-100倍PE发行，透支未来多年成长；
- 统计规律：**大量新股上市后1-3年内业绩「变脸」**（增速骤降甚至亏损）——不是巧合，是把利润提前挪到了上市前。

**防御姿势**：次新股在首份完整年报披露之前，默认其财务数据不可外推。

## 2. 减持的花样大全

减持是合法的，但「怎么减」的花样体现了A股金融工程的全部智慧：

| 姿势 | 操作 | 你需要知道的 |
| --- | --- | --- |
| **集中竞价直接卖** | 受预披露、比例限制（90天≤1%） | 最透明的一种，公告可查 |
| **大宗交易过桥** | 折价卖给接盘方，接盘方6个月后在二级市场卖出 | 规避集中竞价限制；连续折价大宗=批发式出货信号 |
| **转融通出借** | 把限售股借给券商供做空/融券（变相提前变现敞口） | 曾被用于「限售股实质流通」，2023-2024年舆论哗然后被叫停/收紧 |
| **换购ETF** | 用股票换购ETF份额再卖ETF | 规避减持预披露，2019年火过一阵后被限制 |
| **离婚式减持** | 离婚分割股份给配偶，配偶不受高管减持限制 | 多起知名案例后，2023年监管明确「离婚不豁免」 |
| **质押式「减持」** | 股权质押融资拿钱，股价跌破平仓线就「被动减持」 | 实质是把下跌风险转给券商和市场；质押比例>50%的公司自带爆仓引信 |
| **协议转让** | 5%以上大额股份场外转让 | 关注受让方身份：产业方接盘偏正面，神秘投资公司接盘偏负面 |
| **定增解禁套利** | 参与定增（8折拿票）→锁定期满即卖 | 定增解禁日前后常有异动 |
| **技术性辞职** | 高管辞职后减持限制放宽 | 董监高扎堆辞职=经典避雷信号 |

**2024年新规后的格局**：破发、破净、分红不达标的公司大股东不得减持——减持第一次被和「回报股东」挂钩。但道高一尺魔高一丈的游戏不会结束，**你要跟踪的不是具体规则，而是「大股东想不想走」这个意图本身**。

### 识别「想走」的意图信号
- 上市满3年（首发限售全解禁）+ 高位放量滞涨；
- 公司突然热衷蹭热点、改名、发布「战略合作」但无金额的公告（拉高配合减持）；
- 高送转（10转10）出现在解禁前后（拉低股价数字、增加流动性，方便出货）；
- 董监高亲属账户先行减持（公告里藏在犄角旮旯）。

## 3. 再融资与并购：更高级的抽水机

### 3.1 定增的暗面
定增本意是融资工具，但可以被玩成：
- **保底定增**（违规但屡禁不绝）：大股东私下承诺participants保本保收益 → 参与方无脑投 → 股价由「市场定价」变成「兑付安排」；
- **定增前洗澡**：融资前释放利空压低定增价（8折基础上再压低基数），参与方成本极低，解禁即抛压。

### 3.2 并购重组：「三高」的连环雷
2013-2016年并购潮的标准剧本，之后用十年时间爆雷：

```
高估值收购（PE 15-20倍买个游戏/影视/营销公司）
    ↓ 产生
高商誉（收购价-净资产 挂在账上，动辄几十亿）
    ↓ 绑定
高业绩承诺（对方承诺3年业绩，通常精确压线完成）
    ↓ 3年承诺期一过
业绩变脸 → 商誉减值（一次亏掉十年利润）→ 股价脚踝斩
```

**商誉排雷公式**：商誉/净资产 > 30% 的公司，进入每年1月（年报预告季）的高危名单。「商誉洗澡」常常和更换管理层、行业下行同步——新管理层乐于把历史包袱一次亏完，轻装上阵。

## 4. 财务造假：四大名案解剖

### 4.1 康美药业（2019）——「货币资金」造假的天花板
- 2019年4月，康美公告「会计差错更正」：**账上299.44亿货币资金不存在**；
- 此前多年，账面同时挂着数百亿货币资金和数百亿有息负债（**存贷双高**）——有钱为什么还借钱付利息？这个问题问出来就是答案；
- 结局：实控人获刑，A股首例证券集体诉讼（5.2万投资者获赔24.59亿），审计机构正中珠江被重罚。

### 4.2 康得新（2019）——「新材料白马」的122亿
- 连年高增长的明星白马股，账面122亿存款躺在北京银行；
- 暴雷方式极具讽刺性：**15亿的债券到期违约了**——账上122亿却还不起15亿？调查发现存款实际余额为零（资金被大股东通过资金归集协议实时划走）；
- **教训**：「账上有钱+债券违约」=资金被占用的铁证，出现即最后逃命机会。

### 4.3 獐子岛（2014-2019）——会跑的扇贝
- 2014年：扇贝「遭遇冷水团」绝收，巨亏；2017年：扇贝又「跑了」；2019年：扇贝「饿死了」；
- 本质：**生物资产（海底存货）无法盘点审计**，成为利润调节的完美黑箱。证监会最后动用北斗卫星轨迹证明采捕船作业区域造假；
- **教训**：存货不可验证的行业（水产养殖、农林牧渔、在途工程）天然具备造假便利，估值应永久折价。

### 4.4 乐视网（2010-2020）——用市值幻觉融资的庞氏结构
- 造假手法（后被认定IPO即造假）之外，更值得学的是它的**模式病**：「生态化反」的宏大叙事 → 高市值 → 质押融资/定增 → 烧钱扩张七大生态 → 需要更高市值 → 更宏大的叙事……
- 音乐停止于2016年资金链断裂。贾跃亭「下周回国」成为A股头号梗；
- **教训**：当一家公司的商业模式依赖「持续融资」而非「自身造血」，它的股价就是它的生命线，而它讲的每个故事都是融资工具。识别指标：经营现金流常年为负+融资现金流常年为正+故事越讲越大。

## 5. 排雷清单：财务与治理的24个危险信号

**财务信号（读财报时机械核查）：**
1. 存贷双高（大额货币资金+大额有息负债并存）；
2. 应收账款增速远超营收增速（赊销冲业绩/虚构收入）；
3. 毛利率显著高于同行且无法解释（茅台可以，无名公司不行）；
4. 经营现金流与净利润长期背离（利润是纸面的）；
5. 存货异常膨胀且属于难盘点品类；
6. 在建工程常年不转固（藏费用）/固定资产周转率异常；
7. 其他应收款巨大（资金占用的经典藏身处）；
8. 商誉/净资产>30%；
9. 研发资本化率突然提高（把费用挪去资产端）；
10. 前五大客户/供应商高度集中且是陌生公司（关联交易嫌疑）；
11. 税收数据与利润不匹配（增值税、所得税交叉验证）；
12. 分红极少但账上「趴着巨款」（钱可能不存在）。

**治理信号（比财务信号更早）：**
13. 审计机构变更，尤其从大所换小所；
14. 年报被出具「保留意见/无法表示意见」（直接一票否决）；
15. 财务总监、董秘频繁离职；
16. 董监高及亲属密集减持；
17. 实控人高比例质押（>60%）；
18. 频繁变更主业/公司名称/蹭热点；
19. 收到交易所问询函且回复含糊、反复延期；
20. 大存大贷的同时还在高息发债；
21. 关联方占款历史（有过一次就会有第二次）；
22. 媒体/做空机构质疑后公司只骂不答；
23. 实控人有失信记录、场外负债传闻；
24. 「白马股」被基金极度重仓+从无质疑声音（康美康得新暴雷前都是机构重仓白马——**共识不等于安全**）。

**使用原则**：这份清单是**排除法**工具。命中3条以上直接放弃，不要用「但是它逻辑好」说服自己。A股5000多家公司，错杀一百家你毫无损失，踩中一家你损失70%。

## 6. 本章总结

1. **IPO定价机制决定「上市即巅峰」是常态**——所有参与定价的人都被激励往高了定，没人替你留空间。
2. **减持花样会不断进化，但意图信号是恒定的**：解禁日历+蹭热点公告+高送转+高管辞职潮=「想走」。
3. **「三高并购→商誉减值」是慢性雷，「存贷双高→资金占用」是急性雷**，两者都写在报表上，暴雷前至少提前一年可见。
4. **四大名案的公共教训**：造假的破绽永远在「钱的真实性」（现金流、利息、分红能力），不在利润表；机构重仓与白马光环不提供任何保护。
5. **排雷用排除法，宁可错杀**：在一个有5000+选择的市场里，回避可疑者的机会成本≈0。
