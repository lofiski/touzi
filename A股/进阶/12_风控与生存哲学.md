# 进阶第12章：风控与生存哲学

> **本章核心问题：怎么保证自己一直在牌桌上？**
> 交易者的死因排行榜上，「判断错误」远排不到第一。
> 第一名是**杠杆**，第二名是**集中**，第三名是**在极端行情里失去选择权**。
> 这一章先看死亡案例，再给生存数学，最后给可执行的制度。

---

## 1. 极端事件史：A股会发生什么级别的意外

风控的第一课不是公式，是**校准想象力**——你必须知道这个市场真实发生过什么：

| 事件 | 极端程度 | 死亡机制 |
| --- | --- | --- |
| 2015股灾（6-8月） | 「千股跌停」十余次；两个月沪指-45% | 配资强平→流动性螺旋：**想卖卖不出**（跌停排队），只能卖没跌停的→全面传染 |
| 2016熔断（1月） | 4天4次熔断，其中一天开盘29分钟收市 | 制度设计的磁吸效应：机制本身制造踩踏 |
| 2018股权质押危机 | 数百家公司逼近平仓线 | 反身性死亡螺旋（第10章） |
| 2024.2微盘股危机 | 微盘指数数日-30%+，「万股跌停」级踩踏 | 雪球敲入→DMA杠杆平仓→同质化策略互相践踏 |
| 个股级：长生生物（疫苗造假） | 32个跌停 | **黑天鹅+连续跌停=任何止损纪律都无法执行** |
| 个股级：乐视、康美、康得新 | 高位跌90%+ | 白马信仰+基金重仓也不豁免 |

**三条必须内化的结论：**
1. **A股的极端风险形态是「流动性消失」而非「价格下跌」**——跌停制度让你在最需要卖出的那天恰好卖不出。所以A股风控必须**前置**：仓位和标的选择在买入时就完成风控，而不是指望「跌了我会跑」；
2. **策略同质化是新型系统性风险**（2024.2）：你的持仓和某类拥挤资金重叠度越高，你越会在莫名其妙的日子被莫名其妙地践踏；
3. **单一个股的极限损失就是接近归零**，且可能不给你任何退出窗口（连续一字跌停）——这一条直接推导出单票仓位上限的必要性。

## 2. 杠杆：死因第一名的解剖

### 2.1 杠杆的数学陷阱

杠杆的问题不是「放大亏损」这么简单，而是**它把「暂时错误」变成「永久出局」**：

```
无杠杆：跌50% → 浮亏50%，拿住等周期回归，还活着
2倍杠杆：跌33% → 强平，本金归零，游戏结束
   ——而A股任何一只票、任何一年，跌33%都是家常便饭
```

**波动损耗**：杠杆下的复利是不对称的。2倍杠杆遇到「跌20%再涨25%」（标的回到原点），你的净值是 (1-40%)×(1+50%) = 0.9——**标的没亏，你亏10%**。波动本身就在磨损杠杆头寸，横盘震荡也能磨死你。

### 2.2 死亡案例谱系

- **2015场外配资（5-10倍）**：跌10-20%即爆仓。当年无数「几百万本金→几千万浮盈→倒欠配资公司」的真实故事，从暴富到负债只用了两周；
- **两融（1倍杠杆）也照样死**：2015、2018、2024年初都有大规模强平；融资盘的集体平仓线还会成为市场的引力位——**你的止损位是公开信息时，市场会来测试它**；
- **雪球结构（2024）**：「年化20%的稳健理财」，本质是卖出奇异期权——收有限的票息，承担无限的尾部。中证500跌穿敲入线后投资者承担全部下跌。**一切「稳定小赚」的产品，都要问一句：我是不是在做无限责任的保险公司？**
- **可转债正股质押、场外期权、期指满仓单边**：形态各异，死法相同——**尾部事件+强制平仓=不给第二次机会**。

**铁律：本金可以亏损，但永远不要让任何单一事件拥有「清零你」的权力。** 散户相对机构最大的特权就是没有强平线——加杠杆等于亲手把这个特权还给市场。

## 3. 生存的数学

### 3.1 回撤的非对称（再看一遍，这次是作为风控依据）

| 回撤 | 回本所需涨幅 | 含义 |
| --- | --- | --- |
| -10% | +11% | 正常波动，任何策略都会有 |
| -20% | +25% | 需要一年数一数二的行情才能修复 |
| -33% | +50% | 强平线（2倍杠杆） |
| -50% | +100% | 需要一轮牛市修复 |
| -70% | +233% | 需要一轮超级牛市+完美操作，实际≈永久损失 |

**推论：风控的全部目标可以简化为一句话——把组合级最大回撤控制在30%以内**（保证一轮正常周期内可修复），把单票级的「归零事件」隔离在伤不到全局的仓位内。

### 3.2 仓位公式：凯利的实用简化

凯利公式给出理论最优仓位 f = (bp - q) / b（b=赔率，p=胜率，q=1-p）。实战中你永远高估自己的p和b，所以：

- **用「半凯利」或更低**：牺牲少量理论增速，换取回撤大幅下降和参数误差的容错；
- **翻译成人话的三层仓位框架**：

```
① 单票上限：任何单一股票 ≤ 总资产15-20%
     （由「个股可能连续跌停归零」直接推出；确定性再高也不豁免——
       康得新暴雷前的「确定性」不比你现在这只低）
② 同一逻辑上限：同一条逻辑链的持仓（如全是AI链）≤ 40%
     （逻辑证伪时它们会一起死，分散五只票≠分散风险）
③ 总仓位随「环境×估值」调节：
     情绪退潮期/估值高位 → 降低；冰点+低估值分位 → 提高
     ——总仓位管理的依据是第04章情绪周期+第08章顶底特征，不是预感
```

### 3.3 A股特色：止损的前置化

成熟市场的止损纪律（「跌破X立刻卖」）在A股有个bug：**跌停日你根本卖不出**。所以A股的止损体系必须往前挪一层：

1. **标的筛选就是止损**：第07章24条排雷清单命中的票根本不进自选——最好的止损是不买会跌停的东西；
2. **事件日历就是止损**：解禁日、业绩预告期、承诺兑现期之前主动降仓，不与已知的雷同床；
3. **首次跌破逻辑就是止损**：买入理由被证伪的第一天卖出（哪怕当天只跌3%），不等技术位——等到技术位破位时往往已在跌停板上；
4. **时间也是止损**：短线逻辑的票三天不涨就该走（「买入理由是今天涨，它今天没涨=逻辑已错」）。

## 4. 制度化：把风控从「决心」变成「系统」

第09章讲过：对抗人性靠制度不靠意志。以下是可直接抄的执行制度：

**资金的分层隔离（进市场之前）：**
```
生活保障金（1-2年开支）—— 永不入市
中期确定性资金（3-5年内要用：买房/教育）—— 只配债/存款，不入股市
真正的长钱 —— 才是股票账户的钱
学费仓（第11章的10%）—— 独立小账户，亏完即停
```

**交易的流程锁：**
- 所有买入决策在**收盘后**做，写下：逻辑、仓位、证伪条件、预期持有期——盘中只执行，不新增决策；
- 任何单日操作 ≥2次 触发当日禁止交易（防上头）；
- 连续亏损3笔 → 强制空仓一周（防报复性交易）；
- 每月一次组合体检：每只持仓重答一遍「以现价现信息我今天还买它吗」。

**记录与复盘（长期最有价值的一条）：**
- 交易日志记「决策时的理由」而不只是盈亏——半年后回看，你会震惊于自己当时的真实决策质量与记忆中的偏差；
- 统计自己的**分策略胜率赔率**：数据会告诉你哪种钱你真的赚得到（第11章的升级依据）。

**空仓的合法性：**
- 空仓是一个主动仓位，而且常常是胜率最高的仓位（退潮期、顶部特征密集期）；
- 给自己立法：**每年必须有空仓/低仓的时段**，练习「不在场」的能力——做不到这条的人，本质上不是在投资，是在成瘾（第09章多巴胺机制）。

## 5. 本章总结

1. **A股风险的独特形态是「流动性消失」**：跌停制度让止损在最关键的日子失效，所以风控必须前置到标的选择和仓位分配，「跌了再跑」在A股是伪风控。
2. **杠杆把暂时错误变成永久出局**：无强平线是散户最大的特权，任何形式的杠杆（配资、两融、雪球、期权卖方）都在出让这个特权。
3. **生存数学三支柱**：回撤30%红线（保周期内可修复）、单票15-20%上限（隔离归零事件）、同逻辑40%上限（防伪分散）。
4. **A股止损四前置**：排雷筛选、事件日历、逻辑证伪日即卖、时间止损——都发生在跌停板之前。
5. **风控的最终形态是制度而非决心**：资金分层、盘后决策、连亏熔断、交易日志、强制空仓期——**把每一条你认同的原则，都翻译成一条不需要意志力的规则**。
