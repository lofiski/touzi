# 进阶第03章：庄家与操纵简史

> **本章核心问题：价格操纵在A股是如何运作的？它今天还存在吗？以什么形态？**
> 「庄家」是A股文化中最核心的词汇之一。散户的集体记忆、话语体系（「主力」「洗盘」「吸筹」）、
> 甚至技术分析在A股的流行方式，全部建立在坐庄时代的遗产之上。
> 不懂坐庄史，你就看不懂A股散户为什么这样思考。

---

## 1. 坐庄的黄金时代（1996-2001）

### 1.1 时代条件

90年代的A股具备坐庄的一切完美土壤：
- 流通盘极小（几千万股的公司遍地），几个亿就能控盘一只票；
- 没有涨跌幅限制（1996年底才设10%）、监管几乎空白、处罚极轻；
- 没有做空机制，庄家只需要做一件事：把价格拉上去，把货出给散户；
- 信息极度不对称：散户获取信息靠报纸和营业部小道消息。

### 1.2 教科书案例

**亿安科技（2000年）**：A股第一只百元股。四家关联公司联手控盘85%流通股，股价从26元拉到126元。事后证监会罚没8.98亿——但罚款根本执行不到位。散户记住的不是教训，而是「跟对庄就能暴富」。

**中科创业（2000-2001）**：操盘手吕梁（K先生）的「中科系」。这个案例的价值在于它**完整暴露了坐庄的商业模式**：
- 与上市公司大股东签协议（锁定筹码+配合出利好）；
- 用数百个个人账户（拖拉机账户）分仓吸筹；
- 用媒体和股评配合造势（当年著名股评人很多是庄家的喇叭）；
- 资金来自挪用的券商保证金和高息拆借。
2001年初资金链断裂，中科创业连续**9个跌停**，中科系崩盘。吕梁接受媒体采访自曝黑幕后失踪，成为A股史上最魔幻的一幕。

**德隆系（1997-2004）**：坐庄时代的巅峰与绝唱。唐万新控制的「三驾马车」（新疆屯河、合金投资、湘火炬）连续五六年缓慢上涨、翻了十几倍、几乎不回调——因为筹码高度控盘，股价完全是画出来的。德隆的野心是「产业整合+金融控股」，用坐庄的股票市值做质押融资，再收购金融机构挪用资金，滚成一个数百亿的自我循环体。2004年资金链断裂，三驾马车数周内跌去90%+，牵连数十家金融机构，唐万新入狱。**德隆的教训写进了此后所有监管框架：股票质押、关联交易、挪用客户资金的监管都源于此。**

### 1.3 经典坐庄四部曲（至今仍是散户话语体系的底层模板）

```
① 吸筹（数月-数年）：低位横盘震荡，打压股价吓走散户，暗中收集筹码
      盘面特征：长期阴跌缩量后，出现底部放量但价不涨；砸盘凶但总能收回

② 洗盘（穿插进行）：制造恐慌震出跟风盘，抬高市场平均成本
      盘面特征：突然的长阴线、跌破关键位又快速收复、涨前必有吓人一跳的动作

③ 拉升（数周-数月）：快速脱离成本区，配合利好消息、股评造势
      盘面特征：放量长阳、突破创新高、媒体开始出现这只票的「故事」

④ 出货（数周）：高位放量震荡，对倒制造活跃假象，把筹码派发给追高散户
      盘面特征：高位巨量滞涨、冲高回落、利好频出但股价不再涨
```

**必须说透的一点**：这套模板在今天被无数「主力思维」课程当作分析框架教给散户，但它描述的是25年前的市场。今天A股一天成交一两万亿、机构与量化占半壁江山、大数据监控每个账户——**单庄控盘一只票数年的模式已基本绝迹**。但散户的集体心智还停留在「每只票背后有个庄家在下一盘大棋」的时代，这种认知错位本身就是新型收割的土壤。

## 2. 过渡时代：从控盘庄到快庄（2005-2015）

股权分置改革后大小非流通、机构崛起、监管数字化，慢庄玩不下去了，操纵进化为「快进快出」：

**徐翔与泽熙模式（2009-2015）**——从「涨停板敢死队」到私募一哥：
- 早期打法：宁波解放南路营业部的涨停板敢死队，用大单封板制造强势假象，利用T+1下散户次日的追涨接力出货——**这是现代打板文化的直接源头**；
- 巅峰打法：泽熙时期升级为「信息+资金」双轮：与上市公司实控人合谋，约定高送转、重组、热点题材等利好的发布时机，徐翔提前建仓、利好发布后拉高出货，与实控人分成。2015年被捕，2017年判刑，罚没110亿。
- **徐翔案的启示**：A股操纵的最高形态从来不是技术，而是**与信息源头合谋**。散户研究K线时，人家在研究董事长。

**温州帮（2016-2017）**：慢庄绝迹后的暴力快庄：
- 手法特征：选流通盘极小的冷门股，用无量对倒直线拉升（一天拉百分之几不带回调），K线呈诡异的「直线上楼梯」；
- 出货方式同样暴力：毫无征兆的「断头铡刀」——连续一字跌停砸出去，根本不给散户出货机会；
- 温州帮的历史意义：证明了在监控时代，操纵只能越做越短、越做越暴力，「优雅出货」的时间窗口不存在了。

## 3. 现代形态：操纵的当代变种（2017至今）

大数据监控（交易所的监察系统可以穿透到每个账户的关联关系）让传统坐庄的风险收益比彻底恶化。操纵没有消失，而是变成了以下形态：

### 3.1 「伪市值管理」——机构化的合谋

**叶飞事件（2021年）**揭开的产业链：上市公司大股东 → 中间人（叶飞这类掮机构） → 接盘方（某些公私募、营业部资金）。玩法：大股东想减持/做股价，出钱雇「盘方」拉抬，找公募/私募用产品资金在高位「锁仓接货」，各环节分佣。叶飞因分赃不均公开举报，牵出十几只票。
**启示**：小市值、无业绩、无逻辑却异动的票，背后往往是这类灰色资金局。你看到的「主力进场」，可能只是一场分赃游戏的中间环节。

### 3.2 「团伙式打板」——游资的灰色地带

数个大户联合行动：一致行动地打板、拉抬、次日核按钮出货，配合社交媒体（股吧、微博大V、收费群）喊单引流。监管近年处罚的操纵案大多属于此类（处罚书里常见「集中资金优势、持股优势连续买卖」「盘中拉抬」「虚假申报（挂大单撤单）」等术语）。

### 3.3 「市值维护」的正规军版本

不违法但同样是价格管理：大股东回购、员工持股计划、定增前压价/解禁前拉价、股权激励行权价附近的股价「巧合」、可转债转股期的「精准」拉抬（促转股是刚需，见入门手册第14章）。**读懂公司行动日历（解禁日、行权价、转股价、质押平仓线），你就能预判很多「无消息异动」。**

### 3.4 监管的武器库

- **实时监控**：异常交易自动预警，穿透式账户监管（拖拉机账户基本失效）；
- **特停**（特别停牌）：连续暴涨的妖股被停牌核查——特停是情绪周期的人为断点，打板客最怕这个词；
- **窗口指导**：约谈游资大佬、限制账户交易权限；
- **龙虎榜与「关注函」**：舆论层面的降温工具。

## 4. 实战篇：识别「有人在里面」的信号清单

不是让你去跟庄（后面会讲为什么跟庄必死），而是让你**避开或者理解**这些票：

**筹码/价格异常：**
- 长期无基本面、无行业逻辑，却走出独立慢牛（控盘特征）；
- 无量空涨：换手率极低但天天涨（对倒画线）；
- K线「太漂亮」：均线完美多头排列、回调精确到分——自然交易不会这么干净；
- 十大流通股东出现多个陌生个人账户或注册地相同的投资公司。

**行为异常：**
- 冷门股突然连续登上龙虎榜，席位全是知名游资或偏门营业部；
- 大宗交易频繁+二级市场同步异动（过桥减持配合拉抬）；
- 利好公告的时机「太巧」：股价启动之后利好才出——说明有人先知道；
- 高位放出天量长上影/巨震——出货的标准指纹。

**为什么散户跟庄必死：**
1. 你不知道他的成本，他知道你的心理；
2. 你受T+1和涨跌停约束，他用底仓做T不受约束；
3. 洗盘和出货在盘面上**长得一模一样**（都是放量震荡），你只能猜，他不用猜；
4. 就算你真跟对了，出货那一刀（断头铡刀/连续跌停）就是专门砍给「跟对了的人」的。

## 5. 本章总结

1. **坐庄史就是A股散户的心智塑造史**：「主力」「洗盘」「吸筹」这套语言诞生于1990年代的控盘时代，但散户至今仍用它理解一个已经完全不同的市场——错位的认知模型是最大的风险。
2. **操纵的进化方向：越来越短、越来越暴力、越来越依赖信息合谋而非资金控盘。** 从德隆的五年慢牛，到温州帮的五天暴拉，到今天的三小时脉冲。
3. **最高级的操纵从来不在盘面上，在信息源头上**（徐翔模式、伪市值管理）。当你在分析K线时，问一句：这个价格背后，谁可能提前知道什么？
4. **公司行动日历是合法的「庄家意图说明书」**：解禁、质押线、转股价、行权价、定增价，标出了各方在什么价位有什么诉求。
5. 散户对「庄」的正确姿势只有两个字：**避开**。你的优势战场在别处（第11章）。

> 庄家时代落幕后，接管A股短线定价权的是一个更分散、更快、更适应监管的物种——游资。
> 他们创造了全世界独一无二的「涨停板艺术」与「情绪周期」。见第04章。
