# 进阶第06章：机构的游戏规则

> **本章核心问题：机构真的更专业吗？他们的钱到底怎么赚、怎么亏？**
> 散户对机构有两种典型误解：一种把机构当神（「机构建仓了赶紧跟」），
> 一种把机构当鬼（「机构就是来割散户的」）。
> 真相更有趣：**机构是一群被自身激励结构囚禁的聪明人**。
> 看懂他们的牢笼，你就能预判他们的行为。

---

## 1. 公募基金：委托代理问题的教科书

### 1.1 三层扭曲的激励链

```
基民（出钱的人）：想要绝对收益——赚钱
    ↓ 但他用「近期涨幅」选基金
基金公司（管钱的公司）：想要规模——管理费=规模×1.2%
    ↓ 于是它考核经理的「相对排名」
基金经理（做决策的人）：想要排名——排名决定奖金、晋升、流量
```

**每一层的目标都不一样**，最终行为由最后一层决定：基金经理优化的不是「帮你赚钱」，而是「不比同行差」。由此推出公募的四大定理：

**定理一：高点发行定理。** 牛市基金好卖 → 公司密集发新产品 → 募到的巨量资金必须建仓 → 进一步推高市场 → 顶部形成时公募规模恰好达到峰值。**「爆款基金=阶段顶部」是A股胜率最高的反向指标之一**（2015年6月、2021年1月的爆款潮均精确对应顶部）。

**定理二：抱团定理。** 排名是相对游戏：买冷门票做对了排名升一点，做错了直接垫底失业；买大家都买的票，错了一起错（法不责众），对了跟着涨。**理性的经理必然趋向抱团**——这不是道德问题，是纳什均衡。

**定理三：风格漂移定理。** 什么涨买什么。挂着「价值精选」名字的基金满仓TMT，是排名压力下的常态。看基金持仓别看名字，看季报前十大。

**定理四：申赎绑架定理。** 牛市顶部基民疯狂申购，逼着经理高位买入；熊市底部基民恐慌赎回，逼着经理低位卖出。**公募整体是一台「高买低卖」的被动机器**，它的仓位数据（股票型基金仓位「88魔咒」——仓位超88%往往见顶）因此成为反向指标。

### 1.2 案例精读：核心资产抱团的兴衰（2019-2024）

这是理解机构行为最完整的一轮样本，值得逐年复盘：

- **2019-2020 形成**：宏观逻辑（经济增速下台阶→确定性溢价）+外资持续买入龙头（茅台、美的、恒瑞）+公募跟进 →「买赛道龙头」成为共识。「茅指数」「核心资产」「永远涨」成为流行语；
- **2020下半年-2021年初 疯狂**：明星基金经理出圈成为顶流（粉丝团、代言式营销），单日募集千亿的爆款基金出现，茅台估值突破70倍PE（一个增速15%的公司）。**「好公司不问价格」——当估值纪律被公开抛弃，就是终局信号**；
- **2021年2月18日（春节后首个交易日）崩塌开始**：无明显利空，仅仅是美债收益率上行触发估值逻辑松动。抱团的解体和它的形成一样是正反馈：下跌→赎回→被迫卖出重仓股→继续下跌。茅指数成分股此后两三年普遍下跌40-60%；
- **2021-2024 余波**：顶流基金经理跌落神坛，「新能源一哥」「医药女神」的产品腰斩，基民用三年时间学会「明星基金经理」是营销概念。

**必须内化的教训**：
1. 抱团没有错，错的是**抱团末期的估值**——任何逻辑在70倍PE的白酒面前都不再是逻辑；
2. 机构共识的顶点 = 边际买家耗尽的时点。**当一个策略成为全民共识，它的超额收益已经被透支完毕**（这是第10章反身性的预演）；
3. 崩塌不需要利空，**「涨不动」本身就是抱团结构最大的利空**。

## 2. 卖方研究：研报的话术学

券商分析师（卖方）的收入来自基金（买方）的佣金分仓和上市公司的关系维护，**不来自研报的准确性**。由此产生一套需要翻译的语言体系：

### 2.1 评级翻译表

| 研报语言 | 实际含义 |
| --- | --- |
| 买入/强烈推荐 | 正常状态（90%以上研报都是买入——不给买入评级没法维护关系） |
| 增持/推荐 | 略有保留，相当于其他市场的「中性」 |
| 中性/持有 | **实际是看空**——卖方语言里最重的负面词 |
| 卖出 | 几乎绝迹；出现即重大事件 |
| 「低于预期」 | 业绩很差 |
| 「静待拐点」「布局良机」 | 已经跌很惨了，之前的推荐被套 |
| 「维持盈利预测不变」（股价已跌30%） | 分析师不想承认错误 |
| 目标价上调（股价刚涨完） | 追认现实，研报跟着股价走而非相反 |

### 2.2 研报的正确用法

研报的价值**不在结论，在材料**：
- 产业链图谱、竞争格局、专业名词扫盲——卖方做得比你好得多，白嫖这部分；
- 盈利预测的**一致预期**（Wind/东财可查）是市场的锚，你的差异化认知必须相对这个锚定义（超预期/低于预期才驱动股价，好坏本身不驱动）；
- **研报覆盖密度本身是情绪指标**：一个月内30篇首次覆盖 = 题材过热；无人覆盖的行业 = 潜在认知差矿区。

### 2.3 灰色地带

调研纪要外流、「专家电话会」游走内幕边缘、分析师与游资配合的「小作文」（盘中流传的匿名利好传闻）——2023年监管开始严打「小作文」。**你在社群里看到的「内部消息」，是信息食物链的最末端**（第10章展开）。

## 3. 量化：被误解最深的玩家

### 3.1 量化到底在赚什么钱

主流量化策略的收益来源排序：
1. **散户的行为偏差**（最大来源）：追涨杀跌、挂单习惯、尾盘冲动——统计上可预测，量化用上千个因子捕捉这些模式，高胜率小额收割，日内千万次；
2. **打板/情绪资金的模式**：涨停板博弈的行为特征鲜明，量化反向收割（炸板砸盘、撬板套利）；
3. **指数编制与申赎的机械行为**：调仓套利、ETF申赎套利；
4. **真正的基本面alpha**：占比最小。

**推论**：你的交易越像「典型散户/典型打板客」，你就越是量化的直接猎物。降低交易频率是普通人对抗量化最简单的方法——**不给它收割你行为模式的机会**。

### 3.2 2024年2月：量化的至暗时刻（必学案例）

- 背景：雪球产品敲入（详见第12章）压垮中证500/1000期指 → 中性策略空头端巨亏 → 同时小微盘（量化超额的主要猎场）流动性枯竭；
- **DMA业务**（量化中性+4倍杠杆的券商通道）被迫平仓 → 卖小微盘现货 → 微盘股指数几天内暴跌30%+，出现「万股跌停」级别的踩踏；
- 国家队买大盘ETF救市 → 大小盘极端分化 → 部分量化为回补基准偏离又追买大盘 → 策略集体失灵；
- 事后：监管收紧DMA杠杆、限制高频（申报速率、撤单率监控）、量化进入强监管时代。

**教训**：**同质化策略+杠杆=系统性脆弱**。任何「年年赚钱的稳定策略」，在容量拥挤后都会在某个极端日把多年收益一次吐光。这条规律对散户策略同样成立（可转债、打新、微盘股轮动都经历过类似的拥挤-崩塌）。

## 4. 保险/社保/外资：真正值得抄作业的钱

- **社保基金**：A股长期业绩最好的机构（年化约8%+），风格是低估值+分散+逆向（暴跌时加仓）。社保组合新进的票值得研究（季报可查）；
- **保险资金**：负债久期长，偏好高股息（银行、公用事业），是红利策略的定价者。险资举牌潮往往出现在市场底部区域（资产荒逼它买股票）；
- **北向/QFII**：偏好ROE稳定的行业龙头。它们的共同点是：**激励结构健康（真正的长钱、绝对收益导向），所以行为模式与「聪明钱」最接近**。抄作业优先级：社保 > 险资/外资 > 公募 >> 游资。

## 5. 本章总结

1. **机构行为=激励结构的函数**：公募被排名与申赎绑架、卖方被佣金关系绑架、量化被容量与同质化绑架。看懂牢笼即可预判囚徒。
2. **公募四大反向指标**：爆款基金、88魔咒、明星经理出圈、抱团股「不问价格」——全部对应顶部区域。
3. **研报读材料不读结论，「中性」评级=看空，覆盖密度=情绪温度计**。
4. **量化收割的是「典型行为模式」**——你越不典型（低频、逆情绪、长持有），越不在它的猎杀名单上。
5. **抄作业抄激励健康的钱**（社保、险资、外资），别抄被短期排名绑架的钱。
6. 2021抱团崩塌与2024量化危机共享同一条元规律：**任何策略的超额收益都会被拥挤消灭，拥挤的尽头是踩踏**。把这条规律刻在脑子里，它会在未来无数次救你。
