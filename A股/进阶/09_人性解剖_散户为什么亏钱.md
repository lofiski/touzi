# 进阶第09章：人性解剖——散户为什么亏钱

> **本章核心问题：为什么「七亏二平一赚」？为什么明知道还是做不到？**
> 前面八章讲的是市场和对手。这一章讲你自己——你的大脑。
> 结论先行：**散户的亏损不是因为蠢，而是因为人脑的默认设置就是为亏钱优化的。**
> 市场是一台专门利用这些默认设置的机器。

---

## 1. 铁一般的数据

- 上交所研究报告（基于2016.1-2019.6全样本账户数据）：**各资金规模的散户群体，账户平均收益全部为负**；其中散户的择时贡献和选股贡献双负，唯一为正的群体是机构和公司法人；
- 常见的口径统计：单个年度盈利的散户约三成，**连续三年盈利的比例降到个位数**；
- 「七亏二平一赚」是长期结构，不是熊市现象——**2007和2015大牛市年度，仍有大量散户亏损**（高换手在牛市中反复追高割肉）；
- 交易成本的确定性侵蚀：一个换手率500%/年的账户（散户常态），仅佣金+印花税+滑点每年就吃掉本金的2-4%。十年复利下来，成本本身就足以造成显著亏损。

**先接受这个基准率，再谈技术。** 任何让你觉得「赚钱不难」的内容，都在对你隐瞒分母。

---

## 2. 八大心理偏差的A股加强版

行为金融学的经典偏差，在A股的制度环境（涨跌停、T+1、散户结构）下全部被放大。

### 2.1 处置效应（卖盈持亏）——头号杀手
**行为**：赚10%就落袋为安，亏30%却拿着「等回本」。
**机制**：卖出盈利=确认「我对了」（愉悦），卖出亏损=确认「我错了」（痛苦）。人为了逃避认错的痛苦，宁可承受更大的实际损失。
**后果**：**系统性地砍掉盈利的头、留住亏损的尾**——你的组合会自动演化成一篮子亏损股。所有长期亏损账户打开看，几乎全是深套的「等回本」持仓。
**数学补刀**：亏损的回本需求是非对称的——亏20%需赚25%，亏50%需赚100%，亏70%需赚233%。「等回本」等的往往是数学上近乎不可能的事件。

### 2.2 过度自信与过度交易
**数据**：A股散户年换手率长期位居全球第一（数倍于美股散户）。
**机制**：牛市初期的贝塔收益被归因为「我的水平」（自我归因偏差）→ 加大频率和仓位 → 恰好在市场最热、胜率最低时交易最猛。
**加强版**：A股的涨停板和题材轮动制造了远多于成熟市场的「暴富目击事件」——你总能看到别人抓到涨停，FOMO被制度性地每天刺激。

### 2.3 锚定效应
**行为**：「我的成本是20块」「它以前到过60」——用无意义的历史数字做决策。
**真相**：**你的成本价对市场没有任何意义**，股票不知道你在哪买的。唯一有意义的问题是：「以现价、现在的信息，我今天还会买它吗？」不会买=应该卖。
**A股加强版**：前高、整数关口（3000点！）、发行价，全民锚定同样的数字，锚定本身反而成了可自我实现的技术位——但那是博弈价值，不是你的持仓依据。

### 2.4 损失厌恶与「回本就卖」
亏损的痛感约是等额盈利快感的2-2.5倍。深套多年的票一涨回成本立刻卖出（痛苦终于解除）——**然后它开始主升**。「回本就卖」卖掉的往往是刚刚反转的强势票，这是处置效应的镜像补刀。

### 2.5 从众与信息瀑布
散户的信息源（股吧、微信群、短视频、荐股直播）在结构上是**情绪共振器**：涨的时候全是看多声音，跌的时候全是恐慌声音。你以为自己在「参考多方观点」，实际是在同一个情绪回音室里给自己的冲动找论据。
**A股加强版**：散户占比高 → 从众行为直接驱动价格 → 「跟着大家买真的会涨」在短期成立 → 强化从众习惯 → 直到高潮那天大家一起被埋。

### 2.6 彩票偏好
散户系统性偏爱低价股、小盘股、故事股（「10块的票比100块的便宜」「小票弹性大」）——为极小概率的暴富支付持续的期望损耗，与买彩票同构。量化基金收割的第一大因子就是这个偏好（低价小票长期跑输的「彩票溢价」）。

### 2.7 近因效应与牛市顶部开户
人用最近的经验外推未来：连涨三个月=「牛市来了会一直涨」。开户数据与指数点位近乎完全同步——**制度性地保证了散户群体的平均建仓成本在山顶**。2007年10月、2015年5月、2024年10月的开户潮，无一例外。

### 2.8 沉没成本与摊平陷阱
「都亏这么多了，卖了就白亏了」→ 继续持有甚至补仓摊平。摊平在数学上只对「你确定判断正确、只是早了」的情形成立——而散户摊平的绝大多数场景是**基本面已经变坏的票**，等于往漏船上加货。区分「越跌越买的价值投资」和「不肯认错的沉没成本」只有一个标准：**你的买入逻辑是否被证伪了**。逻辑还在→可以补；逻辑没了→价格越低越该卖。

## 3. 神经科学补充：为什么「知道了还是做不到」

- **随机奖励机制**：股票的涨跌是变率强化（variable-ratio reinforcement）——与老虎机、短视频完全相同的成瘾结构。多巴胺在「不确定的期待」时分泌最猛（下单后等开盘的那种兴奋），而不是在赚钱时。**很多人交易不是为了赚钱，是为了那个期待感**，亏钱只是成瘾的代价；
- **情绪压倒前额叶**：恐惧和贪婪激活的脑区（杏仁核）反应速度快于理性脑区（前额叶皮层）数百毫秒。盘中实时决策在神经层面就是「情绪先开枪、理性后编理由」；
- **推论**：对抗人性不能靠「下次我忍住」（意志力是消耗品），只能靠**制度设计**——把决策从盘中挪到盘后（收盘后写好明天的计划价位）、用条件单代替手动下单、物理隔离（删掉手机行情App只留下单工具）、降低频率。**用规则锁住那个不可靠的自己。**

## 4. 一个散户的标准生命周期（对号入座）

```
第一阶段：新手运气期（入场，通常在牛市中后段）
  随便买都赚 → 「炒股也就这样」→ 加仓、加频率、告诉亲友
第二阶段：第一次重创（牛转熊/题材退潮）
  利润回吐+本金受损 → 拒绝止损（处置效应）→ 深套 → 「长期投资」（被动的）
第三阶段：求知期（交学费）
  疯狂学习：K线→指标→缠论→财报→估值……每种方法浅尝辄止
  每换一种方法亏一轮（用新方法接前一种方法的盘）
第四阶段：分岔口（多数人止步于此）
  路径A（约80%）：心灰意冷销户离场，或留一笔「死仓」装死，牛市顶部再回来一次
  路径B（约15%）：变成「资深韭菜」——懂得多、亏得慢，但始终没有正期望的模式
  路径C（<5%）：完成三个觉醒（见下），进入持续盈利
第五阶段（仅路径C）：专一期
  收缩到一种模式+一个能力圈 → 大量放弃「不属于我的机会」→ 靠纪律和复利活着
```

**三个觉醒**（从路径B到路径C的分水岭）：
1. **认清赚谁的钱**：我的每笔盈利来自谁的失误？（答不出=没有edge，见第11章）；
2. **认清自己的性格边界**：急性子做不了价值、扛不住回撤做不了趋势、盯不了盘做不了短线——**模式必须匹配性格，而不是匹配「哪种最赚钱」**；
3. **认清频率与胜率的关系**：机会是等出来的，不是找出来的。空仓是一种持仓。

## 6. 本章总结

1. **七亏二平一赚是结构，不是运气分布**：交易成本+行为偏差+信息位置+入场时机（顶部开户），四重系统性劣势叠加的必然结果。
2. **头号杀手是处置效应**：卖盈持亏让组合自动劣化，配合亏损数学的非对称性（亏50%要赚100%），构成大多数账户的死亡路径。
3. **你的很多交易冲动不是判断，是多巴胺**——市场的随机奖励结构与老虎机同构，先承认成瘾机制，再谈交易系统。
4. **对抗人性靠制度不靠意志**：盘后决策、条件单、降频、物理隔离。规则的意义是锁住那个盘中的自己。
5. **散户生命周期的分水岭是三个觉醒**：赚谁的钱、性格边界、等待的价值。完成之前，学再多技术都只是换着姿势亏钱。

> 个体的偏差汇成集体的情绪，集体的情绪反过来改变市场本身——预期竟然能创造现实。
