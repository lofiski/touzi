# 第06章：A股估值框架与方法论

---

## 1. A股估值的特殊性

A股的估值体系与港股、美股有显著差异，不能直接套用。

### 1.1 A股估值整体偏高于港股

**A股整体PE（沪深300）历史区间：**
- 历史均值：约12-15倍
- 牛市高峰：2015年曾达35倍以上
- 2024-2025年低位：约10-12倍（接近历史底部）

**同行业A/H溢价（A股比H股贵的幅度）：**
- 平均：25-65%
- 内地银行股：A股比H股贵约20-40%
- 白酒（A股独有，港股无对应）：无可比参照

### 1.2 A股估值的驱动因素（与基本面的关系）

**短期（1-3个月）：** 情绪（散户主导）+ 政策预期 >> 基本面
**中期（6-18个月）：** 业绩兑现 + 流动性 ≈ 重要
**长期（2年以上）：** 基本面主导，但受政策干预程度仍高

**结论：** A股的短期定价效率低于港股/美股，基本面估值在短期更容易被忽视，但长期仍有效。这意味着价值投资者在A股需要更长的耐心，同时也有机会找到被短期情绪错误定价的公司。

## 2. 市盈率（PE）在A股的应用

### 2.1 A股各板块PE参考（2026年Q1）

| 板块         | PE区间    | 特点                      |
| ---------- | ------- | ----------------------- |
| 白酒（贵州茅台等）  | 20-30x  | 溢价来自消费品牌护城河+稀缺性         |
| 银行         | 4-7x    | 资产质量担忧+净息差压缩            |
| 保险         | 8-15x   | 以PEV为主，PE仅参考            |
| 新能源（光伏/风电） | 10-20x  | 产能过剩拖累盈利，估值随盈利能力动态调整    |
| 新能源汽车      | 15-40x  | 竞争激烈，看增速                |
| 半导体        | 40-100x | 国产替代逻辑+周期性，PE失真，看PEG或PS |
| 医药（传统）     | 15-25x  | 集采压力，估值收缩               |
| 创新药        | 亏损或高PE  | 类18A章估值逻辑               |
| 军工         | 40-80x  | 政策驱动，估值溢价来自政策确定性        |
| 消费（中端）     | 15-25x  | 受消费弱复苏影响                |
| 公用事业       | 10-18x  | 稳定现金流，高息                |

### 2.2 "市梦率"现象（A股特有）

**A股存在持续的"市梦率"（Dream P/E）现象：** 部分概念/题材股的估值远超基本面支撑，纯粹依靠散户想象空间维持高估值。

**历史典型：**
- 2015年互联网+概念：很多传统企业改名加"互联网"，PE可以炒到300倍以上
- 2020年半导体国产替代：部分公司研发能力不强，但PE被炒到200倍以上
- 2023年AI：ChatGPT发布后，与AI相关的A股标的无论基本面如何，股价均大涨

**对投资者的含义：**
- 市梦率是真实存在的短期赚钱机会（如果能在崩溃前出逃）
- 也是绞杀大多数追高散户的陷阱
- 基本面投资者应对此保持克制，不轻易追高题材股

## 3. 市净率（PB）在A股的应用

**A股PB < 1的公司数量多：**
截至2025年底，A股有约600-800家公司PB < 1（破净股）

**2024年监管政策变化：** 证监会明确表示"破净股"要加大分红力度，破净是触发监管关注的信号，同时也是投资机会的潜在信号（但需结合ROE分析）。

**破净股筛查条件（寻找机会的起点）：**
```
PB < 1.0
AND ROE > 8%（排除低ROE导致的合理破净）
AND 非金融行业（金融行业破净另有逻辑）
AND 无连续亏损
AND 大股东未大量减持
```

## 4. A股的分部估值（SotP）

A股存在大量集团型公司（尤其是国企央企）。对这类公司，分部估值是核心方法：

**典型案例框架（以某综合型国企为例）：**

```
子业务A（周期性）：EV/EBITDA × 5-8倍
子业务B（成长性）：PS × 2-4倍，或PEG × 1.0
子业务C（金融资产）：PB × 1.0-1.5倍
现金及其他资产：账面价值
- 负债（净债务）
- 集团折扣（Conglomerate Discount，通常15-25%）
= 集团合理市值
```

**集团折扣存在的原因：** 集团内部资源分配低效、管理层激励不足（尤其国企）、信息不透明。

## 5. DCF在A股的适用性

**DCF框架与港股一致（见港股手册第06章），A股的特殊参数调整：**

**WACC参数调整：**
- 无风险利率：中国10年期国债收益率（约2.0-2.5%，2026年）← 远低于美国
- 中国股权风险溢价（ERP）：约7-9%（高于美国，因制度风险）
- A股Beta：从东方财富/Wind查，通常与沪深300做比较
- 典型WACC：蓝筹股约8-11%，成长股约11-14%

**终期增长率（g）：**
- 参考中国长期GDP增速预期（4-5%区间），通常取3-4%
- 远高于美国/欧洲的1-2%（反映中国经济仍有较高长期增速预期）

## 6. A股特有的估值指标

### 6.1 市值/政府补贴比

衡量公司盈利对政府补贴的依赖程度：
- 政府补贴/净利润 < 10%：正常
- 政府补贴/净利润 30-50%：需关注盈利质量
- 政府补贴/净利润 > 50%：去掉补贴就亏损，警惕

### 6.2 研发费用率（对科技公司）

**研发费用/营业收入：**
- 互联网平台：5-15%
- 半导体设备/材料：15-25%
- 医药/CRO：15-30%
- 传统制造业：<5%（正常）

**A股特别关注：研发资本化比例（研发支出中计入资产的比例）**
- 普遍规律：资本化比例越高，当期报出的利润越好看（因为当期费用化的研发更少）
- 行业合理资本化比例：通常10-30%，超过50%需关注

### 6.3 股息率与分红政策（2023年新规后更重要）

**2023年底证监会新规：**
- 上市公司连续2年不分红，且净利润超过2亿，证监会将进行重点监管
- 控股股东减持受分红达标率约束

这推动了A股分红文化的根本性转变：

**A股股息率参考（2026年）：**
- 中证红利指数成分股：平均股息率约4-6%
- 银行股：约5-7%
- 主板蓝筹：约2-4%
- 成长股：通常<1%或不分红

**股息率>3%且连续5年稳定分红**：是价值投资者的重要筛选条件。

## 7. 估值的综合使用

**A股估值方法组合建议：**

| 公司类型         | 主要估值方法            | 辅助方法        |
| ------------ | ----------------- | ----------- |
| 稳定盈利型（银行/白酒） | PE + PB + DDM     | 股息率、ROE     |
| 成长型（科技/消费）   | PEG + EV/EBITDA   | DCF（远期）     |
| 亏损成长股（科创板）   | EV/Sales + 现金跑道   | 竞品估值        |
| 资源/周期股       | EV/EBITDA + PB    | 大宗商品价格敏感性分析 |
| 金融（保险）       | P/EV + NBV Margin | ROE         |
| 平台经济         | 用户数/MAU × ARPU    | DCF         |
