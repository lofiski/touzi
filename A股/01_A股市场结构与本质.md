# 第01章：A股市场结构与本质

---

## 1. A股的基本性质

A股（A-shares）是在**中国内地注册、在上海或深圳证券交易所上市、以人民币计价**的股票。

**在岸市场（Onshore Market）的本质：**
- 资本账户管制：人民币不能自由兑换出境，外资进入需要通过QFII/RQFII/沪深股通等受管制通道
- 定价权由内地资金主导：外资持仓约5-7%，内地资金（散户+机构）占绝对主导
- 监管主体是中国证监会（CSRC），交易所是自律监管机构

**与港股对比的核心差异：**

| 维度     | A股                            | 港股        |
| ------ | ----------------------------- | --------- |
| 市场性质   | 在岸，资金管制                       | 离岸，资金自由流动 |
| 散户占比   | ~70-80%（成交量）                  | ~15-20%   |
| 定价主导力量 | 内地散户情绪+政策                     | 外资+南下资金   |
| 涨跌停    | 有（±10%主板，±20%科创/创业，±30%新股前五天） | 无         |
| 交割     | T+1（当日买入，次日可卖）                | T+2       |
| 退市     | 逐步收紧，仍比港股严格                   | 宽松（壳股多）   |
| 信息语言   | 中文                            | 中英双语      |

## 2. A股的三大交易所四大市场

### 2.1 上海证券交易所（上交所，SSE）

**主板（Main Board）：**
- 传统蓝筹、国企、大型民企
- 代码以"6"开头（如600519 贵州茅台）
- 涨跌停：±10%

**科创板（STAR Market，2019年7月开市）：**
- 硬科技、生物医药、半导体、集成电路
- 代码以"688"开头（如688981 中芯国际）
- 涨跌停：±20%（上市前5日无涨跌停限制）
- 投资者门槛：证券账户资产≥50万元，且有24个月股票交易经验

### 2.2 深圳证券交易所（深交所，SZSE）

**主板（含原中小板整合后）：**
- 代码以"000"或"001"开头
- 涨跌停：±10%

**创业板（ChiNext，2009年开市，2020年注册制改革）：**
- 成长型创新企业，科技、新经济
- 代码以"300"开头（如300750 宁德时代）
- 涨跌停：±20%（上市前5日无涨跌停）
- 投资者门槛：证券账户资产≥10万元，且有24个月股票交易经验

### 2.3 北京证券交易所（北交所，BSE，2021年11月开市）

- 前身为新三板精选层
- 服务创新型中小企业
- 代码以"8"开头（如835895，或部分为4位码）
- 涨跌停：±30%（开市前5日无涨跌停）
- 投资者门槛：证券账户资产≥50万元，且有24个月股票交易经验

### 2.4 四个市场的整体规模（2026年Q1参考）

| 市场    | 上市公司数量 | 总市值       |
| ----- | ------ | --------- |
| 上交所主板 | ~1700家 | ~35万亿人民币  |
| 科创板   | ~560家  | ~5万亿人民币   |
| 深交所主板 | ~1300家 | ~18万亿人民币  |
| 创业板   | ~1200家 | ~10万亿人民币  |
| 北交所   | ~240家  | ~0.5万亿人民币 |

## 3. A股的核心定价机制："政策市"

这是理解A股最重要的概念。

### 3.1 政策市的含义

A股的涨跌驱动因素中，**政策预期**的权重远高于全球任何主要市场。

**典型的政策市传导路径：**
```
政策信号（**央行降准/监管松绑/产业扶持）**
    ↓
市场情绪急速转向（散户主导的正反馈）
    ↓
相关板块快速上涨（往往超过基本面应有幅度）
    ↓
政策实际落地（低于预期/高于预期）
    ↓
补跌或补涨修正
```

**历史典型案例：**
- 2014-2015年牛市：政策驱动的杠杆牛，两融余额从5000亿飙至2.3万亿，最终崩溃
- 2020年7月"大牛市"：仅持续2-3周，短促但剧烈
- 2023年底-2024年：多次政治局会议表态→市场急速拉升→实际政策落地后回落

### 3.2 政策的主要来源

| 来源             | 发布时间            | 重要程度       |     |
| -------------- | --------------- | ---------- | --- |
| 政治局会议（经济专题）    | 通常每季末，4月/7月/12月 | 最高（定调）     |     |
| 全国人大（两会）政府工作报告 | 每年3月            | 极高（年度目标）   |     |
| 中央经济工作会议       | 每年12月           | 极高（次年方向）   |     |
| 国务院常务会议        | 不定期             | 高          |     |
| 证监会专项政策        | 不定期             | 中高（针对资本市场） |     |
| 行业主管部委文件       | 不定期             | 针对特定行业高    |     |

### 3.3 散户主导的放大效应

A股散户占成交量约70-80%，这导致：
- **正向反馈循环更强：** 上涨→散户追买→继续上涨→更多散户追买
- **恐慌性抛售更剧烈：** 跌停触发止损→蔓延→踩踏
- **题材炒作空间更大：** 散户对基本面敏感度低，对故事和概念敏感度高
- **均值回归更缓慢：** 错误定价可以持续更长时间

## 4. A股的注册制改革（2019-2023年全面落地）

### 4.1 什么是注册制

**注册制（Registration-based System）：**
- 企业上市审核以**信息披露真实性**为核心，不对公司盈利能力做实质性判断
- 交易所负责审核，证监会注册（背书）
- 相对原来的核准制：审批周期大幅缩短，上市门槛多元化

**与核准制的对比：**

| 维度   | 核准制（主板历史沿革）  | 注册制（科创/创业/北交所） |
| ---- | ------------ | -------------- |
| 盈利要求 | 严格（通常3年连续盈利） | 灵活（可亏损上市）      |
| 审核周期 | 1-3年         | 6-12个月         |
| 定价机制 | 有PE上限限制（23倍） | 市场化定价          |
| 退市   | 相对宽松         | 更严格            |
|      |              |                |

**2023年全面注册制：** 上交所主板和深交所主板也完成注册制改革，标志着A股全面进入注册制时代。

### 4.2 注册制对投资者的影响

**利好：**
- 优质公司上市通道畅通（等待期缩短）
- 定价更市场化（新股不再必然大涨）

**风险：**
- 上市公司数量快速增加，壳资源价值下降
- 退市数量增加（注册制配套退市改革）
- 新股破发更常见（注册制前有23倍PE红线，破发概率极低；注册制后打新变成风险行为）

## 5. 沪深股通（北向资金）

### 5.1 机制

**沪股通（Shanghai Connect）：** 外资通过香港买入上交所股票
**深股通（Shenzhen Connect）：** 外资通过香港买入深交所股票

合称"北向资金（Northbound）"，代表外资流向A股的资金。

**可买标的：** 以沪深300、上证180等成分股为基础，约900+只

**每日额度：** 沪股通+深股通各520亿人民币（实际使用率通常远低于上限）

### 5.2 北向资金的信号意义

**历史规律：**
- 北向资金持续净流入：外资看好A股信号（但非绝对）
- 北向资金单日大幅净卖出（>100亿）：警示信号
- 北向资金在A股持仓占比约3-5%，但因其"聪明钱"属性，市场关注度远超其实际权重

**2021年后的变化：**
北向资金在A股市场的"聪明钱"光环有所褪色，2023年8月出现罕见的单月大幅净卖出（约900亿），但随后A股继续下跌，说明北向并非永远正确。

**数据获取：** 上交所、深交所官网每日16:30后公布，东方财富、同花顺等平台实时显示

## 6. A股与港股的市场联动

**同一公司AH股的定价差异（AH溢价）：**
同一家公司，A股通常比H股贵25-65%（历史均值），原因已在港股手册第01章详述。

**联动规律：**
- A股领涨：政策刺激内地情绪时，A股先动，港股通过南下资金传导
- 港股领跌：外资风险情绪变化时，港股先跌，A股因T+1限制和涨跌停，下跌更缓慢
- 重大事件（如重大政策出台）：两市几乎同步反应
