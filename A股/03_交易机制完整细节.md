# 第03章：A股交易机制完整细节

---

## 1. 交易时间

| 阶段       | 时间          | 说明                             |
| -------- | ----------- | ------------------------------ |
| 集合竞价（开盘） | 09:15-09:25 | 09:15-09:20可撤单；09:20-09:25不可撤单 |
| 连续竞价（上午） | 09:30-11:30 | 正常交易                           |
| 午休       | 11:30-13:00 | 不可交易                           |
| 连续竞价（下午） | 13:00-14:57 | 正常交易                           |
| 集合竞价（收盘） | 14:57-15:00 | 14:57-15:00收盘集合竞价              |
| 盘后固定价格交易 | 15:05-15:30 | 以收盘价成交，不影响价格（2022年引入）          |

**与港股对比：**
- A股无午市（11:30-13:00全程休市），全天交易4小时
- 港股午休1小时，全天5.5小时
- A股有盘后固定价格交易（港股无此机制）

**盘后固定价格交易（盘后交易）：**
- 15:05-15:30，按当日收盘价撮合成交
- 不影响收盘价格
- 适合：有大单需要成交但不想影响市价的机构；散户亦可使用
- 限制：只能使用市价单（以收盘价成交），成交顺序按时间优先

## 2. T+1 交易制度

**A股T+1：当日买入的股票，最快次一交易日才能卖出。**

**实际含义：**
- 今天买→明天才能卖（持有过夜风险不可避免）
- 今天卖出所得资金→当天可以再买（资金T+0）
- 今天买入→今天不能卖→若股票今天买完涨停，想不到明天继续涨也无法锁定收益

**与港股对比：**
港股实质T+0（当天买当天可以卖），A股是真正的T+1。

**对风险管理的影响：**
- 持有A股必然面临隔夜风险（若晚上有重大利空消息，次日开盘可能跌停）
- 不能当天买入后立即止损出局
- 买入决策必须考虑次日流动性

**科创板/创业板对单日涨幅的特殊T+1效应：**
科创板/创业板±20%涨跌幅，若今日买入跌停（-20%），明日仍可能-20%，两日累计损失-36%，且T+1机制使你无法在跌停当天出逃。

## 3. 涨跌停制度

### 3.1 各市场涨跌停幅度

| 市场      | 正常涨跌停幅度 | 新股/特殊情况            |
| ------- | ------- | ------------------ |
| 上交所主板   | ±10%    | 上市首日±43.99%（注册制规定） |
| 深交所主板   | ±10%    | 同上                 |
| 科创板     | ±20%    | 上市前5个交易日无涨跌停       |
| 创业板     | ±20%    | 上市前5个交易日无涨跌停       |
| 北交所     | ±30%    | 上市前5个交易日无涨跌停       |
| ST股     | ±5%     | ST/*ST均为±5%        |
| 退市整理期股票 | ±10%    | 退市整理期前无涨跌停         |

### 3.2 涨跌停的特殊机制

**涨停（Limit Up）的买入逻辑：**
- 若股票封涨停（挂单全为买入，价格不再上涨），表明买盘强劲
- "炸板"（涨停打开后再次回落）：说明有卖盘介入，涨停不牢固
- 次日继续涨停概率需结合量价分析

**跌停（Limit Down）的特殊风险：**
- 股票跌停后，卖单堆积，无法成交（流动性陷阱）
- 若跌停量过大（大量卖单无法成交），说明持有者急于出逃，次日大概率继续下跌
- "连续跌停"（多日跌停）是A股散户最难处理的风险场景：T+1制度使你一旦被困，需等跌停打开才能出逃

**跌停处理策略（实务）：**
```
第一天跌停 → 观察跌停量大小（跌停封单量越大，越难打开）
              → 若为利空消息导致，评估利空是否已被充分消化
              → 若跌停次日开盘能打开，可考虑出逃（通常开盘竞价时出）
              → 若连续跌停（3次以上），通常代表基本面严重问题，不可死守
```

### 3.3 ST机制（特别处理）

**ST（Special Treatment）条件：**
- 最近两年连续亏损（净利润<0）
- 或最近一年净资产为负

**\*ST（退市警示）条件（2024年退市新规后）：**
- 最近两年ROE均<0且净利润<0
- 或最近一年净资产<0
- 或财务造假（追溯调整后触发退市标准）
- 或审计意见非标（保留意见/无法表示意见）

**退市整理期：**
确定退市后，进入15个交易日的退市整理期，在此期间可以交易（±10%涨跌停），整理期满后摘牌。

## 4. 集合竞价详解

### 4.1 开盘集合竞价（09:15-09:25）

**规则：**
1. 09:15-09:20：可以申报买卖委托单，也可以撤销
2. 09:20-09:25：只能申报，**不能撤单**
3. 09:25：以所有可成交委托中成交量最大、且买卖双方基本平衡的价格作为开盘价，一次性撮合成交
4. 09:25-09:30：开盘价确定但不成交（等待连续竞价开始）

**集合竞价的信息价值：**
- 09:20时刻的委托量分布：可以看出买方/卖方力量对比，预判开盘方向
- 若大量买单集中在某价格以上 → 可能高开
- 若大量卖单集中在某价格以下 → 可能低开

### 4.2 收盘集合竞价（14:57-15:00）

**规则：**
- 14:57-15:00：停止连续竞价，进入收盘集合竞价
- 此期间只能申报，不能撤单
- 15:00：以集合竞价方式确定收盘价

**重要性：**
- ETF和指数基金的净值按收盘价计算
- 收盘价是次日涨跌停价格的基础
- 部分机构在14:57后才大量申报（避免影响日中交易）

## 5. 融资融券（两融）

### 5.1 定义

**融资（Margin Financing）：** 借钱买股票，放大多头收益（同时放大风险）

**融券（Securities Lending / Short Selling）：** 借股票卖出，做空

A股的融券制度是A股做空机制的主要途径，但受到严格限制。

### 5.2 融资融券的条件

**开立两融账户条件：**
- 证券账户开立满6个月
- 近20个交易日日均资产≥50万元人民币
- 签署相关风险揭示书

### 5.3 融资（做多杠杆）

**保证金比例（Margin Ratio）：**
- 初始保证金比例：不低于100%（即最高1:1杠杆，借1元需自有1元作保证金）
- 维持保证金比例：不低于130%（低于此触发追保）
- 各券商可自行设置更高要求

**计算示例：**
- 自有资金10万元，融资10万元，共买入20万元股票
- 若股票跌至13万元，维持担保比例 = 13/10 = 130%（触发追保线）
- 若无法追保，券商强制平仓至满足要求

**融资成本：** 年化约4.5-6%（各券商不同，大客户可谈判）

### 5.4 融券（做空）

**A股融券的严格限制：**
1. 只有"两融标的股票"（约1500-2000只，主要是蓝筹）才能融券
2. 融券券源极度稀缺（可借的股票数量有限）
3. 费用高：融券成本年化通常8-12%
4. 期限有限制（通常6个月内）
5. 2024年起监管进一步收紧：禁止战略投资者将锁定期股票出借、限制融券"T+0"操作

**实际影响：**
A股做空机制远不完善，正常散户几乎无法有效做空（券源少+成本高+风险大）。主流做空工具是股指期货（见第15章）。

### 5.5 融资余额的市场信号意义

**全市场融资余额（每日公布）：**
- 融资余额=所有融资买入尚未偿还的金额总和
- 2015年牛市高峰：融资余额超过2.3万亿元（泡沫标志）
- 正常区间（2023-2025年）：1.4-1.6万亿元
- 融资余额持续上升：杠杆增加，市场风险积累
- 融资余额急剧下降：去杠杆，可能引发抛售压力

## 6. 大宗交易系统

**时间：** 每个交易日15:00-15:30（盘后）

**规则：**
- 单笔成交量≥30万股，或成交额≥200万元
- 价格在当日收盘价的90%-110%之间
- 买卖双方自行协商价格，通过大宗交易系统申报成交

**对投资者的意义：**
- **折价大宗：** 以低于市价的价格成交，通常是大股东减持或机构退出 → 潜在压力信号
- **溢价大宗：** 以高于市价的价格成交，通常是战略投资者入股 → 潜在利好信号
- 大宗交易数据每日公布（东方财富、同花顺等平台有专页）

## 7. A股费用完整拆解

以买卖各10万元股票为例：

| 费用    | 收取方    | 比率/金额              | 10万元示例         |
| ----- | ------ | ------------------ | -------------- |
| 佣金    | 券商     | 0.02%-0.1%（可谈）     | 20-100元（买+卖）   |
| 印花税   | 国家税务总局 | **卖出时0.05%（单边）**   | 50元（仅卖出收）      |
| 交易所规费 | 交易所    | 0.00341%（主板）       | 3.41元（买+卖各）    |
| 结算费   | 中证登    | 0.002%（主板）         | 2元（买+卖各）       |
| 过户费   | 中证登    | 主板0.002%，科创板0.002% | 2元（仅A股主板，深交所免） |

**合计（10万买+10万卖）：**
- 佣金（按0.03%）：60元
- 印花税：50元（仅卖出）
- 规费合计：约11元
- **总计约121元（0.06%）**

**与港股对比：** A股印花税**只在卖出时收取（单边0.05%）**，港股双边收（买卖各0.1%）。因此A股同等交易量的税负约为港股的四分之一。

**历史调整：**
- 2023年8月：A股印花税从0.1%降至0.05%（减半），是近30年来最大的印花税减免
- 历史最高：曾达到0.3%双边（1997年）

## 8. 股票质押（大股东常用融资手段）

**机制：** 上市公司大股东将持有的股票质押给券商/银行，获得质押融资（通常为股票市值的30-60%）。

**对普通投资者的风险：**
- 若大股东高比例质押（>50%持股被质押），股价下跌→触发平仓→强制卖股→股价继续跌→恶性循环
- 2018年A股股权质押危机：大规模质押爆仓引发市场流动性危机

**查询大股东质押比例：**
- 巨潮资讯网：公司公告→权益变动→股票质押
- 东方财富：个股页面→股东研究→股东持股质押

**警示信号：** 大股东质押比例>80%（高风险区间）；上市公司实际控制人质押比例接近100%（极高风险）。
