### 第2周：交易机制熟悉

**必须理解的A股特殊机制：**

**T+1的实操含义：**
- 今天买入的股票→明天才能卖出
- 今天融资买入→当天可以融券卖出（但需要融券权限）
- 可转债是T+0例外：买入当天可以卖出

**涨跌停操作规则（实操）：**

| 情况    | 操作要点                       |
| ----- | -------------------------- |
| 股票涨停  | 可以挂单买入（排队等候），已涨停后买单不一定成交   |
| 股票跌停  | 可以挂单卖出（排队），跌停板上卖出难度极大      |
| 次日开盘前 | 集合竞价9:15-9:25，超过昨日涨停价的申报无效 |

**Day 8-10：模拟买卖**

使用小额资金（1000-2000元）进行：
1. 买入一只沪深300成分股（大盘蓝筹，流动性好）
2. 隔日（T+1）卖出
3. 买入一只可转债（验证T+0机制）
4. 同日卖出可转债

**验收标准：**
- [ ] 完成至少3笔实际买卖（非模拟盘）
- [ ] 理解成交记录中的实际佣金、印花税、过户费明细
- [ ] 已确认T+1的持仓限制（买入当天不能卖出的实际感受）

## 第二阶段：第31-60天（核心技能）

### 第5-6周：板块与资金流追踪

**建立每日信息流习惯（10分钟/天）：**

```
早8:30（开盘前）：
① 美股前一日收盘（东方财富→行情→全球股市）
② 离岸人民币汇率（CNH）
③ A50期货夜盘（新加坡SGX）
④ 当日重要财经日历（有无PMI/CPI等数据）

收盘后（15:30）：
① 沪深两市总成交额（<7000亿=冷淡；>1万亿=活跃）
② 北向资金净流入/净流出
③ 个人持仓涨跌复盘（记录原因）
```

**每周资金流复盘（30分钟/周）：**
- 融资余额变化（东方财富→数据→融资融券）
- 行业ETF涨跌幅排名（判断资金流向行业）
- 龙虎榜本周重要席位买卖（东方财富→数据→龙虎榜）

### 第7-8周：选股框架实践

**三步选股流程（适合A股基本面投资者）：**

**Step 1：自上而下——确定行业方向**
- 当前政策重点方向（参考最近一次政治局会议措辞）
- 行业景气度（上游价格/月度销量数据）
- 排除集采压制中的医药、产能严重过剩的中下游

**Step 2：行业内筛选龙头**
- 在申万二级行业中，按市值从大到小排列
- 筛选条件：
  - ROE>10%（近3年均值）
  - 扣非净利润增速>10%
  - 经营现金流/归母净利润>80%（利润有现金支撑）
  - 无ST风险，无大股东质押>50%

**Step 3：估值判断入场时机**
- 当前PE vs 历史PE百分位（同花顺→估值分析）
- PE百分位<30%：历史低估区间，建仓窗口
- PE百分位>70%：历史高估区间，谨慎追高

**实操任务：**
- 选出3只符合上述条件的股票，建立跟踪表
- 每周记录基本面/技术面/资金面变化

**验收标准：**
- [ ] 每日信息流习惯坚持14天以上
- [ ] 完成3只股票的系统化分析（三步选股）
- [ ] 龙虎榜阅读能识别"知名游资席位"与普通席位

## 第三阶段：第61-90天（体系完善）

### 第9-10周：风控系统建立

**仓位管理（T+1约束下的特殊处理）：**

| 仓位层级   | 比例     | 用途               |
| ------ | ------ | ---------------- |
| 核心仓位   | 40-50% | 长期持有，基本面驱动，不频繁操作 |
| 卫星仓位   | 20-30% | 短期题材/事件驱动，严格止损   |
| 现金+可转债 | 20-30% | 流动性储备+国债逆回购轮动    |

**止损规则（T+1限制下的注意事项）：**

T+1环境下，买入当天无法止损，因此：
- 买入前必须预设止损价（买入前写下，而非买入后设置）
- 单只股票跌幅达-7%至-10%，次日开盘卖出（不等待）
- 跌停板卖不出时：次日集合竞价9:15-9:20挂卖单（价格略高于跌停价），若有反弹则成交

**跌停板应对流程：**
```
持仓跌停
    ↓
判断：是否基本面突发重大负面（业绩暴雷/监管处罚/实控人问题）？
    ↓ 是                        ↓ 否（技术性/市场情绪）
次日开盘优先卖出            次日观察是否打开跌停
（即使亏损也要离场）          打开→判断是否继续持有
                            未打开→大概率连板，继续等
```

## 常见错误与避免方法

| 错误类型    | 具体表现           | 避免方法                  |
| ------- | -------------- | --------------------- |
| T+1陷阱   | 买入后当天想卖却不能     | 买入前确认是否愿意持有至少1天       |
| 追涨停板    | 看到涨停想追入        | 涨停板买入成本极高，排队可能买在最高点   |
| 跌停不止损   | "等反弹"心态，越亏越等   | 跌停次日必须机械执行止损          |
| 题材过度参与  | 追热点概念，不看基本面    | 卫星仓位上限30%，严格控制题材股比例   |
| 扣非利润忽视  | 被净利润高增长吸引，不看扣非 | 每次分析必须核查非经常性损益占比      |
| 不看北向数据  | 忽视外资对A股核心标的的影响 | 每日信息流中北向是必看项          |
| 打新只参与股票 | 忽视可转债打新的高性价比   | 可转债打新无门槛，每次必申购        |
| 现金闲置    | 闲置资金不做国债逆回购    | 每周五13:00前将闲置资金买入GC001 |

## 资金量级的差异化建议

| 资金规模     | 核心策略                          | 注意事项                 |
| -------- | ----------------------------- | -------------------- |
| 5万-20万   | 以ETF为主（沪深300ETF+行业ETF）+ 可转债打新 | 个股比例不超过总仓位50%，避免过度集中 |
