## 3. A股ETF期权的特殊性

### 3.1 标的是ETF，而非个股

**关键差异：** A股现阶段只有ETF期权，没有个股期权（不同于港股有个股期权）。

操作含义：
- 看好某只个股→无法直接买该股的期权
- 只能通过对应的指数ETF期权来做方向性判断

**部分替代方案：**
- 看好科技板块→买科创50ETF期权
- 看好创业板成长股→买创业板ETF期权
- 看好大盘蓝筹→买50ETF或沪深300ETF期权

### 3.2 行权方式：欧式期权

A股ETF期权均为**欧式期权（European Style）：只能在到期日行使**，不能提前行使（不同于港股个股期权的美式）。

**含义：** 买入期权后，到期前无法要求对方履约，只能在市场上卖出期权平仓，或持有到到期日。

### 3.3 到期日与结算

**到期日：** 每月第四个星期三

**结算方式：** 现金结算（自动以到期日标的ETF收盘价计算盈亏，不涉及ETF实物交割）

到期日前：
- 价内期权：有内在价值，通常持有到期或提前平仓
- 价外期权：时间价值耗尽，到期归零，不必平仓（自动作废）

## 4. 合约规格详解（以50ETF期权为例）

| 参数     | 数值                          |
| ------ | --------------------------- |
| 标的     | 华夏上证50ETF（510050）           |
| 合约单位   | 10,000份                     |
| 到期月份   | 当月、下月、季月×2（3/6/9/12月）       |
| 到期日    | 到期月份第四个星期三                  |
| 行使方式   | 欧式                          |
| 行权价格间距 | ETF价格×0.5%（价平附近），更远期行权价间距更大 |
| 涨跌停    | 买方：权利金不得为负；卖方：最大涨停幅度规定      |

**行权价格体系：**
通常围绕当前ETF价格，上下各设多个行权价（如±3%、±6%、±9%等），形成行权价"阶梯"。

## 5. 开户条件（分级管理）

A股ETF期权有**四级投资者分级**：

| 级别  | 可操作内容                              | 条件                      |
| --- | ---------------------------------- | ----------------------- |
| 一级  | 买入认购/认沽期权（Long Call/Long Put）      | 最低要求（账户资产≥50万+6个月经验+测试） |
| 二级  | 一级 + 备兑开仓（Covered Call）            | 更高要求                    |
| 三级  | 一级+二级 + 卖出期权（Short Put/Short Call） | 条件更严格                   |
| 四级  | 全部策略（含组合策略）                        | 最高级别                    |

**开户硬性条件（以上交所50ETF期权为例）：**
- 证券账户开立≥6个月
- 有50万元以上资产
- 通过期权知识测试（单选+多选，须85分以上）
- 参与模拟期权交易（至少20笔以上）

**开户渠道：** 具有上市期权经纪业务资格的券商（主流大型券商均可）

## 6. 常用策略（A股ETF期权）

### 6.1 买入认购（Long Call）——看涨ETF

**适合场景：** 判断市场将上涨，但不想全额资金买入ETF

**风险/收益：**
- 最大损失：权利金（100%）
- 最大收益：无限（ETF涨幅×杠杆）

### 6.2 买入认沽（Long Put）——看跌ETF

**主要用途：** 为持有的ETF或股票组合购买"保险"

**Protective Put（保护性认沽）：**
持有50ETF + 买入50ETF认沽期权 = 锁定下行风险

**成本：** 权利金（相当于保险费）

### 6.3 备兑开仓（Covered Call）——增强收益

**操作：** 持有10,000份ETF（1手）+ 卖出1张认购期权

**收益来源：** 收取权利金（额外收益）

**风险：** 若ETF大涨，超过行权价的部分收益受限（被行权后必须以行权价卖出ETF）

**实际用法：** 适合认为ETF短期内涨幅有限、想通过卖权利金增加回报的投资者。

### 6.4 卖出认沽（Cash-Secured Put）——以目标价买入ETF

**操作：** 卖出1张认沽期权 + 持有足够现金（若被行权则买入ETF）

**效果：** 若ETF价格没有跌至行权价，收取权利金；若跌至行权价以下，以（行权价-权利金）的有效成本买入ETF。

**适合场景：** 想以低于市价的价格建仓某ETF，同时赚取等待期间的权利金。

### 6.5 价差策略（Bull/Bear Spread）

**牛市认购价差（Bull Call Spread）：**
买低行权价认购 + 卖高行权价认购

**降低成本，同时限制最大收益**，适合方向确定但不确定幅度的场景。

## 8. 与港股期权的比较

| 维度    | A股ETF期权              | 港股期权           |
| ----- | -------------------- | -------------- |
| 标的    | ETF（指数化）             | 个股 + 指数        |
| 行使方式  | 欧式                   | 美式（个股）/ 欧式（指数） |
| 结算    | 现金结算                 | 实物/现金          |
| 流动性   | 50ETF较好；其他较差         | 流动性参差不齐        |
| 隐含波动率 | 相对美股/港股更低（A股波动率低于预期） | 偏高             |
| 开户门槛  | 50万资产+测试             | 视券商而定，通常更宽松    |
| 可用策略  | 受级别限制（新手只能买，不能卖）     | 相对灵活           |
|       |                      |                |
