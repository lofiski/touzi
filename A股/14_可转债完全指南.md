# 第14章：可转债完全指南（A股特有重要品种）

---

## 1. 可转债是什么

**可转换公司债券（Convertible Bond，CB）** = 可以在特定条件下转换为公司股票的债券

**二重属性：**
- **债券属性：** 有面值（100元），有票息（利率），到期可以还本付息
- **期权属性：** 持有人有权以约定价格（转股价）将债券转换为股票

**A股可转债是全球市场上条款最投资者友好的可转债之一：**
- 有强制赎回条款（对发行人利好，但触发时强迫转股）
- 有回售条款（对持有人利好，兜底价值）
- 发行时面值100元，到期还本付息（如果不转股，至少拿回本金+利息）

---

## 2. 可转债的关键条款

### 2.1 基本要素

| 要素                    | 说明                      |
| --------------------- | ----------------------- |
| 面值                    | 100元（A股可转债统一面值）         |
| 票息                    | 通常1-3%/年（较低，因为含转股期权）    |
| 期限                    | 通常6年                    |
| 转股价（Conversion Price） | 初始设定为发行时股价的约100-110%    |
| 转股比例                  | 100元面值 / 转股价 = 可转换的股票数量 |

**转股价值计算：**
转股价值 = (100 / 转股价) × 当前股价

**示例：**
- 面值100元，转股价10元，当前股价12元
- 可转换股数：100/10 = 10股
- 转股价值：10 × 12 = 120元（高于面值，有20%溢价空间被转化为价值）

### 2.2 转股溢价率（最重要的估值指标）

**转股溢价率 = (可转债价格 - 转股价值) / 转股价值**

| 溢价率     | 含义                         |
| ------- | -------------------------- |
| 接近0%    | 可转债价格≈转股价值，价格主要跟随正股波动      |
| 20-30%  | 正常，债性和股性均衡                 |
| >50%    | 债性为主（正股跌很多，转股无意义）          |
| <0%（折价） | 套利机会（买可转债+立即转股+卖出股票，获取折价差） |

### 2.3 强制赎回条款（Mandatory Redemption / "强赎"）

**触发条件（通常）：**
在转股期内（通常发行后6个月起），股票在30个交易日内有15个交易日收盘价≥转股价的130%

**触发后：**
公司有权以**103元（面值的103%）**赎回所有未转股的可转债，持有人必须在此前转股或以103元卖回给公司。

**实际效果：** 强赎触发后，持有人大量转股卖股，对正股价格造成压力。

**投资者应对：** 触发强赎时，应及时做出选择（转股 or 以103元卖给公司），不要忘记处理，到期被强制103元赎回仍然高于面值，不亏钱，但放弃了更高价格转股的可能。

### 2.4 回售条款（Put Option / "回售"）

**触发条件（通常）：**
在转股期内，股票在连续30个交易日的收盘价低于转股价的70%

**触发后：**
持有人有权以**103元**将可转债卖回给公司（保护持有人的下行风险）

**实际意义：** 可转债的价格有底部保护——无论正股跌多少，理论上可转债不会跌破回售价格（约103元），实际上市场提前反应，可转债价格通常维持在100元以上（债底保护）。

### 2.5 转股价格修正条款（向下修正 / "下修"）

**条件：** 当正股价格低于转股价的80%（或85%，视条款）达一定天数

**董事会权利：** 经股东大会批准，可将转股价向下修正至不低于最近20日均价

**为什么发行人会主动下修：**
- 防止触发回售（公司没钱偿付）
- 希望可转债持有人转股（减少债务）

**投资者利好：** 下修转股价后，转股价值提升，可转债价格通常上涨。

**"博下修"策略：** 在可转债接近回售触发条件（正股价格跌至转股价70%附近）时，买入可转债，押注发行人会主动下修转股价，导致可转债价格上涨。风险是发行人不下修或发行人财务状况已恶化。

## 3. 可转债的定价与波动

### 3.1 双重属性决定价格范围

**债底（Bond Floor）：** 把可转债当纯债券来定价（忽略转股期权），得到的价值

- 通常90-100元区间
- 当正股大幅下跌时，可转债趋近债底（约90-95元）

**正股联动：** 当正股价格上涨，转股价值>债底时，可转债价格随正股上涨

**可转债的"下有保底，上不封顶"特性：**
```
正股大跌 → 可转债跌至债底（约90-95元）≈ 最大亏损10%
正股大涨 → 可转债随股性上涨，理论上无上限
```

这是可转债的核心吸引力：风险/收益不对称。

### 3.2 T+0的优势

**可转债的交易机制是T+0（不同于股票的T+1）！**

当天买入，当天可以卖出。

这使可转债成为A股市场中少数可以日内操作的品种之一（还有ETF、股指期货）。

## 4. 可转债打新

### 4.1 打新机制

**无需持有市值（与股票打新不同）：**
- 每个A股账户可以直接申购（不需要股票市值）
- 每账户每次申购上限：通常100张（10,000元面值）
- 申购方式：提前1天在申购日期申购，资金冻结（约10,000元）
- 中签后缴款（通常申购当日或次日）

### 4.2 历史打新收益率

**可转债打新历史收益（2019-2024年统计）：**
- 平均首日涨幅：约15-25%（远高于股票打新）
- 破发率：约5-10%（远低于股票打新）
- 原因：回售条款/债底保护使可转债价格有底部，破发风险低

**结论：** 可转债打新是A股投资者应坚持参与的基础操作，历史上收益率远高于股票打新，且风险更低。

### 4.3 打新流程

1. 在巨潮资讯网/东方财富查询当日可申购的可转债
2. 在券商App搜索可转债代码，在申购时间内（通常9:30-11:30/13:00-15:00）申购
3. 每账户申购1次，100张（10,000元），资金冻结
4. 次日公布中签结果，中签后缴款（3个工作日内）
5. 上市后（通常申购后约15个工作日）可交易

## 5. 二级市场可转债交易策略

### 5.1 低价可转债策略

买入价格接近面值（100元附近）或低于面值（<100元）的可转债：
- 债底保护下，下行风险有限（最多跌至90-95元）
- 若公司经营改善或下修转股价，可转债价格弹性大

**筛选条件：**
- 价格：100-110元之间（最低风险区间）
- 转股溢价率：<50%（股性不能太弱）
- 评级：至少AA-（防范信用风险）
- 公司：无退市风险，财务状况健康

### 5.2 双低策略（"双低可转债"）

**双低 = 价格低 + 溢价率低**

**双低分数 = 可转债价格 + 100 × 转股溢价率**

双低分数越低，可转债的性价比越高（价格低且和正股联动性高）。

**操作：** 定期（如每月）重新筛选双低评分最低的10只可转债，平均持有，定期轮动。

这是A股可转债投资最广为流传的量化策略，历史上长期年化收益约15-25%（视回测区间）。

## 6. 可转债的信用风险

### 6.1 发行人信用风险

可转债是债券，若发行公司破产，持有人可能拿不回全额面值。

**A股历史实际违约：**
- 2021年：蓝盾转债（蓝盾股份退市引发的可转债违约，首例退市可转债）
- 2023年后：随着退市数量增加，可转债违约案例增加

**风险控制：** 避免买入退市风险高的公司的可转债（见第10章退市识别）；关注可转债信用评级（AA以上为安全区间）。
