## 2. 白酒行业

### 2.1 行业结构

**寡头格局，高度集中：**

| 梯队        | 代表公司         | 价格带       | 特点            |
| --------- | ------------ | --------- | ------------- |
| 第一梯队（超高端） | 贵州茅台（600519） | 1000元+/瓶  | 独家定价权，实为"奢侈品" |
| 第二梯队（高端）  | 五粮液、泸州老窖国窖   | 500-1000元 | 量价弹性较大        |
| 第三梯队（次高端） | 洋河、汾酒、古井贡酒   | 200-500元  | 竞争激烈，区域品牌扩张   |
| 区域龙头      | 今世缘、口子窖、迎驾贡酒 | 100-300元  | 区域壁垒，全国化难度高   |

### 2.2 白酒的估值文化

**历史PE中枢：**
- 茅台：30-60倍PE（2020年高峰超70倍）
- 行业整体：20-40倍PE

**估值逻辑特殊性：**
- 库存周期是核心变量：渠道库存高→价格压力→业绩下修→股价承压
- 批价（飞天茅台批发价）是茅台最实时的景气度指标
- 吨酒价是次高端酒提价能力的核心指标

**白酒的A股特殊性：**
- 大量政务消费（2012年限制三公消费是上一次行业大顶的信号）
- 春节/中秋是旺季，Q4/Q1是业绩核心期
- 外资持仓占茅台流通股约8-10%（是外资在A股配置最重的单一标的）

### 2.3 白酒行业下行信号

- 批价连续2个月下降>5%
- 渠道反馈压货增加
- 宏观反腐力度加强
- 高端白酒出口受限（对外政策风险）

## 3. 新能源行业

### 3.1 产业链结构

```
上游（资源）→ 中游（材料/制造）→ 下游（整车/电站）
锂/钴/镍矿       正负极材料           电动车整车
             隔膜/电解液           光伏电站
             电芯/电池组           风电场
             逆变器/组件           储能系统
```

### 3.2 各环节估值特点

| 环节   | 代表公司         | 估值逻辑       | 风险点            |
| ---- | ------------ | ---------- | -------------- |
| 锂矿   | 赣锋锂业、天齐锂业    | 锂价×储量，周期性强 | 锂价暴跌（2023年发生过） |
| 负极材料 | 贝特瑞、璞泰来      | 出货量增速×毛利率  | 一体化竞争（宁德自制）    |
| 隔膜   | 恩捷股份         | 单㎡价格×出货量   | 产能过剩，价格战       |
| 电池   | 宁德时代（300750） | 装机量份额×单位利润 | 车企自建电池厂        |
| 光伏组件 | 隆基绿能、通威股份    | 硅料价格×出货量   | 供给过剩是永久主题      |
| 整车   | 比亚迪、理想、小鹏    | 销量增速+毛利率改善 | 价格战压缩利润        |

### 3.3 新能源周期分析框架

**供需分析（优先于估值）：**
1. 每月产量/装机数据：工信部/中国汽车工业协会/国家能源局
2. 开工率：行业协会月报（反映供需真实状态）
3. 价格：锂价（上海有色网）、硅料价（PVInfoLink周报）

**新能源政策风险：**
- 补贴退坡（2022年电动车补贴全退）→短期需求透支后回落
- 海外关税壁垒（欧盟2024年加征关税）→出口型企业利润压缩

## 4. 半导体行业

### 4.1 A股半导体的特殊性：国产替代逻辑

A股半导体估值远高于全球同行，核心驱动是**政策+国产替代预期**，而非当期盈利。

**国产替代进展（2026年状态）：**

| 细分领域     | 国产化率（约）    | 代表公司      | 差距               |
| -------- | ---------- | --------- | ---------------- |
| 设计（芯片设计） | 30-40%     | 海光信息、龙芯中科 | 高端CPU/GPU仍落后2-3代 |
| 晶圆代工     | <10%（先进制程） | 中芯国际（A+H） | 28nm国产化，7nm以下受限  |
| 设备       | 15-20%     | 北方华创、中微公司 | 光刻机几乎空白          |
| 材料       | 20-30%     | 沪硅产业、鼎龙股份 | 大硅片/光刻胶仍依赖进口     |
| 封测       | 30-40%     | 长电科技、通富微电 | 先进封装差距缩小中        |

### 4.2 半导体估值特点

**市梦率（Dream P/E）是常态：**
- 景气上行期：市场给予50-100倍PE，甚至亏损公司用PS估值
- 景气下行期：即使低PE也不能阻止下跌（盈利下修同步发生）

**半导体周期（Semiconductor Cycle）：**
- 全球半导体有明显的3-5年库存周期
- A股半导体股价通常领先基本面6-12个月
- 跟踪指标：费城半导体指数（SOX）、三星/台积电月报、下游存储价格（DRAM/NAND）

### 4.3 政策敏感性

**大基金（国家集成电路产业投资基金）是A股半导体的最重要政策信号：**
- 大基金一期（2014年，1387亿元）
- 大基金二期（2019年，2042亿元）
- 大基金三期（2024年，3440亿元）——支持方向：设备、材料、先进制程

**美国出口管制升级（如增加新的实体清单）→ A股半导体短期上涨（国产替代预期强化）**

## 5. 医药行业

### 5.1 A股医药的核心变量：集采

**集中带量采购（集采）：** 国家医保局组织，以量换价，强制压低药价。

**集采的影响机制：**
```
集采落地→药品降价幅度50-90%→仿制药企业利润暴跌→估值重估
            同时→创新药/医疗器械溢价提升（集采规避）
```

**集采历史轮次（截至2026年）：**
- 化学药：第1-9批（覆盖大多数常见仿制药）
- 生物类似药：第1-2批
- 医疗器械：骨科关节（75-90%降幅）、冠脉支架（93%降幅）、眼科人工晶状体

### 5.2 医药子板块分类与估值

| 子板块  | 估值方式         | 核心变量         | 代表公司           |
| ---- | ------------ | ------------ | -------------- |
| 创新药  | DCF/管线价值     | 临床进展+适应症空间   | 恒瑞医药、百济神州（A+H） |
| 仿制药  | PE（低，10-15倍） | 集采降幅+品种数量    | 华海药业           |
| CXO  | PE/PEG       | 海外订单增速+产能利用率 | 药明康德（A+H）      |
| 医疗器械 | PE/PS        | 国产替代进度+集采风险  | 迈瑞医疗、联影医疗      |
| 中药   | PE           | 政策支持+提价能力    | 片仔癀、云南白药       |
| 医疗服务 | EV/EBITDA    | 床位数×ARPU     | 爱尔眼科、通策医疗      |

### 5.3 医保谈判（医保目录调整）

**每年12月：** 国家医保局公布新版医保目录
- 创新药谈判进入目录→销量放量但价格大幅下降（谈判降幅通常50-60%）
- 进入目录是创新药商业化的关键节点

## 6. 军工行业

### 6.1 军工的特殊性

**A股军工是纯政策驱动板块：**
- 军工企业利润不透明（涉密），财报可靠性有限
- 订单来自国防预算，不受市场竞争影响
- 估值中枢高于其他工业企业（政策安全溢价）

**核心驱动：**
1. 国防预算增速（每年3月两会公布）：2015年以来基本维持5-8%增速
2. 地缘政治紧张度：台海/南海局势升温→军工板块上涨
3. 武器装备换代需求（航母/歼-20批量交付/导弹库存补充）

### 6.2 军工产业链

| 层级        | 内容          | 代表               |
| --------- | ----------- | ---------------- |
| 主机厂（总装）   | 飞机/导弹/舰船总装  | 中航沈飞、航天科技集团（未上市） |
| 分系统       | 航电/雷达/发动机   | 中航电子、航发动力        |
| 配套（材料/零件） | 特种材料/精密零件   | 钢研高纳、抚顺特钢        |
| 民参军       | 民营企业进入军品供应链 | 航天彩虹、振华科技        |

### 6.3 军工的估值陷阱

- 军工企业业绩预测极难（订单保密，分析师看不到）
- 估值弹性大但基本面验证慢（高PE无法用盈利增速验证）
- 频繁作为政策预期载体被炒作，与基本面脱钩

## 7. 银行行业

### 7.1 A股银行的估值困境

**2020年以来，银行板块持续破净（PB<1）：**

**原因：**
1. **净息差（NIM）持续收窄：** LPR多次下调，贷款利率↓，存款成本刚性→息差被压缩
2. **房地产风险：** 银行对房企/地方城投的贷款敞口存在潜在不良
3. **让利实体经济：** 政策要求银行降低融资成本，压缩利润空间

**2026年净息差参考水平：** 大型国有银行约1.5-1.6%（2023年曾降至1.7%以下）

### 7.2 银行估值指标

| 指标       | 含义           | 银行业参考值                   |
| -------- | ------------ | ------------------------ |
| PB（市净率）  | 股价/每股净资产     | 国有大行0.4-0.7×；股份行0.5-0.8× |
| ROE      | 净资产收益率       | 国有大行10-12%；股份行10-13%     |
| 不良贷款率    | 逾期贷款/总贷款     | 1.5%以下为健康（监管红线约2%）       |
| 拨备覆盖率    | 已提准备金/不良贷款   | 监管要求>150%，大行普遍>300%      |
| 净息差（NIM） | 利息净收入/平均生息资产 | 2026年约1.5-1.7%           |

### 7.3 银行的红利属性

**国有大行股息率（2025年）：3.5-6%**

在无风险利率持续下行（10年期国债约2%）的背景下，银行股成为"红利资产"被保险资金追捧：
- 工商银行/农业银行/建设银行：股息率约5-6%
- 招商银行：股息率约4-5%（质地更优，估值溢价）

## 10. 行业研究框架（标准化流程）

分析任何A股行业，按以下顺序：

**1. 竞争格局（CR3/CR5集中度）**
- 集中度高（寡头）→ 定价权强→ 估值溢价
- 集中度低（充分竞争）→ 价格战→ 估值折价

**2. 政策属性**
- 政策扶持（新能源/半导体）→ 允许更高估值
- 政策限制（平台经济/教育）→ 估值折价
- 政策中立→ 按基本面估值

**3. 行业景气度指标**
- 每个行业有1-3个核心月度/季度跟踪指标（见各行业章节）

**4. 龙头公司ROE可持续性**
- 高ROE + 低资本开支 = 护城河（茅台是极端案例）
- 高ROE + 高资本开支 = 增长期，需判断未来产能利用率

## 关键认知清单

- [ ] 白酒行业估值与渠道库存/批价强相关，批价是实时景气度指标
- [ ] 新能源是周期性行业，供需格局（产能过剩）优先于估值判断
- [ ] 半导体在A股有国产替代政策溢价，估值逻辑与全球同行不同
- [ ] 医药的最大变量是集采：仿制药→利润暴跌；创新药→规避集采溢价
- [ ] 军工板块依赖政策信号，财务数据不透明，地缘政治是核心催化剂
- [ ] 银行破净是结构性现象（息差收窄+让利），高股息率是低利率时代的吸引力
- [ ] 行业ETF是参与某一板块最低风险（规避个股踩雷）的工具
