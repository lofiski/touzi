# 第05章：A股财报解读

---

## 1. A股财报体系

### 1.1 法定披露文件

| 文件    | 披露时间     | 内容详尽度         |
| ----- | -------- | ------------- |
| 一季度报告 | 4月30日前   | 简版（仅财务数据，无审计） |
| 半年度报告 | 8月31日前   | 完整（含审计/审阅）    |
| 三季度报告 | 10月31日前  | 简版（无审计）       |
| 年度报告  | 次年4月30日前 | 完整（含审计）       |
| 业绩预告  | 满足条件时强制  | 净利润预计变化幅度     |
| 业绩快报  | 自愿/部分强制  | 关键财务数据快速版     |

**A股信息密度高于港股：** 季报（1季报+3季报）让投资者每季度都能看到财务数据更新，但季报不经审计，数据可靠性低于年报/半年报。

### 1.2 会计准则

**A股采用中国会计准则（CAS，Chinese Accounting Standards）**，已基本与国际财务报告准则（IFRS）趋同，但仍有部分差异：

| 差异点    | CAS               | IFRS      |
| ------ | ----------------- | --------- |
| 投资性房地产 | 允许成本模式（不必按公允价值重估） | 允许公允价值模式  |
| 资产减值   | 已计提减值不可转回         | 金融资产减值可转回 |
| 少数股东权益 | 同IFRS（合并报表列示）     | 同         |
| 政府补助   | 分为与资产相关/与收益相关     | 类似        |
|        |                   |           |

**重要：** 部分在A股和H股同时上市的公司，A股用CAS编制，H股可能同时用IFRS编制，两套报表数字可能不同，需注意对比。

## 2. 三大财务报表

### 2.1 利润表（Profit & Loss Statement）

A股利润表的结构：

```
营业收入（Revenue）
  - 营业成本（Cost of Revenue）
= 毛利润（Gross Profit）
  - 税金及附加（Taxes & Surcharges）          ← A股特有，含增值税附加
  - 销售费用（Selling Expenses）
  - 管理费用（G&A Expenses）
  - 研发费用（R&D Expenses）                  ← 注册制后单独列示
  - 财务费用（Finance Costs）                 ← 利息支出净额
  + 其他收益（Other Income）                  ← 通常包含政府补贴
  + 投资收益（Investment Income）
  + 公允价值变动损益
  + 信用减值损失                              ← 应收账款坏账
  + 资产减值损失                              ← 存货、长期资产减值
  + 资产处置损益
= 营业利润（Operating Profit）
  + 营业外收入
  - 营业外支出
= 利润总额（Profit Before Tax）
  - 所得税费用
= 净利润（Net Profit）
  - 少数股东损益
= 归属于母公司股东的净利润（PAT）
```

**A股利润表的特殊项目：**

**税金及附加：**
A股特有的税金项目，包含增值税附加税（城市维护建设税+教育费附加+地方教育附加），通常占收入0.3-0.8%。港股/美股无此项。

**其他收益（政府补贴）：**
内地上市公司普遍获得各级政府补贴。"其他收益"科目通常记录计入当期损益的政府补助。

- **补贴规模重要性：** 若某公司净利润主要依赖政府补贴（补贴/净利润>30%），实际盈利能力存疑
- 数据在年报附注中有详细披露（政府补助明细）

**研发费用的资本化 vs 费用化：**
A股允许部分研发支出资本化（计入无形资产），而非全部费用化。
- 资本化比例越高→当期利润越好看
- 但未来需逐年摊销，且若研发失败，可能面临减值
- 审查年报中"研发费用资本化比例"，过高是警示

### 2.2 资产负债表

与港股基本结构相同（见港股手册第05章），以下列出A股特有关注点：

**商誉（Goodwill）的A股特殊性：**
2015-2018年A股并购潮遗留了大量商誉，总规模峰值超过1.4万亿元。2018-2019年出现商誉集中减值潮，导致大量公司业绩骤降。

**检查商誉规模的方法：**
- 商誉/净资产 > 30%：需关注
- 商誉/市值 > 20%：尾部风险不小
- 收购溢价高、被收购方业绩承诺期将届满：减值风险高（承诺期通常3年，届满后基本面可能恶化）

**业绩承诺（Performance Commitment）：**
A股定增或并购中常见的特殊条款：被收购方/定增对象承诺未来3年的净利润。承诺期一过，业绩往往变脸。

这是A股特有的风险：
```
年份1（承诺期内）：业绩达标，股价高企
年份2（承诺期内）：业绩达标，股价维持
年份3（承诺期内）：业绩勉强达标
年份4（承诺期结束）：业绩大幅变脸，商誉减值
```

**经典信号：** 大额并购+高溢价+业绩承诺+承诺期即将届满 → 高风险组合。

### 2.3 现金流量表

与港股基本框架相同，重点关注：

**经营活动现金流的中国特殊性：**
- 内地企业应收账款回收期通常长于欧美企业，导致经营现金流可能持续低于净利润
- 行业性问题：建筑企业（甲方拖款）、医疗企业（医保结算慢）等行业应收账款积压

**政府补贴的现金流确认：**
收到政府补贴计入"收到的其他与经营活动有关的现金"，在现金流量表附注中披露，需单独关注其对经营现金流的贡献。

## 3. 非经常性损益（Non-recurring P&L）

这是A股财报中极其重要的概念，是判断公司真实盈利能力的关键。

### 3.1 定义

证监会对"非经常性损益"有明确界定，包括：
- 政府补贴（部分）
- 资产处置损益
- 投资收益（非主营业务）
- 公允价值变动损益
- 债务重组收益
- 商誉减值（负向）
- 汇兑损益（部分情况）

### 3.2 扣非净利润（Core Earnings）

**扣除非经常性损益后的净利润（扣非净利润）** = 净利润 - 非经常性损益（税后）

**扣非净利润更能反映公司的持续经营能力。**

**典型的"利润操控"模式：**
- 年末通过出售资产或获取政府补贴，将本来亏损的年度变为微利，规避连续亏损退市
- 关注：净利润为正但扣非净利润为负 → 高度警示

**数据查询：** 年报中"非经常性损益项目及金额"表，直接列示各项目金额。

## 4. 季报的使用与限制

### 4.1 季报的价值

- 更高频的业绩更新（港股只有半年报）
- 早于半年报反映业务拐点
- 业绩爆雷往往最先在季报中显现

### 4.2 季报的局限性

- 一季报和三季报**不经审计**，数据可信度低于年报/半年报
- 季度数据波动正常，单季度数据不宜过度解读
- 上市公司可能在季报中"平滑"收益（把部分利润从业绩差的季度推到业绩好的季度）

### 4.3 季报的阅读方法

**关注同比而非环比（季度有季节性）：**
- 餐饮/旅游：Q2/Q3收入高于Q1/Q4（季节性）
- 零售/消费：Q4（双十一+春节）通常最强
- 建筑/工程：Q4结算多，收入集中

**关注收入vs利润的结构变化：**
- 收入增长但毛利率下降 → 竞争加剧或成本上升
- 利润增长但经营现金流恶化 → 需警惕

## 5. 审计机构（A股）

**A股会计师事务所格局：**

| 类型         | 代表机构                  | 特点                   |
| ---------- | --------------------- | -------------------- |
| 国际四大（Big4） | 毕马威、德勤、普华永道、安永（在华合伙所） | 最高标准，主要审计大型央企和外资背景公司 |
| 国内头部所      | 天健、立信、大华、容诚、瑞华（已解散）   | 审计质量差异大              |
| 地方中小所      | 各地小型会计师事务所            | 警示信号区域               |
|            |                       |                      |

**A股的"审计所问题"历史案例：**
- 瑞华会计师事务所：曾是国内最大之一，2019年因多起造假丑闻（康得新等案例）遭暂停经营，最终解散
- 立信所：瑞幸咖啡（美股）的案例中被点名

**风险信号：** 上市公司频繁更换审计机构，或从Big4/大所降级为小所，是重大警示。

## 6. A股特有的信息核查渠道

### 6.1 工商信息（企查查/天眼查）

**企查查（qichacha.com）** 或 **天眼查（tianyancha.com）**：

可查询：
- 公司工商注册信息、股权结构
- 法院诉讼记录（是否涉诉）
- 经营异常、行政处罚记录
- 关联公司网络（股权穿透）

**应用：** 查上市公司实际控制人的其他关联公司，判断是否存在"体外循环"风险。

### 6.2 裁判文书网（wenshu.court.gov.cn）

查询与上市公司或其高管相关的法院判决，发现潜在法律风险。

### 6.3 国家企业信用信息公示系统（gsxt.gov.cn）

查工商注册信息、经营异常名录。
