# 第02章：A股监管体系

---

## 1. 监管层级结构

```
国务院金融稳定发展委员会（金融委）
    ↓ 统筹协调
中国证券监督管理委员会（CSRC / 证监会）← 核心监管机构
    ↓
上海证券交易所（SSE）      深圳证券交易所（SZSE）      北京证券交易所（BSE）
（自律监管机构）             （自律监管机构）             （自律监管机构）
    ↓
中国证券登记结算公司（中证登，CSDC）← 结算机构
```

**中国人民银行（央行）** 和 **国家外汇管理局（外汇局）** 不直接监管股票市场，但通过货币政策和外汇管理间接影响市场。

---

## 2. 中国证监会（CSRC）

**核心职能：**
- 制定证券法规和政策
- 审核（注册制下为"注册"）上市申请
- 监管信息披露
- 查处内幕交易、市场操纵、证券欺诈
- 监管证券公司、基金公司、期货公司的牌照

**证监会主席的市场影响力：**
A股独特现象：证监会主席的公开讲话、表态，往往直接影响市场短期走势。2024年吴清就任证监会主席后推出的一系列政策（退市新规、分红要求、减持限制）对市场结构产生深远影响。

**证监会重要数据库：**
- 上市公司信息披露：巨潮资讯网（cninfo.com.cn）— A股的"披露易"等价平台
- 行政处罚决定书：证监会官网公告栏（sec.gov.cn/发行监管→行政处罚）
- 证券公司等机构牌照：证监会官网→机构监管→证券公司

## 3. 沪深交易所的自律监管

### 3.1 问询函制度（A股独有重要机制）

上交所和深交所可向上市公司发出**问询函（Inquiry Letter）**，要求公司就特定问题作出书面回复。

**问询函类型：**

| 类型      | 触发情形              |
| ------- | ----------------- |
| 年报问询函   | 财务数据异常、关联交易、商誉减值等 |
| 半年报问询函  | 同上                |
| 重大事项问询函 | 并购重组、股价异常波动       |
| 临时报告问询函 | 公告信息不完整或有疑问       |

**对投资者的意义：**
- 公司收到问询函→可能有潜在问题被监管注意→警示信号
- 问询函及公司回复均在巨潮资讯网公开，是研究公司的重要资料
- 未能在规定期限内回复问询函→可能被暂停交易

**实操：** 在巨潮资讯网搜索某公司，在公告类型中选"交易所问询函"，可查全部历史问询记录。

### 3.2 年报问询的常见方向（财务红旗的监管版本）

- 营收增速与同行业明显背离
- 应收账款异常增加
- 毛利率显著高于同行
- 商誉规模大且减值测试假设过于乐观
- 关联交易定价合理性
- 大额资金拆借给关联方

## 4. 信息披露制度

### 4.1 法定披露文件体系

| 文件        | 频率      | 截止时间                    |
| --------- | ------- | ----------------------- |
| 年度报告      | 年度      | 4月30日前（主板），4月30日（科创/创业） |
| 半年度报告     | 半年      | 8月31日前                  |
| 一季报（季度报告） | 季度（1季度） | 4月30日前                  |
| 三季报（季度报告） | 季度（3季度） | 10月31日前                 |
| 业绩预告      | 满足条件时必须 | 业绩出现大幅变动时提前披露           |
| 业绩快报      | 自愿或部分强制 | 年报前发布                   |
| 重大事项公告    | 即时      | 知悉后立即                   |

**A股披露频率高于港股：** A股每季度有季报（港股只有半年报+年报），信息更新更频繁。

### 4.2 业绩预告制度

**触发强制业绩预告的条件（主板）：**
- 净利润亏损
- 净利润同比增长或下降50%以上
- 扭亏为盈或由盈转亏

**科创板/创业板：** 预告条件有所差异，部分为自愿披露。

**对投资者的意义：** 业绩预告往往是股价急剧波动的触发点。如果你持有某只股票且即将进入业绩预告窗口（通常是季报公布前2-4周），需要特别警惕。

### 4.3 信息披露平台

**巨潮资讯网（cninfo.com.cn）：** 证监会指定的A股信息披露平台，所有公告免费查阅，等同于港股的披露易。

**上交所官网（sse.com.cn）：** 上交所上市公司公告

**深交所官网（szse.cn）：** 深交所上市公司公告

**北交所官网（bse.cn）：** 北交所上市公司公告

## 5. 股东权益披露

### 5.1 持股变动披露门槛

| 门槛             | 披露要求               |
| -------------- | ------------------ |
| 持股达5%          | 须在3个工作日内披露         |
| 持股每增/减1%（5%以上） | 须在次日披露             |
| 持股达20%         | 通常触发要约收购讨论         |
| 持股达30%         | 触发要约收购义务（A股规则类似港股） |

### 5.2 大股东减持规则（A股特别严格）

A股有专门的**大股东减持规定**，远比港股严格：

**核心约束：**
- 控股股东/实际控制人：减持须提前15个交易日披露减持计划
- 大宗交易减持：每90天不超过公司股份总数2%
- 集中竞价减持：每90天不超过公司股份总数1%
- 破发、破净、分红不达标时：控股股东不得减持（2023年新规）

**2023年减持新规影响：**
- 上市公司股价低于发行价（破发）或低于每股净资产（破净），控股股东被限制减持
- 近3年未分红或分红不达标，控股股东被限制减持
- 这一新规显著改善了A股的分红文化，迫使更多公司提高分红比例

## 6. 证券公司监管

### 6.1 证券公司的分类监管

证监会对证券公司实行**分类评级（A/B/C/D/E）**，评级影响：
- 新业务申请资质
- 客户保证金比例
- 自营投资规模上限

**对投资者影响：**
- 选择评级A类（AA/A）的大型券商，资产安全性更高
- 评级低的券商合规风险更高

### 6.2 投资者保护机制

**证券投资者保护基金（保护基金）：**
- 若证券公司破产，个人客户资产最高获赔50万元人民币（仅覆盖公司挪用/破产，不覆盖投资损失本身）
- 实际情况：客户的证券资产（股票）存于中证登，不在券商资产负债表内，安全性较高；主要风险是融资融券的质押品

## 7. 上市审核的实质条件（注册制下）

### 7.1 科创板上市标准（五套之一选择）

| 标准  | 财务要求                                |
| --- | ----------------------------------- |
| 标准一 | 预计市值≥10亿，近2年利润合计≥5000万，或近1年利润≥3000万 |
| 标准二 | 预计市值≥15亿，近1年收入≥2亿，且近3年研发投入合计≥6000万  |
| 标准三 | 预计市值≥20亿，近1年收入≥3亿，且经营活动现金流为正        |
| 标准四 | 预计市值≥30亿，近1年收入≥3亿                   |
| 标准五 | 预计市值≥40亿，主要资产为无形资产，收入主要来自无形资产       |

科创板允许未盈利公司上市（标准四、五），但需满足市值和收入门槛。

### 7.2 创业板上市标准

| 标准  | 要求                                |
| --- | --------------------------------- |
| 标准一 | 最近2年盈利且合计≥5000万，或最近1年盈利且收入≥3亿     |
| 标准二 | 预计市值≥10亿，最近1年收入≥1亿，且近2年研发合计≥5000万 |
| 标准三 | 预计市值≥50亿，最近1年收入≥3亿                |

### 7.3 科创属性要求（科创板特有）

申请在科创板上市，必须满足"科创属性"评价标准之一：
- 最近3年研发投入合计≥6000万，且占营收比例≥5%
- 或研发人员占比≥10%
- 或获得核心技术相关发明专利≥5项
- 或近3年营收复合增速≥20%（收入≥3亿时）
