# 第11章：A股打新（IPO认购）

---

## 1. A股打新机制概述

A股的打新机制在注册制改革后发生了根本性变化，与注册制前有很大不同。

### 1.1 注册制前 vs 注册制后对比

| 维度     | 核准制（2019年前）       | 注册制（科创板2019+，全面2023+） |
| ------ | ----------------- | --------------------- |
| 发行定价   | 23倍PE红线（不能超过）     | 市场化定价（询价机制）           |
| 破发概率   | 极低（受PE红线保护）       | 常见（15-30%的概率）         |
| 上市首日涨幅 | 通常44%封顶（沪深主板首日限制） | 无首日涨跌停（前5日），可大幅波动     |
| 申购方式   | 网上投资者直接申购         | 同，但科创板/创业板门槛不同        |
| 配售对象   | 公众散户为主            | 询价（机构）+网上（散户）         |

### 1.2 主板打新 vs 注册制板块打新差异

| 维度     | 主板（上交所/深交所）             | 科创板/创业板/北交所                  |
| ------ | ----------------------- | ---------------------------- |
| 投资者门槛  | 无（所有A股账户可申购）            | 科创/北交所：50万+24个月；创业板：10万+24个月 |
| 定价     | 市场化（但主板仍有23倍PE参考）       | 完全市场化                        |
| 上市首日限制 | ±10%（主板注册制后为43.99%涨幅上限） | 前5日无限制                       |
| 破发风险   | 较低                      | 较高                           |

## 2. 打新的参与条件

### 2.1 市值配售制度（A股打新核心机制）

**A股打新的关键机制：** 打新不需要额外资金，而是按**持有的A股市值**来配售申购数量。

**规则（以上交所主板为例）：**
- 每持有10,000元市值的A股（沪市股票/基金），可申购1签（500股）
- 每次只能申购1个账户1次（不能重复申购）
- 中签后才需要冻结资金（主板）

**计算示例：**
- 持有沪市股票市值：10万元
- 可申购数量：10签（10 × 1签）
- 中签概率：假设为1%，期望中签0.1签（大概率空手）

**持有市值越高，可申购数量越多，中签概率越高。**

### 2.2 所需市值来源

**沪市新股（上交所）：** 持有沪市A股、科创板股票、上交所基金（含ETF）的市值计入

**深市新股（深交所）：** 持有深市A股、创业板股票、深交所基金的市值计入

**注意：** 沪市和深市的市值**分别计算**，不能混用（在深交所上市的新股，必须用持有深市股票的市值申购）。

## 3. 打新流程详解

### 3.1 新股申购时间线

```
T-7天：招股说明书公开（巨潮资讯网）
T-5天：网下询价（机构投资者参与）
T-4天：定价完成（公布发行价）
T-3天（通常为周二）：网上申购日（散户参与，一天内完成）
  - 申购时间：上午9:30-下午11:30，下午13:00-15:00
  - 网上申购后，资金不冻结（主板注册制后改为无须提前冻结资金）
T-2天：公布中签率，冻结中签账户资金
T-1天：公布中签结果
T日：新股上市交易
```

### 3.2 申购操作

1. 开盘后在券商App的"打新/新股"页面找到当日申购新股
2. 填写申购数量（按市值计算最大可申购量，或按需填写）
3. 点击申购（全程免费，无须冻结资金，中签后才扣款）
4. 等待次日结果

**打新的边际成本极低：** 申购不冻结资金，无手续费，仅需几分钟操作，因此"每天打新"是A股散户的基本操作。

## 4. 注册制下打新的破发风险

### 4.1 破发（首日跌破发行价）

注册制下，新股破发已成常态，尤其在市场低迷期：

**历史破发率数据：**
- 2021年（科创板/创业板注册制初期）：破发率约15-20%
- 2022年（市场低迷）：破发率达到30-40%
- 2023-2024年：市场好转后降至15%左右，但仍远高于核准制时代

### 4.2 哪类新股破发率高

| 风险因素                 | 说明             |
| -------------------- | -------------- |
| 估值过高（发行PE>40倍且行业不支持） | 询价机构抬高定价，上市后回调 |
| 上市时市场整体低迷            | 系统性风险下所有新股均承压  |
| 公司基本面弱（收入低、亏损大）      | 无实际支撑          |
| 超募严重（融资额远超计划）        | 发行方贪婪定价        |
| 同板块已有破发先例            | 散户避险情绪蔓延       |

### 4.3 打新的策略判断

**中签后是否参与打新：不等于必须持有**

中签后需做决策：
```
上市首日开盘价 > 发行价（涨幅>10%）→ 考虑卖出锁定收益
上市首日开盘价 ≈ 发行价（±5%）→ 观察走势，可短期持有或卖出
上市首日开盘价 < 发行价（破发）→ 视破发幅度和基本面决定是否止损
```

**注册制下打新不再是"稳赚"，每次中签后都需要做独立的投资决策。**

## 5. 科创板打新的特殊性

### 5.1 科创板网下询价机制

科创板/创业板注册制新股，**60%-70%的股份通过网下询价分配给机构投资者（公募/私募/QFII等）**，剩余20-30%才是网上（散户）申购。

**初步询价 → 定价（剔除最高10%报价）→ 最终发行价**

机构报价机制导致：部分过度追捧的科技股定价极高（机构激进报价），上市后破发风险更大。

### 5.2 科创板战略配售

IPO的部分股份分配给**战略投资者**（锁定期12-18个月），与港股的基石投资者类似。

战略投资者强大的阵容（头部基金/产业资本）是对新股质量的背书，但锁定期到期后的减持压力也需要关注。

---

## 6. 北交所打新的特殊性

北交所的打新机制与沪深不同：

**精选层打新（北交所）：**
- 需要开通北交所权限（50万元资产+24个月经验）
- 采用询价机制，无市值配售（与科创板类似）
- 流动性更差，破发概率更高
- 上市前5日无涨跌停（±30%从第六日起）

**北交所打新风险明显高于沪深主板，新手谨慎参与。**

---

## 7. 可转债打新（T+0的补充打新机会）

可转债（Convertible Bond）的打新机制与股票打新不同，是A股特有的重要补充：
- 无需市值配售，每个账户直接申购100张（1万元面值）
- 中签率随机，资金冻结制（申购时冻结资金）
- 上市首日可以立即卖出（T+0）
- 历史上可转债打新收益率较稳定（见第14章）
