# 12 · 进阶策略与组合构建

---

## 一、从"选股"到"组合管理"

初级投资者：关注单只股票涨跌  
进阶投资者：关注**整体组合**的风险/收益特征

这个转变至关重要。一只股票的表现只有放在组合背景下才有意义。

---

## 二、因子投资框架

学术研究证明的超额收益来源（Risk Premia）：

### 五大核心因子

| 因子 | 解释 | 2026年状态 |
|------|------|-----------|
| 市场（Beta）| 持有股票本身的风险溢价 | 一直有效 |
| 规模（Size）| 小市值溢价 | 近10年弱化 |
| 价值（Value）| 低估值溢价 | 2022年后复苏 |
| 动量（Momentum）| 强者恒强 | 有效但崩溃风险高 |
| 质量（Quality）| 高ROE/低杠杆 | 高利率下表现突出 |

### 因子轮动

各因子有自己的经济周期偏好：

| 宏观环境 | 占优因子 |
|---------|---------|
| 经济扩张+低利率 | 成长、动量 |
| 经济扩张+高利率 | 质量、价值 |
| 经济收缩+低利率 | 成长、低波动 |
| 经济收缩+高利率 | 质量、低波动、防御 |

**2026年背景**：高利率环境下，质量因子（QUAL）和价值因子表现优于成长因子。

## 三、宏观框架下的资产配置

### 美联储政策周期与资产类别

```
紧缩周期（加息）:
  → 利率敏感资产下跌（长债、高估值成长股、REITs）
  → 受益：银行（净息差扩大）、大宗商品（通胀对冲）

宽松周期（降息）:
  → 利率敏感资产上涨
  → 受益：成长股、REITs、长期债券

滞胀：
  → 所有传统资产同步受压
  → 受益：黄金、大宗商品、能源股
```

### 经济周期四象限

**复苏阶段**（GDP向上，通胀向下）：
- 最佳资产：股票（特别是周期股、小盘股）、企业债

**过热阶段**（GDP向上，通胀向上）：
- 最佳资产：大宗商品、能源、原材料、通胀保护债券

**滞涨阶段**（GDP向下，通胀向上）：
- 最佳资产：大宗商品、黄金、现金，最差：股票

**衰退阶段**（GDP向下，通胀向下）：
- 最佳资产：国债（特别是长债）、防御股（必需消费品、医疗）

**2026年位置**：高利率后期，部分行业出现压力，美联储进入降息周期准备阶段。

## 四、组合构建的五个层次

### 层次一：战略资产配置（SAA）

确定各资产类别的长期目标比例，不频繁调整。

**参考模板（中度风险投资者，30-50岁）**：

```
美国股票（VTI）：50%
国际股票（VXUS）：20%
美国债券（BND）：20%
黄金/大宗商品：5%
现金/短期债券：5%
```

### 层次二：战术资产配置（TAA）

在SAA基础上，根据当前宏观环境做小幅偏离（±5-10%）。

**例**：SAA中债券20%，当前降息周期开始 → 临时增加到30%

### 层次三：行业/板块选择

在股票部分内决定哪些行业超配/低配。

### 层次四：个股选择

在确定的行业内选择具体公司。

### 层次五：时机与执行

技术分析 + 分批建仓控制时机风险。

**原则**：每个层次的决策不要互相干扰——行业判断不影响个股选择逻辑。

## 五、再平衡（Rebalancing）

随着时间推移，各资产比例会偏离目标，需要再平衡。

### 为什么要再平衡

- 防止组合风险慢慢漂移（牛市后股票占比可能从50%涨到70%）
- 强制执行"高了卖，低了买"的纪律

### 再平衡触发条件

**方法一：日历再平衡**
- 每年1月固定再平衡
- 简单，适合大多数人

**方法二：阈值再平衡**
- 某资产偏离目标比例5%时再平衡
- 更精确，但需要更频繁关注

### 再平衡的税务考量（应税账户）

- 卖出已经盈利的资产 → 产生资本利得，触发税
- 优化方法：用新增资金买入低配资产，而不是卖出高配资产
- 或在Roth IRA等避税账户中进行再平衡

## 六、收益归因分析

了解你的收益从哪里来，才知道哪里值得继续投入。

### 简单归因框架

```
超额收益 = 市场Beta贡献 + 行业/板块贡献 + 个股选择贡献 + 时机贡献
```

**实操方法**：
- 每季度对比：你的组合收益 vs 标普500
- 超出的部分，分析来自哪几只股票或哪种配置
- 哪些是你的判断，哪些是运气？

## 七、量化策略简介（进阶）

### 动量策略（Momentum）

买入过去3-12个月涨幅最大的股票，卖出跌幅最大的。

**历史数据**：在美股中，12个月动量因子长期有效  
**风险**：动量崩溃（Momentum Crash）——在市场急速反转时可能亏损20-30%

**实现工具**：MTUM ETF，或自己用筛选器构建

### 统计套利思路（均值回归）

两只相关股票（如可口可乐和百事）的价差在历史范围内均值回归。

- 当价差偏大时：买便宜的，卖贵的
- 当价差回归时：获利平仓

**门槛**：需要统计知识和回测能力，不适合纯新手

### 系统化价值投资

建立量化筛选模型，定期（季度/年度）更新持仓：

**Greenblatt魔法公式**：
= 高收益率（EBIT/EV）+ 高ROC（回报率）的公司组合  
历史回测：年化超额收益5-10%（但有几年大幅落后市场的时期）

## 八、做空（Short Selling）

### 做空机制

1. 向券商借入股票
2. 立即卖出（收到现金）
3. 等股价下跌后以更低价格买回
4. 归还股票，保留差价

**做空的风险**：
- **损失无限**：股价可以涨到任何高度，理论上损失无上限
- **借券成本**：做空热门股票需要支付高额借券费用（年化可达50%+）
- **逼空（Short Squeeze）**：大量做空者被迫平仓，股价暴涨

**实例**：GameStop（GME）2021年事件，散户协调逼空机构做空仓位。

### 普通投资者的做空工具

**反向ETF**：
- SQQQ：3倍做空纳斯达克100
- SH：1倍做空标普500
- SPXU：3倍做空标普500

**注意**：3倍反向ETF有每日复利衰减（Volatility Decay），不适合长期持有，只能短期交易。

## 九、另类策略

### 股息增长策略（Dividend Growth Investing）

投资持续提高股息的公司（Dividend Aristocrats = 25年以上连续提高股息的标普500成分股）。

**逻辑**：能持续提高股息的公司通常：
- 业务稳定
- 自由现金流强劲
- 管理层有股东友好的资本配置习惯

**代表指数**：NOBL ETF（Proshares S&P 500 Dividend Aristocrats）  
**2026年背景**：高利率下，股息收益率与债券收益率相近，股息增长股吸引力有所下降，但长期仍是优质持仓。

### 回购策略

专注于大规模持续回购的公司。

回购 = 减少股数 = 每股价值增加  
**指标**：回购收益率 = 年度回购金额 / 市值

高回购收益率公司通常认为自家股票被低估，且FCF充裕。

## 十、完整投资流程总结

**年度级别（每年做一次）**：
1. 评估宏观周期位置（经济/通胀/利率）
2. 调整战略资产配置目标
3. 年度组合再平衡
4. 全年表现复盘，归因分析

**季度级别（每季度做一次）**：
1. 跟踪持仓公司财报
2. 判断投资论点是否仍然成立
3. 检查是否需要阈值再平衡
4. 新的投资机会研究

**月度级别**：
1. 执行定投计划
2. 检查仓位比例是否严重偏离

**每日**：
1. 不要每天盯盘
2. 只在需要执行特定操作时查看账户

---

## 关键点速查

- 从选股转向组合管理：评估单只股票时看它对整体组合的贡献
- 五大因子：市场/规模/价值/动量/质量；2026年质量因子突出
- SAA（战略配置）不频繁调整，TAA（战术配置）小幅跟随宏观
- 再平衡首选"买入低配资产"而非"卖出高配资产"（避税）
- 动量策略有效但有崩溃风险，不适合单独使用
- 做空：损失无限，适合对冲不适合投机
- 3倍反向ETF每日衰减，只适合短期交易工具
