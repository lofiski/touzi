# 05 · 技术分析

---

## 一、技术分析的定位与边界

技术分析研究的是**价格和成交量的历史形态**，用于判断：
- 何时买入（时机选择）
- 设在哪里止损（风险定义）
- 目标价位在哪（盈利预期）

**技术分析的正确位置**：在基本面确定"买什么"之后，技术面确定"什么时候买"。

**技术分析不能做什么**：
- 预测公司的基本面变化
- 预测重大宏观事件
- 在完全随机的市场中发现"秘密规律"

---

## 二、K线（蜡烛图）基础

### K线的解读

```
        ┃  ← 上影线（最高价）
    ┌───┐
    │   │  ← 实体（开盘价到收盘价）
    │   │    实体绿色/白色 = 收盘 > 开盘（上涨）
    │   │    实体红色/黑色 = 收盘 < 开盘（下跌）
    └───┘
        ┃  ← 下影线（最低价）
```

### 重要单K线形态

**锤子线（Hammer）**：下影线长，实体小，位于下跌趋势末端 → 潜在底部反转  
**射击之星（Shooting Star）**：上影线长，实体小，位于上涨趋势末端 → 潜在顶部反转  
**十字星（Doji）**：开盘=收盘，多空均衡，方向待定  
**吞没形态（Engulfing）**：后一根K线完全包住前一根，反转信号  
**孕线（Inside Bar）**：波动收窄，能量蓄积，等待方向突破

### 多根K线组合

**早晨之星 / 黄昏之星**：三根K线组合，底部/顶部反转信号  
**三白兵 / 三黑鸦**：连续三根同向实体，趋势确认信号

**使用原则**：K线形态是概率，不是必然。必须结合成交量、支撑阻力位使用。

---

## 三、支撑与阻力

最核心、最可靠的技术概念。

**支撑位**：价格下跌时反复被承接的价位，多空力量博弈点  
**阻力位**：价格上涨时反复受阻的价位

### 支撑阻力的来源

1. **历史高低点**：前期明显的高点和低点
2. **整数位**：$100、$150、$200——心理关口
3. **移动均线**：MA20、MA50、MA200
4. **斐波那契回撤位**：38.2%、50%、61.8%
5. **成交量密集区**：大量筹码换手的价位

### 支撑变阻力 / 阻力变支撑

**突破后角色互换**是技术分析中最可靠的规律之一：
- 价格跌破支撑 → 原支撑变新阻力
- 价格突破阻力 → 原阻力变新支撑

## 四、趋势分析

### 趋势定义（道氏理论基础）

**上升趋势**：一系列更高的低点（Higher Lows）+ 更高的高点（Higher Highs）  
**下降趋势**：一系列更低的高点（Lower Highs）+ 更低的低点（Lower Lows）  
**盘整区间**：高点和低点在水平范围内震荡

**趋势的三个级别**：
- **主趋势**（数月到数年）
- **中间趋势**（数周到数月）
- **短期趋势**（数天到数周）

用高级别趋势确定方向，在低级别趋势中找买卖点。

### 趋势线画法

1. 上升趋势线：连接**两个或以上的低点**，第三次触碰有效
2. 下降趋势线：连接**两个或以上的高点**
3. 触碰次数越多，趋势线越有效
4. 突破趋势线：收盘价为准，而非日内刺穿

## 五、移动均线

### 常用均线及含义

| 均线 | 周期 | 含义 |
|------|------|------|
| MA5/MA10 | 5/10日 | 超短期趋势 |
| MA20 | 20日（约1个月）| 短期趋势，反弹阻力支撑 |
| MA50 | 50日（约2.5个月）| 中期趋势，机构关注 |
| MA200 | 200日（约1年）| 长期趋势基准，多空分水岭 |

### 均线的使用

**价格与均线的关系**：
- 价格 > MA200：长期趋势向上（牛市区间）
- 价格 < MA200：长期趋势向下（熊市区间）

**均线交叉信号**：
- 黄金交叉（Golden Cross）：MA50上穿MA200 → 中长期看涨信号
- 死亡交叉（Death Cross）：MA50下穿MA200 → 中长期看跌信号

**注意**：均线交叉是**滞后指标**，只能确认趋势，不能预测转折。

### 均线作为动态支撑阻力

机构和算法大量使用MA50和MA200作为买卖参考，形成**自我实现效应**——越多人用，越有效。

## 六、成交量分析

**价格的谎言，成交量难以撒谎。**

### 量价关系基本规则

| 价格 | 成交量 | 含义 |
|------|--------|------|
| 上涨 | 放量 | 强势突破，可信 |
| 上涨 | 缩量 | 上涨乏力，警惕 |
| 下跌 | 放量 | 强力抛售，空头强势 |
| 下跌 | 缩量 | 无量阴跌，抛压减轻，可能接近底部 |

### OBV（能量潮指标）

将成交量按当日涨跌累加，形成一条线。  
如果OBV先于价格创新高 → 资金在偷偷买入（bullish divergence）  
如果OBV先于价格创新低 → 资金在偷偷卖出（bearish divergence）

## 七、常用技术指标

### RSI（相对强弱指数）

- 范围0-100
- RSI > 70：超买区间
- RSI < 30：超卖区间
- **背离（Divergence）比超买超卖更有用**：
  - 价格创新高，RSI没创新高 → 顶部背离
  - 价格创新低，RSI没创新低 → 底部背离

### MACD

三条线：MACD线（快线）、信号线（慢线）、柱状图（差值）

**使用方式**：
- MACD线上穿信号线 → 买入信号
- MACD线下穿信号线 → 卖出信号
- 柱状图由负转正 → 多头动能增强

**最可靠用法**：与价格的背离。价格创新高，MACD柱缩短 → 动能衰减。

### 布林带（Bollinger Bands）

中轨：MA20  
上轨：MA20 + 2倍标准差  
下轨：MA20 - 2倍标准差

**使用方式**：
- 价格触及上轨 + RSI超买 → 短期可能回调
- 价格触及下轨 + RSI超卖 → 短期可能反弹
- 布林带收窄（Squeeze）→ 即将大幅波动，方向待定
- **波动率高时布林带会扩张**，不要单独用布林带位置判断

## 八、经典形态

### 持续形态（趋势中的整理）

**旗形（Flag）**：急涨后横盘收缩，突破方向延续原趋势  
**楔形（Wedge）**：高点低点都在收窄，方向相反于收缩方向突破  
**杯柄形（Cup & Handle）**：W形底部整理，手柄突破买入点

### 反转形态

**头肩顶/底（Head & Shoulders）**：
- 三个高点/低点，中间最高/低
- 颈线突破确认反转
- 目标价 = 颈线 ± 头到颈线的距离

**双顶/双底（Double Top/Bottom）**：
- 两次触及相近价位受阻/承接
- M形/W形
- 颈线突破确认

### 形态使用原则

1. 形态有效性从左向右，时间越长越有效
2. 突破必须有**成交量放大**确认
3. 突破前后的假突破（Fakeout）很常见，等待收盘确认
4. 目标价只是参考，实际要结合止损比例判断值不值得

## 九、技术分析的实操框架

### 多时间框架分析

**先看大，再看小**：
1. **周线/月线**：确定主要趋势方向
2. **日线**：寻找买入形态和区间
3. **小时线/15分钟**：精确入场点和止损位

### 入场三要素

1. **方向**：大趋势支持做多还是做空？
2. **区域**：价格在支撑区域/阻力突破点附近？
3. **触发**：有K线确认信号（如收阳突破、强势锤子线）？

三要素同时满足，才是高概率交易机会。

### 止损设置

止损的逻辑：**设在这个分析假设被证伪的位置**
- 做多突破阻力：止损设在突破位下方5-10%
- 做多支撑反弹：止损设在支撑位下方5-10%
- 止损距离决定仓位大小（见09风险管理篇）

---

## 关键点速查

- 技术分析 = 解决"什么时候买"，不解决"买什么"
- 支撑/阻力是最可靠的技术概念，角色互换
- MA200是多空分水岭，机构重度关注
- 量价背离早于价格转折出现
- RSI/MACD背离比超买超卖信号更可靠
- 三时间框架：月线定方向，日线定区间，小时线定入场
