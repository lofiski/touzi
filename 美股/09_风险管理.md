# 09 · 风险管理

---

## 一、风险管理的核心原则

**第一法则**：不亏钱。  
**第二法则**：不忘记第一法则。  
——巴菲特

这不是保守，是数学：
- 亏损50%后，需要涨100%才能回本
- 亏损80%后，需要涨400%才能回本
- **保住本金的价值 > 赚取超额收益的价值**

---

## 二、仓位管理系统

### 风险单位（Risk Per Trade）

每笔交易只拿多少账户资金去冒险？

**核心公式**：
```
仓位大小 = (账户总值 × 风险比例) / 止损距离
```

**例子**：
- 账户：$100,000
- 每次最多亏1%（风险比例）= $1,000
- 买入价$50，止损$45 → 止损距离$5
- 可买入数量 = $1,000 / $5 = 200股
- 实际投入 = 200 × $50 = $10,000（仓位10%）

**推荐风险比例**：
- 新手：0.5%/笔
- 有经验：1%/笔
- 专业：1-2%/笔（极少超过2%）

### 最大持仓限制

| 类别 | 单笔上限 | 说明 |
|------|---------|------|
| 个股 | 10% | 超过需极高确信度 |
| 行业集中 | 30% | 同一行业不超过 |
| 单一主题/因子 | 40% | 如科技整体 |
| 杠杆/期权 | 5% | 高风险工具总暴露 |

### 组合层面风险

**Beta控制**：组合的整体市场敏感度
- 牛市可以适当高Beta（>1），跟着市场涨得更多
- 熊市或不确定时降低Beta，持有低相关性资产

**最大回撤容忍度**：
- 自问：账户跌多少我还能正常执行策略？
- 跌超过这个数字，说明仓位或策略需要调整

## 三、止损策略

### 为什么必须设止损

**不设止损的代价（真实案例型）**：
- 某股票-10%，"等等看"
- -20%，"跌这么多了，再等等"
- -40%，"割了就真亏了，等回来"
- -70%，"算了，公司完了"

每一步都是理性的，结果是灾难性的。**止损不是认输，是保留继续参与市场的资格。**

### 止损类型

**固定百分比止损**：
- 单价$100的股票，设8-10%止损（$90-$92）
- 简单，不需要过多分析
- 适合初学者

**技术位止损**：
- 止损设在关键支撑位下方（如MA50、前低点下方）
- 更合理，因为你的分析假设建立在该支撑有效的基础上
- 需要技术分析能力

**时间止损**：
- 买入后3-6个月，如果价格没有明显变化（横盘）
- 说明催化剂不如预期，资金有机会成本
- 适合成长股

**基本面止损**：
- 触发条件：公司基本面出现重大变化（不是因为股价）
- 例：收入增速从30%降至5%，或管理层重大变动

### 永远先定止损位，再决定买多少

止损位 → 决定仓位大小 → 保证单笔最大损失在1-2%以内

## 四、集中与分散

### 过度分散的危害

- 持有50只股票 → 你实际上在复制一个昂贵的指数
- 无法深度研究所有持仓
- 一只涨50%对组合影响只有1%

### 过度集中的危害

- 3只股票占90%仓位
- 一只出问题，账户受重创
- 情绪上也更难坚持策略

### 推荐结构

**普通投资者（业余时间有限）**：
```
核心指数（VOO/VTI）：60-70%
高信念个股：3-5只，各5-10%
行业/主题ETF：10-20%
现金：5-10%
```

**进阶投资者（有系统性研究能力）**：
```
10-20只股票，每只3-10%
最大单一持仓15%（需要极高确信）
指数ETF作为基准对冲
```

## 五、相关性与真正的分散

很多人以为持有30只科技股是分散了，实际上相关性极高。

**真正的分散要求资产之间的相关性低**：

| 资产类别 | 与标普500相关性（近10年）|
|---------|----------------------|
| 美国小盘股 | 0.85（高） |
| 国际发达市场 | 0.87（高） |
| 新兴市场 | 0.75（中高） |
| 美国国债 | -0.20（负相关）|
| 黄金 | 0.05（几乎不相关）|
| 大宗商品 | 0.25（低） |
| REITs | 0.72（中高） |

**2026年现状**：全球化背景下，各市场相关性比20年前高，但债券和黄金仍是有效的分散工具。

## 六、杠杆风险

### 保证金（Margin）杠杆

**杠杆放大一切——包括损失**：
- 2倍杠杆，股市下跌30% → 你亏60%
- 3倍杠杆，股市下跌33% → 你亏100%

**Margin Call（追缴保证金）**：
- 当账户净值低于维持保证金要求时触发
- 被迫在最坏时机（市场崩盘时）卖出
- 主动管理的最低线：永远维持账户净值远高于最低要求

**建议**：
- 除非经验丰富，不用保证金杠杆于股票
- 如果使用，保证金借贷不超过账户净值的20-30%

### 期权的隐性杠杆

- 买入$500的期权合约，控制$5000的股票 → 10倍隐性杠杆
- 看起来仓位很小，实际风险暴露很大
- 期权头寸用Delta/美元计算真实暴露量

## 七、黑天鹅与尾部风险

### 历史上美股的极端事件

| 事件 | 最大跌幅 | 时间 |
|------|---------|------|
| 大萧条（1929）| -89% | 3年 |
| 科网泡沫（2000-02）| -49% | 2.5年 |
| 金融危机（2008-09）| -57% | 1.5年 |
| COVID崩盘（2020）| -34% | 约1个月 |

**规律**：每次大跌，很多人认为"这次不一样，不会回来了"。历史上，每次都回来了（前提：你的本金还在）。

### 防御性措施

**现金比例**：
- 保留5-20%现金，用于危机时加仓
- 危机时加仓 = 同样的钱买到更多资产

**对冲工具**：
- 买入长期OTM Put（保险费用高，长期持有不划算）
- 买入VIX Call（极端恐慌时大涨）
- 持有逆相关资产（黄金、国债）

**策略层面的防御**：
- 避免在高杠杆状态下持有高波动性资产
- 历史高点附近减少新增买入，不是因为能预测，而是控制时机风险

## 八、情境分析：不同市场环境下的调整

### 牛市末期信号（参考，非精确指标）

- 信贷利差收窄至历史低位
- 散户情绪极度乐观（AAII调查）
- 估值分位数 > 80%（席勒PE > 35）
- IPO市场极度热闹，垃圾公司也能高估值上市
- 市场广度收窄（只有少数大市值股票在拉指数）

**操作**：不是"清仓跑路"，而是：
- 减少高Beta成长股仓位
- 增加现金和防御性持仓
- 收紧止损

### 熊市中的操作

- **不要抄底**，而是等待趋势确认
- 每次反弹都可能是熊市反弹，不是真正底部
- 真正底部的特征：成交量极度萎缩的最后一跌，或政策面重大转向
- 分批买入，不要一次底仓全压

## 九、量化风险指标

### 最大回撤（Max Drawdown）

从最高点到最低点的最大跌幅。  
这才是真正衡量风险的指标，不是年化波动率。

### 夏普比率（Sharpe Ratio）

= (年化收益率 - 无风险利率) / 年化波动率

衡量每单位风险换取的超额收益：
- Sharpe > 1.0：优秀
- Sharpe > 0.5：可以接受
- Sharpe < 0：策略在承担风险但没有超额收益

### 卡尔玛比率（Calmar Ratio）

= 年化收益率 / 最大回撤

比Sharpe更关注下行风险，对长期投资者更有意义。

---

## 关键点速查

- 每笔交易最大亏损1-2%账户，由止损位决定仓位大小
- 止损位要先设，再决定买多少——这是顺序
- 分散≠持有很多只股票，而是持有低相关性资产
- 杠杆放大一切，大多数人不需要保证金杠杆
- 保留5-20%现金，危机是最好的买入机会
- 最大回撤是比年化波动率更重要的风险指标
