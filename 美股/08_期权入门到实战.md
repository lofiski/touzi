# 08 · 期权入门到实战

---

## 一、期权是什么

期权是**权利，不是义务**。

| 类型         | 持有人的权利          | 支付            |
| ---------- | --------------- | ------------- |
| Call（看涨期权） | 在到期前，以行权价买入100股 | 付权利金（Premium） |
| Put（看跌期权）  | 在到期前，以行权价卖出100股 | 付权利金（Premium） |

每张期权合约 = 控制100股。

---

## 二、期权的四个基本操作

| 操作              | 行为   | 最大损失    | 最大收益    |
| --------------- | ---- | ------- | ------- |
| Buy Call（买入看涨）  | 付权利金 | 全部权利金   | 无限      |
| Sell Call（卖出看涨） | 收权利金 | 无限（裸卖）  | 权利金     |
| Buy Put（买入看跌）   | 付权利金 | 全部权利金   | 行权价-权利金 |
| Sell Put（卖出看跌）  | 收权利金 | 行权价-权利金 | 权利金     |

**规则一**：买期权 = 买权利 = 付钱 = 有限损失，无限（或有限）收益  
**规则二**：卖期权 = 卖权利 = 收钱 = 有限收益，无限（或有限）损失

---

## 三、期权的价格构成

```
期权价值 = 内在价值（Intrinsic Value）+ 时间价值（Time Value）
```

### 内在价值

Call的内在价值 = max(股价 - 行权价, 0)  
Put的内在价值 = max(行权价 - 股价, 0)

- **实值（In-The-Money, ITM）**：有内在价值
- **平值（At-The-Money, ATM）**：行权价 ≈ 股价，内在价值约为0
- **虚值（Out-of-The-Money, OTM）**：无内在价值，纯时间价值

### 时间价值

- 到期越远，时间价值越大
- **时间衰减（Theta）**：每过一天，期权价值减少
- 越接近到期日，时间衰减加速（尤其是最后30天内）

---

## 四、希腊字母（Greeks）

理解Greeks是真正使用期权的必要条件。

### Delta（δ）

**期权价格相对于标的股价变动的敏感度**

- Call Delta：0 到 +1
- Put Delta：-1 到 0
- ATM期权 Delta ≈ ±0.5
- ITM越深，Delta越接近±1（像持有股票）
- OTM越深，Delta越接近0

**用途**：
- 判断期权对股价的暴露量（Delta = 0.7的Call → 股价涨$1，期权涨$0.70）
- Delta-neutral对冲：做市商和机构用来消除方向性风险

### Theta（θ）

**每天的时间衰减量**（通常为负数，对期权买家不利）

- 买期权：Theta是成本，每天损失一点价值
- 卖期权：Theta是收入，每天赚一点时间价值
- **规律**：ATM期权Theta最大，OTM和ITM期权Theta小

### Gamma（γ）

**Delta变化的速度**

- 高Gamma = Delta变化快 = 期权价值对股价变化的杠杆更强
- ATM期权Gamma最高
- 高Gamma对买方有利（股价波动越大越好），对卖方有风险

### Vega（v）

**期权价格对隐含波动率（IV）变化的敏感度**

- IV上升 → 期权价值上升（对买方有利）
- IV下降 → 期权价值下降（对买方不利）
- **IV Crush**：财报发布后，IV从高位下降，期权价值骤降，即使方向判断正确也可能亏钱

---

## 五、隐含波动率（IV）

**IV是市场对未来波动的预期，不是历史波动。**

```
IV Percentile = 当前IV在过去一年所有IV中的排名百分位
```

- IV Percentile > 70：IV处于历史高位，期权贵，倾向卖出策略
- IV Percentile < 30：IV处于历史低位，期权便宜，倾向买入策略

**IV Crush的具体场景**：
- 财报前：市场预期大幅波动，IV被买高
- 财报后：不确定性消除，IV暴跌
- 即使股价涨了10%，如果IV从80%跌到20%，Call可能不赚钱

## 六、常用期权策略

### 买入Call（Long Call）

**适用场景**：强烈看涨，有时间催化剂（财报、产品发布）  
**优点**：有限损失，无限收益  
**缺点**：需要方向对+时间对，时间价值是成本  

**选择参数的原则**：
- 到期日：至少2-3个月（留够时间），避开30天内
- 行权价：不要太OTM（成功率低），ATM到轻度OTM（15-20%OTM）

### 卖出Put（Short Put / Cash-Secured Put）

**适用场景**：愿意以更低价格买入某股票，同时收取权利金  
**机制**：如果股价跌到行权价以下，被迫买入100股；如果没跌，保留权利金  
**实质**：以"打折价"买入你本来想买的股票

**例子**：
- 苹果当前价$220，你愿意以$200买入
- 卖出$200行权价的Put，收$5权利金
- 如果到期苹果>$200：保留$5，等于$220买入收益5.5%
- 如果到期苹果<$200：以$200买入，实际成本$195（$200-$5）

### 买入Put（Long Put）

**适用场景**：看跌某只股票，或对冲现有多头持仓  
**对冲用途**：持有$100,000股票组合，买入对应金额的Put，类似买保险

### Covered Call（备兑看涨）

**适用场景**：持有100股，同时卖出高于当前股价的Call，增强持仓收益  
**机制**：股价未突破行权价，保留权利金；突破行权价，股票被call走  
**实质**：放弃超额上涨收益，换取当前收入

**例子**：
- 持有100股苹果@$200，卖出$230 Call，收$3权利金
- 苹果到期<$230：保留权利金，每股年化额外收益1.5%
- 苹果>$230：股票被以$230卖出，额外收益$3权利金

### 牛市价差（Bull Call Spread）

**适用场景**：看涨但降低成本  
**构成**：买低行权价Call + 卖高行权价Call（相同到期日）  
**优点**：成本比单独买Call低  
**缺点**：上方收益有上限

### 铁鹰式（Iron Condor）

**适用场景**：预期股价在区间内震荡，IV高时卖  
**构成**：卖OTM Call + 买更远OTM Call + 卖OTM Put + 买更远OTM Put  
**盈利条件**：到期时股价在两个行权价之间  
**最大损失有限**，适合高IV环境中的稳健策略

## 七、实战规则

### 永远知道最大损失

在开仓前，计算**最坏情况下你会损失多少**，确保这在你的承受范围内。

### 避免买入快到期的OTM期权

这是最快亏完权利金的方法：
- OTM：没有内在价值
- 临近到期：时间价值加速衰减
- 两个因素叠加，期权很快归零

### 财报期间的期权

- 财报前：IV高，期权贵
- 财报后：IV Crush，期权暴跌
- 不要在财报前买入期权，除非预期的波动幅度远超IV隐含的幅度
- 财报前卖出期权（Iron Condor）是很多专业交易者的策略

### 仓位管理

- 单次期权交易不超过总账户的2-5%
- 期权的高杠杆意味着小仓位已有足够暴露
- 把期权收益/损失换算为"如果直接买股票"的等效金额，感受更直观

---

## 八、常见亏钱方式

1. **买入频临到期的OTM期权**：最常见，几乎肯定归零
2. **财报前买Call/Put**：IV Crush把你的收益全部吃掉
3. **过度加杠杆**：期权本来就是杠杆，再用保证金放大，指数级风险
4. **不设止损**：期权可以在几天内亏90%，不止损就是等归零
5. **不理解Theta衰减**：以为买了看涨期权就等涨，每天在流血

---

## 关键点速查

- 买期权：有限损失，理论无限收益，每天时间流逝
- 卖期权：有限收益，有较大损失风险，每天赚时间价值
- Delta=方向暴露，Theta=时间成本/收益，Vega=波动率敏感度
- IV高时倾向卖期权，IV低时倾向买期权
- IV Crush是财报期最常见的杀伤方式
- Covered Call + Cash-Secured Put = 对持仓者最实用的两个策略
- 永远先计算最大损失，再开仓
