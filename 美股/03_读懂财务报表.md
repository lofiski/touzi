# 03 · 读懂财务报表

---

财报是公司说话的地方，也是骗子造假的地方。读懂它是一切基本面分析的前提。

## 一、报告类型与周期

| 报告 | 频率 | 提交期限 | 内容 |
|------|------|---------|------|
| 10-K | 年报 | 财年结束后60-90天 | 完整年度财务数据+管理层讨论 |
| 10-Q | 季报 | 季度结束后40-45天 | 简版季度财务数据 |
| 8-K | 重大事项 | 事发后4个工作日 | 收购、高管变动、财报业绩预警等 |
| Proxy Statement (DEF 14A) | 年度股东会前 | - | 高管薪酬、股权激励、股东议案 |

**读原文的顺序**：
1. 先看8-K中的财报新闻稿（Earnings Release）——快速了解关键数字
2. 再看10-Q/10-K中的管理层讨论与分析（MD&A）——了解公司怎么解读自己
3. 最后看财务报表本身——核实数字

---

## 二、三张核心财务报表

### 1. 损益表（Income Statement / P&L）

**回答的问题**：这段时间公司赚了多少钱？

```
营业收入（Revenue）
- 营业成本（COGS）
= 毛利润（Gross Profit）
- 运营费用（OpEx）：研发、营销、管理
= 营业利润（Operating Income / EBIT）
- 利息支出/收入
- 税
= 净利润（Net Income）
```

**必须关注的行**：

**Revenue（营业收入）**：增速是否加速或减速？  
**Gross Margin（毛利率）= 毛利润 / 营业收入**
- 软件/SaaS：70-80%+ 是健康的
- 零售业：25-35% 是正常的
- 制造业：10-20% 是正常的
- 毛利率持续下降 = 竞争压力或成本失控，危险信号

**Operating Income（营业利润）**：剔除了财务结构影响，更能反映主业盈利能力  
**EPS（每股收益）= 净利润 / 稀释后股数**：华尔街最关注的指标，预期差（Beat/Miss）直接影响股价

### 2. 资产负债表（Balance Sheet）

**回答的问题**：某一时间点，公司有什么、欠什么？

```
资产（Assets）= 负债（Liabilities）+ 股东权益（Equity）
```

**资产侧重点**：
- **现金及等价物**：越多越安全，但过多可能是资本配置效率低
- **应收账款（AR）**：卖了货还没收到的钱。AR增速 > 收入增速 = 收款出问题
- **存货（Inventory）**：存货增速 > 销售增速 = 产品卖不动
- **商誉（Goodwill）**：收购时溢价形成，需要每年减值测试，一旦减值直接打击利润

**负债侧重点**：
- **长期债务**：债务/EBITDA > 4x 需要警惕
- **递延收入（Deferred Revenue）**：收了钱还没提供服务，对SaaS公司是好事（预付款多）

**关键比率**：
- **流动比率 = 流动资产 / 流动负债**，>1.5为健康，<1.0有短期偿债压力
- **净现金 = 现金 - 总债务**，正值说明公司无净债务

### 3. 现金流量表（Cash Flow Statement）

**回答的问题**：钱从哪来，到哪去？

这是三张表中**最难造假的**，也是最重要的。

```
经营活动现金流（Operating Cash Flow, OCF）
  = 净利润 + 折旧摊销 ± 营运资金变动

投资活动现金流（Investing Cash Flow）
  = 资本支出（CapEx）+ 收购 + 投资买卖

融资活动现金流（Financing Cash Flow）
  = 发债/还债 + 股票回购 + 股息支付
```

**自由现金流（FCF）= OCF - CapEx**：这才是公司真正创造的"可用的钱"

**FCF vs 净利润**：
- FCF持续 > 净利润：优质公司，折旧多，轻资产
- FCF持续 < 净利润：危险，利润是"纸面"的，实际没有那么多钱

**真实案例**：某公司净利润$1亿，但OCF只有$2000万，FCF只有$0——意味着这家公司的盈利有大量应收账款和存货，实际收不到现金。

## 三、关键财务指标

### 盈利质量

**毛利率（Gross Margin）**：  
核心竞争力的体现，越高越好，重点看趋势

**EBITDA Margin**：  
= EBITDA / 营业收入  
剔除折旧摊销和财务成本，适合比较重资产vs轻资产公司

**FCF Margin = FCF / 营业收入**：  
真正意义上的盈利质量，>15%为优秀

### 成长性

**收入增速（Revenue Growth YoY）**：同比增速  
**有机增速（Organic Growth）**：剔除收购影响的增速，才能看清主业  
**Rule of 40（40法则）**：对SaaS公司  
= 收入增速 + FCF利润率，应 ≥ 40，否则增长不够好或利润不够健康

### 资本效率

**ROE（净资产收益率）= 净利润 / 股东权益**  
巴菲特最爱的指标，持续>15%说明公司有竞争优势

**ROA（总资产收益率）= 净利润 / 总资产**  
衡量资产使用效率

**ROIC（投入资本回报率）= NOPAT / 投入资本**  
最精确的资本效率指标，>WACC才是真正在创造价值

**Asset Turnover（资产周转率）= 收入 / 总资产**  
零售、餐饮等轻资产商业模式特别重要

## 四、读财报的红旗（造假/恶化信号）

### 收入质量问题
- 应收账款增速长期高于收入增速
- Days Sales Outstanding（DSO）不断延长
- 收入突然出现大量"一次性"项目
- 频繁修改收入确认政策

### 现金流问题
- 净利润持续增长，但OCF停滞或下降
- 投资活动现金流巨大，但找不到对应资产
- 融资活动频繁，债务不断增加

### 审计问题
- 审计师出具"非标意见"（Non-Standard Opinion）
- 频繁更换审计师
- 推迟提交财报（申请延期）
- 内控有"重大缺陷"（Material Weakness）

### 管理层信号
- 高管频繁大量卖出自家股票（通过Form 4查看）
- CEO/CFO突然离职
- 股权激励目标被频繁下调
- 关联交易复杂（特别是中概股）

## 五、财报季节奏

美股财报季每年四次，集中在以下时段：

| 财报季 | 时间 | 发布的是哪个季度业绩 |
|--------|------|-------------------|
| Q1财报季 | 4月 | 前一年Q4或当年Q1 |
| Q2财报季 | 7月 | Q2业绩 |
| Q3财报季 | 10月 | Q3业绩 |
| Q4财报季 | 1-2月 | Q4和全年业绩 |

**财报前后的股价行为**：
- 财报前：股价往往已经反映预期（"买预期，卖事实"）
- 财报后：根据业绩vs预期的差值（Earnings Surprise）产生跳空
- **Beat并不够**：要看是否比"lowered bar"后的预期高，以及Guidance是否上调

**实操建议**：
- 持仓公司财报前后不要加杠杆
- 不确定方向时，财报前减仓到可以承受跳空的仓位

## 六、不同行业的读法差异

| 行业 | 最重要指标 |
|------|-----------|
| SaaS软件 | ARR、NRR、CAC、LTV、Rule of 40 |
| 银行 | NIM（净息差）、NPL（不良贷款率）、CET1资本充足率 |
| 零售 | 同店销售增长（Comps）、存货周转天数 |
| 制造业 | 产能利用率、存货周期、自由现金流 |
| 制药 | 管线进展、专利到期日期、研发/收入比 |
| 地产（REIT）| FFO（资金运营流量）、出租率、债务/资产比 |

---

## 关键点速查

- 三表最重要：损益表看赚钱能力，资产负债表看安全边际，现金流表看真实情况
- FCF > 净利润 = 优质公司；FCF < 净利润 = 利润质量存疑
- 毛利率看竞争力，看趋势不看单点
- 应收账款增速 > 收入增速 = 红旗
- 推迟财报 + 更换审计师 = 严重警告
- 从EDGAR看原始文件，不依赖二手数据
