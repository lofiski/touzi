# 02 · 开户·工具·基础设施

---

## 一、账户类型详解

在美股中，账户类型决定了税务处理方式，选错账户每年多交几千美元的税。

### 应税账户（Taxable / Brokerage Account）

- 随时存取，无限额限制
- **所有收益需缴税**（股息税+资本利得税）
- 中国居民主要使用此类账户
- 适合：需要流动性、金额较大的投资

### 退休账户（适合有美国税务身份的人）

| 账户类型 | 年供款上限(2026) | 税务优惠 | 取款限制 |
|---------|---------------|---------|---------|
| 传统IRA | $7,000（50岁以上$8,000）| 供款可能抵税，增值延税 | 59.5岁前取款罚10% |
| Roth IRA | $7,000 | 税后供款，增值及取款免税 | 59.5岁前本金可取出 |
| 401(k) | $23,500 | 雇主可匹配，延税增值 | 与工作挂钩 |

**只有美国税务居民（持绿卡、H1B等工签持有者）才应优先使用退休账户。**  
纯中国居民直接用应税账户即可。

## 二、券商选择（2026年横向对比）

### 富途证券（Futu/moomoo）

**优点**
- 中文界面，对中国用户友好
- 港美股同一平台
- 美股交易0佣金（部分订单类型）
- 实时行情免费

**缺点**
- 香港监管，内地合规存在不确定性
- 资金安全依赖富途本身稳健性
- 不提供美国税务身份所需的完整退休账户

**适合**：大多数中国大陆投资者的现实选择

### 老虎证券（Tiger Brokers）

**优点**：与富途类似，竞品  
**缺点**：用户规模小于富途，产品深度略逊

### 嘉信理财（Charles Schwab）

**优点**
- 美国最大零售券商，SIPC保险$500,000
- 产品线最全（股票、ETF、期权、债券、退休账户）
- 研究工具完善
- 美联储监管

**缺点**
- 开户需要美国地址（可用有效美国地址）
- 全英文界面
- 国际汇款有限制

**适合**：在美工作或学习者、对安全性要求极高者

### Interactive Brokers（盈透证券）

**优点**
- 全球覆盖最广（135+市场）
- 机构级工具，保证金利率最低
- 期权、期货、外汇、债券一个账户全搞定
- 正式接受中国大陆客户

**缺点**
- 界面复杂，学习成本高
- 月费（但低活跃度账户有条件可豁免）
- 不适合纯新手

**适合**：有一定基础、想做多品类交易的投资者

### 选择建议

```
新手 + 中文需求 → 富途
有美国税务身份 → 嘉信
多资产/期权重度用户 → 盈透
```

## 三、订单类型——执行层面的基础

很多人亏钱只是因为下错了订单类型。

### 市价单（Market Order）

- 立即以当前最优价格成交
- **优点**：保证成交
- **缺点**：价格不可控，流动性差的股票滑点可能很大
- **使用场景**：大型蓝筹股正常交易时段，紧急建仓/平仓

### 限价单（Limit Order）

- 只在指定价格或更优价格成交
- **买入限价单**：实际成交价 ≤ 设定价
- **卖出限价单**：实际成交价 ≥ 设定价
- **使用场景**：绝大多数情况，特别是小市值股票和盘前盘后

### 止损单（Stop Order / Stop-Loss）

- 触发价到达后转为市价单
- 例：持仓均价$100，设置止损$90 → 跌破$90立即市价卖出
- **风险**：跳空（gap down）可能导致实际成交远低于止损价

### 止损限价单（Stop-Limit Order）

- 触发后转为限价单，不是市价单
- 例：止损触发价$90，限价$88 → 跌到$90触发，只接受$88以上成交
- **风险**：极端行情可能完全不成交，保护失效

### 追踪止损（Trailing Stop）

- 止损价随价格上涨而上移，下跌时固定
- 例：设置10%追踪止损，股价涨到$150，止损自动移到$135
- 适合趋势股锁定利润

### 最佳实践

1. **永远用限价单**代替市价单，除非流动性极好
2. 盘前盘后**必须用限价单**
3. 对于重要持仓，设置止损单自动保护
4. 止损触发价和限价之间留足够空间（建议3-5%）

## 四、核心研究工具

### 基本面数据

**Seeking Alpha（seekingalpha.com）**
- 最全的美股分析文章和数据
- 付费版有量化评级系统
- 2026年AI辅助分析功能已相当强大

**Macrotrends（macrotrends.net）**
- 免费，历史财务数据极全
- 可以看任意公司20年的PE、利润率等历史趋势
- 必备工具

**EDGAR（sec.gov/edgar）**
- 美国SEC官方数据库
- 所有上市公司的原始财报（10-K、10-Q、8-K）
- 看原文永远比看二手分析可靠

**Finviz（finviz.com）**
- 股票筛选器（Stock Screener）
- 可用20+财务指标快速筛选股票
- 免费版已够用

### 技术分析工具

**TradingView（tradingview.com）**
- 2026年最主流的图表工具
- 覆盖全球市场
- 内置Pine Script可自定义指标
- 免费版够用，付费版多图表窗口

**Thinkorswim（TD Ameritrade，已并入Schwab）**
- 专业级期权链、期权策略分析
- 适合期权交易者

### 新闻与信息流

**Bloomberg / Reuters**：机构级新闻，付费  
**Benzinga**：免费，财报前后及时性好  
**Twitter/X + 财经账号**：实时情绪，噪音多，需过滤  
**Earnings Whispers（earningswhispers.com）**：财报日历，散户预期vs官方预期  

### 宏观数据

**FRED（fred.stlouisfed.org）**：美联储圣路易斯分行，所有宏观数据  
**CME FedWatch（cmegroup.com）**：市场对美联储加降息的概率预期  
**BLS.gov**：非农就业、CPI等原始数据

## 五、账户设置要点

### 开户后立即做的事

1. **启用双因素认证（2FA）**：SMS不够安全，用认证器App
2. **设置提款确认邮件**：防止账号被盗后资金被转走
3. **了解SIPC保险范围**：
   - SIPC保护$500,000（含$250,000现金）
   - 保护账户中的证券，不保护市场损失
4. **了解保证金账户 vs 现金账户**：
   - **现金账户**：用实际持有的钱交易，无负债
   - **保证金账户**：可借钱交易，期权某些策略需要
   - 新手建议先用现金账户

### 资金划转

- 美国银行 → 嘉信/盈透：ACH转账1-3日，电汇当日
- 中国银行 → 富途/老虎：通过港元账户，1-3日
- **汇款备注**：写清楚是个人投资，保留所有记录

### PDT规则（重要！）

**Pattern Day Trader（频繁日内交易者）规则**：
- 在**保证金账户**中，5个交易日内4次或以上的日内交易（当天买当天卖）
- 触发后账户净值必须维持$25,000以上，否则被限制交易90天
- **如何避免**：用现金账户，或账户净值>$25,000，或减少日内交易次数

## 六、移动端 vs 桌面端

| 场景 | 建议 |
|------|------|
| 日常监控持仓 | 手机App足够 |
| 研究分析 | 桌面端，多屏幕 |
| 下单执行 | 两者皆可，关键是熟练 |
| 期权交易 | 强烈建议桌面端 |

## 关键点速查

- 中国居民主要用应税账户，有美国税务身份才优先用退休账户
- 平台：新手→富途，进阶→盈透，有美国身份→嘉信
- 永远优先用限价单，盘前盘后必须限价
- EDGAR是最权威的财报来源，不可替代
- TradingView + Macrotrends + Finviz = 免费研究三件套
- 新手用现金账户，避免PDT规则触发
